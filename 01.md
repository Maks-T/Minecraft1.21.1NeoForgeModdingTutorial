## Шаг 1: Установка Java (JDK 21)

Поскольку Minecraft написан на Java, для создания модов вам понадобится Java Development Kit (JDK). Для версии Minecraft 1.21.1 требуется **JDK 21**.

1. Перейдите на сайт Oracle (или используйте альтернативы, например, OpenJDK).
2. Скачайте установщик JDK 21 для Windows (рекомендуется формат `.exe` или `.msi`).
3. Запустите установщик. По умолчанию Java устанавливается в папку `C:\Program Files\Java\jdk-21`.
4. *Примечание:* Установщики обычно автоматически прописывают переменные среды (`Path`), но в редких случаях вам может потребоваться перезагрузить компьютер после установки.

## Шаг 2: Установка среды разработки (IntelliJ IDEA)

Для написания кода мы будем использовать **IntelliJ IDEA** от компании JetBrains. Это мощная и удобная IDE (интегрированная среда разработки).

1. Перейдите на официальный сайт JetBrains.
2. Мы рекомендуем использовать **Community Edition** — она абсолютно бесплатна и ее функционала более чем достаточно для создания модов.
    * *(Студенты университетов могут получить лицензию на Professional Edition бесплатно по студенческому email).*
3. Удобный способ установки — скачать **JetBrains Toolbox App**. Это программа-менеджер, через которую удобно скачивать, обновлять и запускать IntelliJ IDEA и другие продукты компании.
4. Установите IDEA. Если на диске `C:` мало места, вы можете изменить путь установки в настройках Toolbox.

## Шаг 3: Генерация проекта мода

Мы не будем использовать шаблон с GitHub (так как его сложнее переименовывать под себя). Вместо этого мы воспользуемся официальным генератором проектов.

1. Перейдите на официальный сайт NeoForge и найдите инструмент **Mod Generator** (Генератор модов).
2. Заполните поля следующим образом:
    * **Mod Name (Имя мода):** Ваше название (например, `Tutorial Mod`).
    * **Mod ID:** Уникальный идентификатор мода.
        * *Важно:* Используйте только **строчные буквы и нижние подчеркивания** (например, `tutorial_mod`). Пробелы и заглавные буквы недопустимы!
    * **Package Name (Имя пакета):** Стандартный формат — `com.ваше_имя.id_мода` (например, `com.besson.tutorial`).
    * **Minecraft Version:** Выберите `1.21.1`.
    * **Gradle Plugin:** Выберите `ModDevGradle`.
    * **Advanced Options:** Обязательно поставьте галочку **"Add mixin configuration"** (Понадобится в будущем для сложных модификаций кода игры).
3. Внимательно проверьте все данные, особенно `Mod ID`.
4. Нажмите **Download Mod Project**, чтобы скачать `.zip` архив с проектом.

## Шаг 4: Импорт проекта в IntelliJ IDEA

1. Распакуйте скачанный `.zip` архив в удобную для вас папку (где вы планируете хранить свои проекты).
2. Переименуйте папку во что-то понятное (например, `TutorialMod-1.21.1-NeoForge`).
3. Откройте IntelliJ IDEA и перетащите эту папку в окно программы, либо нажмите `Open` и выберите папку.
4. Дождитесь окончания первоначальной настройки Gradle.
    * **Внимание:** Первая сборка (скачивание библиотек, ресурсов игры и т.д.) может занять от 2 до 10 минут в зависимости от скорости интернета. Обязательно дождитесь сообщения `BUILD SUCCESSFUL`.

## Шаг 5: Обзор структуры проекта и конфигурация

### Настройки Gradle
Откройте файл `build.gradle`.
* Найдите блок настройки `java`. Убедитесь, что `languageVersion` установлен на `21`.
  ```gradle
  java {
      toolchain {
          languageVersion = JavaLanguageVersion.of(21)
      }
  }
  ```
Проверьте настройки в IDE: перейдите в `Settings -> Build, Execution, Deployment -> Build Tools -> Gradle` и убедитесь, что **Gradle JVM** установлен на версию `21`.

### Файл gradle.properties (Маппинги)
Откройте файл `gradle.properties`. Обратите внимание на строку с маппингами (Parchment).
Маппинги (Mappings) — это словари, которые переводят обфусцированный (запутанный) код Minecraft в понятные названия классов и методов.
* NeoForge и Fabric совместно используют маппинги **Parchment**. Они более полные, чем официальные маппинги Mojang, и переводят даже параметры методов, что сильно упрощает разработку.

### Настройка главного класса (Main Mod Class)
1. Перейдите по пути: `src -> main -> java -> com -> ваше_имя -> tutorial -> TutorialMod.java` (или как вы назвали класс).
2. В файле будет сгенерирован демонстрационный код (регистрация блоков, предметов, креативных вкладок). Для чистоты проекта **удалите весь примерный код**, оставив только конструктор и логгер (мы напишем всё с нуля в следующих уроках).
3. **Безопасное переименование:** Если вам нужно переименовать `Mod ID` или название переменной в коде, не делайте это вручную! Выделите текст и нажмите `Shift + F6`. Это безопасно переименует значение во всем проекте.

## Шаг 6: Загрузка исходного кода Minecraft

Для успешной разработки вам часто придется подглядывать в оригинальный код Minecraft, чтобы понимать, как работают ванильные предметы или блоки.

1. Откройте панель **Gradle** в правой части экрана IntelliJ IDEA.
2. Перейдите в раздел `Tasks -> mod development` (или `download sources`).
3. Дважды кликните на задачу **`downloadSources`** (Загрузить исходники).
4. Процесс может занять некоторое время. После этого вы сможете искать ванильные классы.
5. Нажмите дважды клавишу `Shift` (Double Shift) для поиска по всему проекту (Search Everywhere). Введите, например, `Item` и откройте класс. Теперь вы будете видеть читаемый деобфусцированный код игры!

## Шаг 7: Тестовый запуск игры

Теперь проверим, всё ли настроено правильно.

1. В верхней панели IntelliJ IDEA найдите выпадающий список конфигураций запуска (рядом с зеленой кнопкой Play).
2. Выберите конфигурацию **`Run Client`** (или просто `Client`).
3. Нажмите зеленую кнопку **Play** (или `Shift + F10`).
4. Дождитесь запуска игры. Создайте новый одиночный мир (Singleplayer).
5. Зайдите в мир, попробуйте сломать или поставить блок. Если игра работает стабильно, значит ваша среда разработки настроена идеально!
6. Вы также можете зайти в меню `Mods` в главном меню игры и найти там ваш мод — он должен отображаться с вашим названием, версией и описанием.
