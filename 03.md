## 1. Обзор ванильных вкладок (`CreativeModeTabs`)

Все стандартные вкладки творческого режима зарегистрированы в классе `net.minecraft.world.item.CreativeModeTabs`.

Основные вкладки игры:
* `BUILDING_BLOCKS` (Строительные блоки)
* `COLORED_BLOCKS` (Цветные блоки)
* `NATURAL_BLOCKS` (Природные блоки)
* `FUNCTIONAL_BLOCKS` (Функциональные блоки)
* `REDSTONE_BLOCKS` (Редстоун)
* `HOTBAR` (Панель быстрого доступа)
* `SEARCH` (Поиск предметов)
* `TOOLS_AND_UTILITIES` (Инструменты и полезности)
* `COMBAT` (Бой)
* `FOOD_AND_DRINKS` (Еда и напитки)
* `INGREDIENTS` (Ингредиенты)
* `SPAWN_EGGS` (Яйца призыва)
* `OP_BLOCKS` (Вкладка оператора / админ-предметы)
* `INVENTORY` (Инвентарь выживания)

## 2. Теория: `Item` vs `ItemStack` и `Component`

### Чем `Item` отличается от `ItemStack`?
* **`Item` (Предмет как определение):** это одиночный неизменяемый объект (Singleton). Он описывает общие правила для предмета: базовую прочность, максимальный стак, свойства еды и модель. Сам по себе `Item` не может хранить данные конкретного предмета в руке игрока.
* **`ItemStack` (Стек предметов):** это экземпляр предмета в игре (то, что физически лежит в слоте инвентаря). Он хранит:
    * Ссылку на базовый `Item`.
    * Количество предметов в стаке (Count).
    * Текущую прочность/износ (Damage).
    * Компоненты данных (Data Components / NBT): зачарования, кастомное имя, эффекты зелий и т. д.

> **Аналогия:** `Block` и `BlockEntity`. Обычный блок камня (`Block`) одинаков везде. Но сундук или печка требуют `BlockEntity` для хранения предметов и данных плавки.

### Текстовые компоненты: `translatable` vs `literal`
При задании названий в Minecraft используется интерфейс `Component`:
* **`Component.translatable("key")`:** использует ключ перевода из файлов локализации (`.json`). Текст адаптируется под язык клиента каждого игрока.
* **`Component.literal("Text")`:** жестко заданная строка. Она всегда будет отображаться одинаково, независимо от выбранного в игре языка. Для модов рекомендуется всегда использовать `translatable`.

## 3. Создание класса регистрации вкладок (`ModCreativeModeTabs`)

1. В пакете вашего мода создайте подпакет `tab` (или `item`).
2. Создайте класс `ModCreativeModeTabs.java`.

Для вкладок используется стандартный `DeferredRegister`:

```java
package com.besson.tutorial.tab;

import com.besson.tutorial.TutorialMod;
import com.besson.tutorial.item.ModItems;
import net.minecraft.core.registries.Registries;
import net.minecraft.network.chat.Component;
import net.minecraft.world.item.CreativeModeTab;
import net.minecraft.world.item.ItemStack;
import net.neoforged.bus.api.IEventBus;
import net.neoforged.neoforge.registries.DeferredRegister;

import java.util.function.Supplier;

public class ModCreativeModeTabs {
    // 1. Создаем реестр для вкладок творческого режима
    public static final DeferredRegister<CreativeModeTab> CREATIVE_MODE_TABS = 
            DeferredRegister.create(Registries.CREATIVE_MODE_TAB, TutorialMod.MOD_ID);

    // 2. Регистрируем основную вкладку мода
    public static final Supplier<CreativeModeTab> TUTORIAL_TAB = CREATIVE_MODE_TABS.register(
            "tutorial_tab",
            () -> CreativeModeTab.builder()
                    // Иконка вкладки (передается ItemStack)
                    .icon(() -> new ItemStack(ModItems.ICE_ETHER.get()))
                    // Название вкладки (ключ для локализации)
                    .title(Component.translatable("itemGroup.tutorial_tab"))
                    // Предметы, отображаемые во вкладке
                    .displayItems((parameters, output) -> {
                        output.accept(ModItems.ICE_ETHER.get());
                        output.accept(ModItems.RAW_ICE_ETHER.get());
                    })
                    .build()
    );

    // Метод регистрации шины событий
    public static void register(IEventBus eventBus) {
        CREATIVE_MODE_TABS.register(eventBus);
    }
}
```

## 4. Создание нескольких вкладок и настройка их порядка (`withTabsBefore`)

Если у мода несколько вкладок (например, общая и вкладка материалов), по умолчанию Minecraft сортирует их по алфавиту (названию реестра).

Буква **M** (`material`) идет перед **T** (`tutorial_tab`), поэтому вкладка материалов оказалась бы перед основной. Чтобы принудительно задать порядок, используется метод `.withTabsBefore(...)`:

```java
    // 3. Регистрируем вторую вкладку (Материалы)
    public static final Supplier<CreativeModeTab> MATERIAL_TAB = CREATIVE_MODE_TABS.register(
            "material",
            () -> CreativeModeTab.builder()
                    .icon(() -> new ItemStack(ModItems.CARDBOARD.get()))
                    .title(Component.translatable("itemGroup.material"))
                    .displayItems((parameters, output) -> {
                        output.accept(ModItems.CARDBOARD.get());
                    })
                    // Указываем, что вкладка "material" должна идти ПОСЛЕ "tutorial_tab"
                    .withTabsBefore(net.minecraft.resources.ResourceLocation.fromNamespaceAndPath(
                            TutorialMod.MOD_ID, "tutorial_tab"
                    ))
                    .build()
    );
```

> **Обратите внимание:** метод называется `.withTabsBefore(...)` («С вкладками перед этой»), поэтому переданный в него `ResourceLocation` вкладки `tutorial_tab` расположится **перед** текущей вкладкой `material`.

## 5. Подключение реестра в главном классе мода

В конструкторе вашего главного класса (`TutorialMod.java`) зарегистрируйте `ModCreativeModeTabs` на шине событий мода:

```java
public TutorialMod(IEventBus modEventBus) {
    // Регистрация предметов
    ModItems.register(modEventBus);

    // Регистрация собственных креативных вкладок
    ModCreativeModeTabs.register(modEventBus);

    // Слушатель добавления в ванильные вкладки (если требуется)
    modEventBus.addListener(this::addCreative);
}
```

## 7. Тестирование и скрытая вкладка оператора (OP Items)

### Проверка в игре:
1. Запустите клиент (`Run Client`).
2. Откройте инвентарь творческого режима (`E`).
3. Так как первая страница полностью занята ванильными вкладками, в правом верхнем углу появится переключатель страниц: стрелка вправо `>` (**Страница 2/2**).
4. Перейдите на вторую страницу:
    * Вы увидите ваши вкладки: сначала **Tutorial Tab** с иконкой `Ice Ether`, затем **Material** с иконкой `Cardboard`.
    * Внутри каждой вкладки лежат добавленные через `output.accept(...)` предметы.

### Бонус: Вкладка оператора (Operator Items Tab)
В видео упомянута специальная ванильная вкладка со служебными предметами (командные блоки, барьеры, структурные блоки, палочка отладки и т. д.):

1. Нажмите `Esc -> Настройки (Options) -> Управление (Controls)`.
2. Найдите пункт **«Вкладка для оператора» (Operator Items Tab)** и переключите в положение **ВКЛ (ON)**.
3. Вернитесь в креативный инвентарь: рядом с инвентарем выживания появится иконка командного блока — это отдельная вкладка со всеми скрытыми техническими блоками игры.
