## 1. Почему блоки не выпадают? Теория лута в Minecraft

В Minecraft за любое выпадение предметов отвечают **Таблицы лута (Loot Tables)**:
* Дроп с мобов после убийства.
* Содержимое сундуков в данжах и структурах.
* Предметы из рыбалки и археологии.
* **Дроп при разрушении блоков (`minecraft:block`)**.

Если для блока нет JSON-файла в папке таблиц лута, игра считает, что блок не должен ничего сбрасывать.

> 💡 **Важное изменение в 1.21+:**  
> Начиная с версии Minecraft 1.21, названия многих папок ресурсов изменились с множественного числа на единственное. Папка лута теперь называется **`loot_table`**, а не `loot_tables`! Папка тегов — **`tags/block`**, а не `tags/blocks`.

## 2. Анатомия таблицы лута (Loot Table JSON)

Таблица лута напоминает систему вытягивания карт («пул» и «роллы»):
* **`type`**: тип таблицы (для блоков всегда `"minecraft:block"`).
* **`pools`**: список пулов (групп предметов).
    * **`rolls`**: сколько раз «вытягивается» дроп из пула (обычно `1.0`).
    * **`bonus_rolls`**: дополнительные попытки при высоком уровне удачи игрока.
    * **`entries`**: возможные исходы/предметы:
        * `"type": "minecraft:item"` — конкретный предмет.
        * `"name": "mod_id:item_name"` — идентификатор выпадающего предмета.
        * `"functions"` — функции-модификаторы (например, задать количество `set_count`, учесть зачарование «Удача» `apply_bonus`, или разрушение взрывом `explosion_decay`).
    * **`conditions`**: условия выпадения (например, блок разрушен взрывом `survives_explosion` или добыт инструментом с «Шёлковым касанием» `match_tool`).

## 3. Создание таблиц лута для наших блоков

Создайте директорию:  
`src/main/resources/data/<mod_id>/loot_table/blocks/` (например, `.../data/tutorial_mod/loot_table/blocks/`).

---

### 3.1. Обычный блок (выпадает сам блок)
Создайте файл **`ice_ether_block.json`** (и аналогичный **`raw_ice_ether_block.json`**):

```json
{
  "type": "minecraft:block",
  "pools": [
    {
      "bonus_rolls": 0.0,
      "conditions": [
        {
          "condition": "minecraft:survives_explosion"
        }
      ],
      "entries": [
        {
          "type": "minecraft:item",
          "name": "tutorial_mod:ice_ether_block"
        }
      ],
      "rolls": 1.0
    }
  ]
}
```

* Пояснение: при разрушении с вероятностью 100% выпадает сам блок, если он не был уничтожен взрывом крипера или динамита без шанса на дроп.

---

### 3.2. Руда (Шёлковое касание vs Дроп с Удачей)
Для руд логика сложнее: если кирка зачарована на «Шёлковое касание», должен выпасть блок руды; если нет — сырой минерал с учетом зачарования «Удача».

Создайте файл **`ice_ether_ore.json`**:

```json
{
  "type": "minecraft:block",
  "pools": [
    {
      "bonus_rolls": 0.0,
      "entries": [
        {
          "type": "minecraft:alternatives",
          "children": [
            {
              "type": "minecraft:item",
              "conditions": [
                {
                  "condition": "minecraft:match_tool",
                  "predicate": {
                    "predicates": {
                      "minecraft:enchantments": [
                        {
                          "enchantments": "minecraft:silk_touch",
                          "levels": {
                            "min": 1
                          }
                        }
                      ]
                    }
                  }
                }
              ],
              "name": "tutorial_mod:ice_ether_ore"
            },
            {
              "type": "minecraft:item",
              "functions": [
                {
                  "add": false,
                  "count": {
                    "type": "minecraft:uniform",
                    "max": 3.0,
                    "min": 1.0
                  },
                  "function": "minecraft:set_count"
                },
                {
                  "enchantment": "minecraft:fortune",
                  "formula": "minecraft:ore_drops",
                  "function": "minecraft:apply_bonus"
                },
                {
                  "function": "minecraft:explosion_decay"
                }
              ],
              "name": "tutorial_mod:raw_ice_ether"
            }
          ]
        }
      ],
      "rolls": 1.0
    }
  ]
}
```

* **`minecraft:alternatives`**: игра проверяет условия по порядку:
    1. Есть «Шёлковое касание»? ➔ Выпадает **`tutorial_mod:ice_ether_ore`**.
    2. Нет? ➔ Выпадает **`tutorial_mod:raw_ice_ether`** в количестве от 1 до 3 штук, умноженное на уровень «Удачи» (`ore_drops`).

## 4. Теги блоков: настройка инструментов и уровней добычи

Если в свойствах блока указано `.requiresCorrectToolForDrops()`, игра требует, чтобы блок был прописан в тегах допустимых инструментов и уровней добычи.

> ⚠️ **Критически важно:**  
> Папка тегов создается в пространстве имен **`minecraft`**, а **НЕ** вашего мода:  
> `src/main/resources/data/minecraft/tags/block/`  
> Таким образом мы дописываем свои блоки в ванильные списки игры!

---

### 4.1. Тег инструмента (`mineable/pickaxe`)
Создайте путь:  
`src/main/resources/data/minecraft/tags/block/mineable/pickaxe.json`:

```json
{
  "replace": false,
  "values": [
    "tutorial_mod:ice_ether_block",
    "tutorial_mod:raw_ice_ether_block",
    "tutorial_mod:ice_ether_ore"
  ]
}
```

* **`"replace": false`** — обязательно! Указывает игре добавить наши блоки к ванильным, а не стереть все стандартные блоки Minecraft из списка кирок.

---

### 4.2. Тег уровня кирки (`needs_iron_tool`)
Чтобы руду нельзя было добыть деревянной или каменной киркой, укажем требование к железному уровню или выше.

Создайте файл:  
`src/main/resources/data/minecraft/tags/block/needs_iron_tool.json`:

```json
{
  "replace": false,
  "values": [
    "tutorial_mod:ice_ether_ore"
  ]
}
```

*Другие доступные ванильные теги уровней:*
* `needs_stone_tool` — требует каменную кирку или выше.
* `needs_diamond_tool` — требует алмазную кирку или выше (например, для обсидиана).
* *Незеритовые инструменты по умолчанию могут копать всё, что требует алмазный уровень.*

## 5. Тестирование в игре

1. Запустите конфигурацию **`Run Client`**.
2. Войдите в мир и переключитесь в режим выживания (`/gamemode survival`).
3. Возьмите каменную, железную и алмазную кирки:
    * **Добыча каменной киркой:** руда `Ice Ether Ore` ломается медленно и **ничего не сбрасывает**, так как кирка ниже железного уровня.
    * **Добыча железной киркой:** руда ломается быстро и из нее выпадает **`Raw Ice Ether`**!
    * **Добыча алмазной киркой с Шёлковым касанием:** выпадает сам блок **`Ice Ether Ore`**.
    * **Добыча блоков эфира:** выпадают соответствующие целые блоки.

## 6. Перспектива: ручной JSON против генерации данных (DataGen)

Писать десятки JSON-файлов вручную для сотен предметов, рецептов и таблиц лута долго и легко допустить опечатку (в скобках или ключах).

В современных версиях NeoForge принято использовать механизм **Data Generation (DataGen)** — написание Java-кода, который при сборке проекта автоматически генерирует все JSON-модели, рецепты, таблицы лута и языковые файлы за доли секунды. Мы обязательно подробно разберем DataGen в будущих уроках!

***

**Итог:** Теперь ваши блоки полноценно интегрированы в игровую механику: имеют собственные правила дропа, поддерживают чары и требуют соответствующий уровень инструментов.
