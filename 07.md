# Урок 7: Автоматическая генерация данных (Data Generation / DataGen) в NeoForge 1.21.1

В предыдущих уроках мы создавали предметы, блоки, модели, теги и таблицы лута, вручную прописывая каждый JSON-файл в директории `resources`. При добавлении десятков и сотен предметов такой подход неизбежно приводит к опечаткам (неправильный синтаксис, забытые запятые, ошибочные пути к текстурам).

В этом уроке мы разберем продвинутый инструмент разработчиков Minecraft — **Data Generation (DataGen)**. Мы напишем Java-код, который сам за доли секунды сгенерирует абсолютно все JSON-файлы: состояния блоков (`blockstates`), 3D/2D-модели, файлы локализации (`lang`), таблицы выпадения лута (`loot_table`), теги (`tags`) и рецепты крафта/переплавки (`recipe`).

## 1. Что такое DataGen и почему ручной JSON больше не нужен

**Data Generation** — это встроенная в движок Minecraft и NeoForge система провайдеров (`DataProvider`). Вместо ручной правки сотен строчек JSON:
* Вы описываете правила генерации строго типизированным кодом на Java.
* Компилятор и IDE отслеживают ошибки еще до компиляции (нельзя указать несуществующий блок или опечататься в идентификаторе).
* Специальная Gradle-задача **`runData`** выполняет генерацию файлов за считанные миллисекунды.

> 💡 **Как разделяются провайдеры:**
> * **Клиентская часть (Assets / Client):** модели блоков, модели предметов, языковые файлы.
> * **Серверная часть (Data / Server):** таблицы лута, рецепты, теги блоков и предметов, достижения.

## 3. Генератор состояний и моделей блоков (`ModBlockStateProvider`)

Этот класс создает файлы `blockstates/*.json` и модели `models/block/*.json`. Метод `simpleBlockWithItem` дополнительно генерирует модель блока для инвентаря в `models/item/*.json`.

Создайте класс `ModBlockStateProvider.java`:

```java
package com.besson.tutorial.datagen;

import com.besson.tutorial.TutorialMod;
import com.besson.tutorial.block.ModBlocks;
import net.minecraft.data.PackOutput;
import net.neoforged.neoforge.client.model.generators.BlockStateProvider;
import net.neoforged.neoforge.common.data.ExistingFileHelper;

public class ModBlockStateProvider extends BlockStateProvider {

    public ModBlockStateProvider(PackOutput output, ExistingFileHelper existingFileHelper) {
        super(output, TutorialMod.MOD_ID, existingFileHelper);
    }

    @Override
    protected void registerStatesAndModels() {
        // Создает blockstate, модель cube_all в models/block и модель предмета в models/item
        simpleBlockWithItem(ModBlocks.ICE_ETHER_BLOCK.get(), cubeAll(ModBlocks.ICE_ETHER_BLOCK.get()));
        simpleBlockWithItem(ModBlocks.RAW_ICE_ETHER_BLOCK.get(), cubeAll(ModBlocks.RAW_ICE_ETHER_BLOCK.get()));
        simpleBlockWithItem(ModBlocks.ICE_ETHER_ORE.get(), cubeAll(ModBlocks.ICE_ETHER_ORE.get()));
    }
}
```

## 5. Генератор тегов (`ModBlockTagsProvider` и `ModItemTagsProvider`)

### 5.1. Теги блоков (`ModBlockTagsProvider`)
Создайте класс `ModBlockTagsProvider.java`:

```java
package com.besson.tutorial.datagen;

import com.besson.tutorial.TutorialMod;
import com.besson.tutorial.block.ModBlocks;
import net.minecraft.core.HolderLookup;
import net.minecraft.data.PackOutput;
import net.minecraft.tags.BlockTags;
import net.neoforged.neoforge.common.data.BlockTagsProvider;
import net.neoforged.neoforge.common.data.ExistingFileHelper;
import org.jetbrains.annotations.Nullable;

import java.util.concurrent.CompletableFuture;

public class ModBlockTagsProvider extends BlockTagsProvider {

    public ModBlockTagsProvider(PackOutput output, 
                                CompletableFuture<HolderLookup.Provider> lookupProvider, 
                                @Nullable ExistingFileHelper existingFileHelper) {
        super(output, lookupProvider, TutorialMod.MOD_ID, existingFileHelper);
    }

    @Override
    protected void addTags(HolderLookup.Provider provider) {
        // Все наши блоки ломаются киркой
        tag(BlockTags.MINEABLE_WITH_PICKAXE)
                .add(ModBlocks.ICE_ETHER_BLOCK.get())
                .add(ModBlocks.RAW_ICE_ETHER_BLOCK.get())
                .add(ModBlocks.ICE_ETHER_ORE.get());

        // Руда требует уровень инструмента не ниже железного
        tag(BlockTags.NEEDS_IRON_TOOL)
                .add(ModBlocks.ICE_ETHER_ORE.get());
    }
}
```

## 7. Генератор таблиц лута блоков (`ModBlockLootTablesProvider`)

В NeoForge таблицы лута блоков создаются через наследника `BlockLootSubProvider`.

> ⚠️ **Важная проверка движка:**  
> Метод `getKnownBlocks()` обязан возвращать итератор по всем зарегистрированным блокам мода. Если вы зарегистрировали блок в `ModBlocks`, но забыли указать для него правило лута в методе `generate()`, DataGen намеренно выдаст ошибку сборки, защищая вас от блоков-«пустышек» без дропа.

Создайте класс `ModBlockLootTablesProvider.java`:

```java
package com.besson.tutorial.datagen;

import com.besson.tutorial.block.ModBlocks;
import com.besson.tutorial.item.ModItems;
import net.minecraft.core.HolderLookup;
import net.minecraft.core.registries.Registries;
import net.minecraft.data.loot.BlockLootSubProvider;
import net.minecraft.world.flag.FeatureFlags;
import net.minecraft.world.item.Item;
import net.minecraft.world.item.enchantment.Enchantment;
import net.minecraft.world.item.enchantment.Enchantments;
import net.minecraft.world.level.block.Block;
import net.minecraft.world.level.storage.loot.LootTable;
import net.minecraft.world.level.storage.loot.entries.LootItem;
import net.minecraft.world.level.storage.loot.functions.ApplyBonusCount;
import net.minecraft.world.level.storage.loot.functions.SetItemCountFunction;
import net.minecraft.world.level.storage.loot.providers.number.UniformGenerator;

import java.util.Set;

public class ModBlockLootTablesProvider extends BlockLootSubProvider {

    public ModBlockLootTablesProvider(HolderLookup.Provider registries) {
        super(Set.of(), FeatureFlags.REGISTRY.allFlags(), registries);
    }

    @Override
    protected void generate() {
        // Обычные блоки выпадают сами
        dropSelf(ModBlocks.ICE_ETHER_BLOCK.get());
        dropSelf(ModBlocks.RAW_ICE_ETHER_BLOCK.get());

        // Руда: выпадает от 1 до 3 единиц сырого эфира с учетом удачи и шелкового касания
        add(ModBlocks.ICE_ETHER_ORE.get(), block -> createCustomOreDrop(
                block,
                ModItems.RAW_ICE_ETHER.get(),
                1.0f, 3.0f
        ));
    }

    /**
     * Вспомогательный метод для генерации лута руд с кастомным диапазоном выпадения
     */
    protected LootTable.Builder createCustomOreDrop(Block block, Item item, float min, float max) {
        HolderLookup.RegistryLookup<Enchantment> registryLookup = 
                this.registries.lookupOrThrow(Registries.ENCHANTMENT);

        return createSilkTouchDispatchTable(
                block,
                this.applyExplosionDecay(
                        block,
                        LootItem.lootTableItem(item)
                                .apply(SetItemCountFunction.setCount(UniformGenerator.between(min, max)))
                                .apply(ApplyBonusCount.addOreBonusCount(registryLookup.getOrThrow(Enchantments.FORTUNE)))
                )
        );
    }

    @Override
    protected Iterable<Block> getKnownBlocks() {
        // Возвращает все зарегистрированные в моде блоки для строгой валидации
        return ModBlocks.BLOCKS.getEntries().stream().map(e -> (Block) e.value())::iterator;
    }
}
```

## 8. Генератор рецептов (`ModRecipeProvider`)

`RecipeProvider` позволяет создавать рецепты переплавки (печь, плавильня), верстака (форменные `Shaped` и бесформенные `Shapeless`).

> ⚠️ **Предотвращение перезаписи ванильных рецептов:**  
> Всегда указывайте пространство имен вашего мода во втором аргументе метода `.save(output, ResourceLocation)`! Если вызвать `.save(output)` без указания ID для предметов ванили (например, рецепт получения ванильного сахара), рецепт сгенерируется под namespace `minecraft` и перетрет стандартный ванильный крафт.

Создайте класс `ModRecipeProvider.java`:

```java
package com.besson.tutorial.datagen;

import com.besson.tutorial.TutorialMod;
import com.besson.tutorial.block.ModBlocks;
import com.besson.tutorial.item.ModItems;
import net.minecraft.core.HolderLookup;
import net.minecraft.data.PackOutput;
import net.minecraft.data.recipes.*;
import net.minecraft.resources.ResourceLocation;
import net.minecraft.world.item.Items;
import net.minecraft.world.item.crafting.Ingredient;
import net.minecraft.world.level.ItemLike;

import java.util.List;
import java.util.concurrent.CompletableFuture;

public class ModRecipeProvider extends RecipeProvider {

    // Список сырья, которое переплавляется в ледяной эфир
    private static final List<ItemLike> ICE_ETHER_SMELTABLES = List.of(
            ModItems.RAW_ICE_ETHER.get(),
            ModBlocks.ICE_ETHER_ORE.get()
    );

    public ModRecipeProvider(PackOutput output, CompletableFuture<HolderLookup.Provider> registries) {
        super(output, registries);
    }

    @Override
    protected void buildRecipes(RecipeOutput output) {
        // 1. Плавка в обычной печи (200 тиков)
        oreSmelting(output, ICE_ETHER_SMELTABLES, RecipeCategory.MISC, 
                ModItems.ICE_ETHER.get(), 0.7f, 200, "ice_ether");

        // 2. Плавка в плавильне (100 тиков)
        oreBlasting(output, ICE_ETHER_SMELTABLES, RecipeCategory.MISC, 
                ModItems.ICE_ETHER.get(), 0.7f, 100, "ice_ether");

        // 3. Форменный крафт: 9 единиц эфира -> Блок эфира
        ShapedRecipeBuilder.shaped(RecipeCategory.BUILDING_BLOCKS, ModBlocks.ICE_ETHER_BLOCK.get())
                .pattern("###")
                .pattern("###")
                .pattern("###")
                .define('#', ModItems.ICE_ETHER.get())
                .unlockedBy(getHasName(ModItems.ICE_ETHER.get()), has(ModItems.ICE_ETHER.get()))
                .save(output);

        // 4. Бесформенный крафт: 1 Блок эфира -> 9 единиц эфира
        ShapelessRecipeBuilder.shapeless(RecipeCategory.MISC, ModItems.ICE_ETHER.get(), 9)
                .requires(ModBlocks.ICE_ETHER_BLOCK.get())
                .unlockedBy(getHasName(ModBlocks.ICE_ETHER_BLOCK.get()), has(ModBlocks.ICE_ETHER_BLOCK.get()))
                .save(output, ResourceLocation.fromNamespaceAndPath(TutorialMod.MOD_ID, "ice_ether_from_block"));

        // 5. Бесформенный крафт с ванильным выходом: Картон -> Сахар (пример правильного указания ID)
        ShapelessRecipeBuilder.shapeless(RecipeCategory.MISC, Items.SUGAR, 3)
                .requires(ModItems.CARDBOARD.get())
                .unlockedBy(getHasName(ModItems.CARDBOARD.get()), has(ModItems.CARDBOARD.get()))
                .save(output, ResourceLocation.fromNamespaceAndPath(TutorialMod.MOD_ID, "sugar_from_cardboard"));
    }

    /**
     * Переопределение методов плавки с явным указанием пространства имен мода
     */
    protected static void oreSmelting(RecipeOutput output, List<ItemLike> ingredients, RecipeCategory category, 
                                      ItemLike result, float experience, int cookingTime, String group) {
        oreCooking(output, RecipeSerializer.SMELTING_RECIPE, SmeltingRecipe::new, ingredients, category, 
                result, experience, cookingTime, group, "_from_smelting");
    }

    protected static void oreBlasting(RecipeOutput output, List<ItemLike> ingredients, RecipeCategory category, 
                                      ItemLike result, float experience, int cookingTime, String group) {
        oreCooking(output, RecipeSerializer.BLASTING_RECIPE, BlastingRecipe::new, ingredients, category, 
                result, experience, cookingTime, group, "_from_blasting");
    }

    private static <T extends AbstractCookingRecipe> void oreCooking(
            RecipeOutput output, RecipeSerializer<T> serializer, AbstractCookingRecipe.Factory<T> recipeFactory, 
            List<ItemLike> ingredients, RecipeCategory category, ItemLike result, float experience, 
            int cookingTime, String group, String recipeSuffix) {

        for (ItemLike itemlike : ingredients) {
            SimpleCookingRecipeBuilder.generic(Ingredient.of(itemlike), category, result, experience, cookingTime, serializer, recipeFactory)
                    .group(group)
                    .unlockedBy(getHasName(itemlike), has(itemlike))
                    .save(output, ResourceLocation.fromNamespaceAndPath(TutorialMod.MOD_ID, 
                            getItemName(result) + recipeSuffix + "_" + getItemName(itemlike)));
        }
    }
}
```

## 9. Главный класс DataGen и точка входа (`ModDataGenerator`)

Чтобы запустить созданные провайдеры, их необходимо подписать на событие `GatherDataEvent`.

Создайте класс `ModDataGenerator.java`:

```java
package com.besson.tutorial.datagen;

import com.besson.tutorial.TutorialMod;
import net.minecraft.core.HolderLookup;
import net.minecraft.data.DataGenerator;
import net.minecraft.data.PackOutput;
import net.minecraft.data.loot.LootTableProvider;
import net.minecraft.world.level.storage.loot.parameters.LootContextParamSets;
import net.neoforged.bus.api.SubscribeEvent;
import net.neoforged.fml.common.EventBusSubscriber;
import net.neoforged.neoforge.common.data.ExistingFileHelper;
import net.neoforged.neoforge.data.event.GatherDataEvent;

import java.util.Collections;
import java.util.List;
import java.util.concurrent.CompletableFuture;

@EventBusSubscriber(modid = TutorialMod.MOD_ID, bus = EventBusSubscriber.Bus.MOD)
public class ModDataGenerator {

    @SubscribeEvent
    public static void gatherData(GatherDataEvent event) {
        DataGenerator generator = event.getGenerator();
        PackOutput packOutput = generator.getPackOutput();
        ExistingFileHelper existingFileHelper = event.getExistingFileHelper();
        CompletableFuture<HolderLookup.Provider> lookupProvider = event.getLookupProvider();

        // ================= СЕРВЕРНЫЕ ДАННЫЕ (Data / Server) =================
        // Таблицы лута
        generator.addProvider(event.includeServer(), new LootTableProvider(
                packOutput,
                Collections.emptySet(),
                List.of(new LootTableProvider.SubProviderEntry(ModBlockLootTablesProvider::new, LootContextParamSets.BLOCK)),
                lookupProvider
        ));

        // Рецепты
        generator.addProvider(event.includeServer(), new ModRecipeProvider(packOutput, lookupProvider));

        // Теги блоков
        ModBlockTagsProvider blockTagsProvider = new ModBlockTagsProvider(packOutput, lookupProvider, existingFileHelper);
        generator.addProvider(event.includeServer(), blockTagsProvider);

        // Теги предметов (зависят от тегов блоков)
        generator.addProvider(event.includeServer(), new ModItemTagsProvider(
                packOutput, lookupProvider, blockTagsProvider.contentsGetter(), existingFileHelper
        ));

        // ================= КЛИЕНТСКИЕ РЕСУРСЫ (Assets / Client) =================
        // Состояния и модели блоков
        generator.addProvider(event.includeClient(), new ModBlockStateProvider(packOutput, existingFileHelper));

        // Модели предметов
        generator.addProvider(event.includeClient(), new ModItemModelProvider(packOutput, existingFileHelper));

        // Локализация (en_us и ru_ru)
        generator.addProvider(event.includeClient(), new ModEnUsLangProvider(packOutput));
        generator.addProvider(event.includeClient(), new ModRuRuLangProvider(packOutput));
    }
}
```

## 10. Запуск задачи `runData` и проверка сгенерированных ресурсов

### 10.1. Очистка старых файлов
Перед первым запуском генерации:
1. Зайдите в папку `src/main/resources/assets/<mod_id>/` и удалите папки `blockstates`, `models`, `lang`.
2. Зайдите в папку `src/main/resources/data/` и удалите папки `loot_table`, `recipe`, `tags`.
3. Оставьте только текстуры: `assets/<mod_id>/textures/` (текстуры DataGen не генерирует, они рисуются вручную).

### 10.2. Запуск генерации
1. В выпадающем меню конфигураций запуска IntelliJ IDEA выберите конфигурацию **`Run Data`** (или в панели Gradle: `Tasks -> forge/neoforge -> runData`).
2. Нажмите зеленую кнопку **Play**.
3. Дождитесь выполнения. В консоли отобразится:
   ```text
   [Data Provider] Generated 34 total files in 89ms
   BUILD SUCCESSFUL
   ```

### 10.3. Проверка файлов и запуск игры
В директории вашего проекта (`src/generated/resources/` или `src/main/resources/`) мгновенно появятся все валидные JSON-файлы со структурированным форматированием.

1. Запустите клиент игры (**`Run Client`**).
2. Зайдите в мир:
    * Проверьте инвентарь: все предметы и блоки имеют правильные 2D/3D модели.
    * Переключите язык игры с английского на русский: все названия мгновенно локализуются.
    * Попробуйте расплавить `Raw Ice Ether` в печи или плавильне.
    * Скрафтите блок эфира из 9 кристаллов на верстаке и разберите его обратно.
    * Разрушьте руду киркой с зачарованием «Удача» или «Шелковое касание».
