## 1. Теория: Механика голода и насыщения в Minecraft

### 1.1. Питательность (Nutrition) против Насыщения (Saturation)

В режиме выживания сытость персонажа определяется двумя параметрами:
1. **Питательность (`nutrition`):** количество видимых «окорочков» на шкале голода (каждая единица восстанавливает половину окорочка, т.е. значение `4` восстановит 2 полных окорочка).
2. **Уровень насыщения (`saturation`):** скрытая шкала сытости. Пока насыщение не иссякнет, основная шкала голода не начнет уменьшаться, а здоровье игрока регенерирует быстрее. Многие интерфейсные моды (например, *AppleSkin*) визуализируют этот параметр в виде золотой рамки вокруг окорочков.

---

### 1.2. Формула расчета насыщения

В коде Minecraft разработчики задают не абсолютное значение насыщения, а **модификатор насыщения** (`saturationModifier`).

Реальное количество восстанавливаемого насыщения игра рассчитывает по формуле:
$$\text{Насыщение} = \text{Питательность (nutrition)} \times \text{Модификатор (saturationModifier)} \times 2.0$$

#### Пример: Золотая морковь (Golden Carrot)
* `nutrition = 6` (3 полных окорочка)
* `saturationModifier = 1.2f`
* **Итоговое насыщение:** $6 \times 1.2 \times 2.0 = 14.4$ единиц насыщения! Именно поэтому золотая морковь считается одной из лучших разновидностей еды в игре.

## 2. Создание класса свойств еды (`ModFoodProperties`)

В Minecraft свойства еды инкапсулируются объектом `FoodProperties`. Чтобы код регистрации предметов оставался чистым, вынесем параметры продуктов в отдельный класс.

1. В пакете вашего мода (`com.besson.tutorial.item`) создайте класс `ModFoodProperties.java`.
2. Используем `FoodProperties.Builder`:

```java
package com.besson.tutorial.item;

import net.minecraft.world.effect.MobEffectInstance;
import net.minecraft.world.effect.MobEffects;
import net.minecraft.world.food.FoodProperties;

public class ModFoodProperties {

    // 1. Простая еда: Клубника (Strawberry)
    public static final FoodProperties STRAWBERRY = new FoodProperties.Builder()
            // Восстанавливает 3 единицы голода (1.5 окорочка)
            .nutrition(3)
            // Модификатор насыщения: 3 * 0.4 * 2.0 = 2.4 насыщения
            .saturationModifier(0.4f)
            // С шансом 20% (0.2f) накладывает эффект "Скорость I" на 10 секунд (200 тиков)
            .effect(() -> new MobEffectInstance(MobEffects.MOVEMENT_SPEED, 200, 0), 0.2f)
            .build();

    // 2. Продвинутая еда: Сыр (Cheese)
    public static final FoodProperties CHEESE = new FoodProperties.Builder()
            .nutrition(5)
            .saturationModifier(0.7f)
            // Позволяет есть продукт ДАЖЕ при полной шкале сытости (как золотые яблоки)
            .alwaysEat()
            // Эффект "Скорость I" на 10 секунд с шансом 100%
            .effect(() -> new MobEffectInstance(MobEffects.MOVEMENT_SPEED, 200, 0), 1.0f)
            // Эффект "Прыгучесть I" на 10 секунд с шансом 50%
            .effect(() -> new MobEffectInstance(MobEffects.JUMP, 200, 0), 0.5f)
            // Эффект "Огнестойкость I" на 15 секунд с шансом 30%
            .effect(() -> new MobEffectInstance(MobEffects.FIRE_RESISTANCE, 300, 0), 0.3f)
            .build();
}
```

### Пояснения по методам `FoodProperties.Builder`:
* `.nutrition(int)` — восстанавливаемый видимый голод.
* `.saturationModifier(float)` — коэффициент для формулы скрытого насыщения.
* `.alwaysEat()` — разрешает употребление еды при полностью заполненной шкале голода (по умолчанию Minecraft запрещает есть, если шкала заполнена).
* `.fast()` — ускоренное поедание (в 2 раза быстрее обычного, как у сушеной ламинарии).
* `.effect(Supplier<MobEffectInstance>, float probability)` — добавление статус-эффекта с вероятностью от `0.0f` до `1.0f`.
  > 💡 **Важно для NeoForge 1.21+:** Передавайте создание `MobEffectInstance` через лямбда-выражение `() -> new MobEffectInstance(...)`. Использование прямого экземпляра устарело (`deprecated`), так как прямое создание эффекта на этапе инициализации классов может вызвать проблемы порядка загрузки реестров.

## 3. Регистрация предметов еды в `ModItems`

Откройте класс `ModItems.java` и добавьте регистрацию предметов, передав свойства еды через `.food(...)`:

```java
package com.besson.tutorial.item;

import com.besson.tutorial.TutorialMod;
import net.minecraft.world.item.Item;
import net.neoforged.bus.api.IEventBus;
import net.neoforged.neoforge.registries.DeferredItem;
import net.neoforged.neoforge.registries.DeferredRegister;

public class ModItems {
    public static final DeferredRegister.Items ITEMS = 
            DeferredRegister.createItems(TutorialMod.MOD_ID);

    // ================= ЕДА =================
    public static final DeferredItem<Item> STRAWBERRY = ITEMS.register(
            "strawberry",
            () -> new Item(new Item.Properties().food(ModFoodProperties.STRAWBERRY))
    );

    public static final DeferredItem<Item> CHEESE = ITEMS.register(
            "cheese",
            () -> new Item(new Item.Properties().food(ModFoodProperties.CHEESE))
    );

    // ================= ДРУГИЕ ПРЕДМЕТЫ =================
    public static final DeferredItem<Item> ICE_ETHER = ITEMS.register("ice_ether", () -> new Item(new Item.Properties()));
    public static final DeferredItem<Item> RAW_ICE_ETHER = ITEMS.register("raw_ice_ether", () -> new Item(new Item.Properties()));
    public static final DeferredItem<Item> CARDBOARD = ITEMS.register("material/cardboard", () -> new Item(new Item.Properties()));

    public static void register(IEventBus eventBus) {
        ITEMS.register(eventBus);
    }
}
```

## 4. Добавление еды в Creative Tab

Откройте класс `ModCreativeModeTabs.java` и поместите созданные продукты в нужную вкладку:

```java
.displayItems((parameters, output) -> {
    output.accept(ModItems.ICE_ETHER.get());
    output.accept(ModItems.RAW_ICE_ETHER.get());
    
    // Новая еда
    output.accept(ModItems.STRAWBERRY.get());
    output.accept(ModItems.CHEESE.get());

    output.accept(ModBlocks.ICE_ETHER_BLOCK.get());
    output.accept(ModBlocks.RAW_ICE_ETHER_BLOCK.get());
    output.accept(ModBlocks.ICE_ETHER_ORE.get());
})
```

## 5. Обновление DataGen (модели и локализация)

Благодаря генераторам данных из Урока 7 нам не нужно создавать JSON вручную.

### 5.1. Модели предметов (`ModItemModelProvider`)
Откройте `ModItemModelProvider.java` и добавьте вызовы `basicItem`:

```java
@Override
protected void registerModels() {
    basicItem(ModItems.ICE_ETHER.get());
    basicItem(ModItems.RAW_ICE_ETHER.get());
    basicItem(ModItems.CARDBOARD.get());

    // Модели для еды
    basicItem(ModItems.STRAWBERRY.get());
    basicItem(ModItems.CHEESE.get());
}
```

### 5.2. Локализация (`ModEnUsLangProvider` и `ModRuRuLangProvider`)
В `ModEnUsLangProvider.java`:
```java
add(ModItems.STRAWBERRY.get(), "Strawberry");
add(ModItems.CHEESE.get(), "Cheese");
```

В `ModRuRuLangProvider.java`:
```java
add(ModItems.STRAWBERRY.get(), "Клубника");
add(ModItems.CHEESE.get(), "Сыр");
```

### 5.3. Текстуры
Поместите PNG-изображения (16x16) в директорию текстур:
* `src/main/resources/assets/tutorial_mod/textures/item/strawberry.png`
* `src/main/resources/assets/tutorial_mod/textures/item/cheese.png`

## 6. Тестирование в игре

1. Запустите Gradle-задачу **`runData`** для генерации новых JSON-файлов моделей и локализации.
2. Запустите клиент игры (**`Run Client`**).
3. Создайте или откройте тестовый мир в режиме выживания (`/gamemode survival`).
4. **Проверка `Strawberry` (Клубника):**
    * При полной шкале голода съесть клубнику **нельзя**.
    * Израсходуйте шкалу сытости (побегайте или попрыгайте).
    * Съешьте клубнику: восполнится 1.5 окорочка.
    * При съедании нескольких ягод с шансом 20% на игрока наложится эффект ускорения.
5. **Проверка `Cheese` (Сыр):**
    * Восстановите шкалу голода на максимум.
    * Попробуйте съесть сыр: благодаря опции `.alwaysEat()` персонаж успешно съест сыр даже при полной сытости.
    * Проверьте панель эффектов в инвентаре: вы гарантированно получите эффект «Скорость», а также с заданной вероятностью эффекты «Прыгучесть» и «Огнестойкость».
