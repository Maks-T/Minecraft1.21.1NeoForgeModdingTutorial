# Урок 14: Создание инструментов (Меч, Кирка, Топор, Лопата, Мотыга) в NeoForge 1.21.1

В предыдущих уроках мы научились регистрировать блоки и интерактивные предметы. В этом уроке мы создадим полноценный комплект из пяти классических инструментов из нашего материала (**Ледяной эфир**):
1. **Меч (`SwordItem`)**
2. **Кирка (`PickaxeItem`)**
3. **Топор (`AxeItem`)**
4. **Лопата (`ShovelItem`)**
5. **Мотыга (`HoeItem`)**

В версиях Minecraft **1.20.5+ и 1.21.1** система инструментов претерпела важные архитектурные изменения:
* Уровни инструментов (`Tier`) теперь ссылаются на тег недопустимых для добычи блоков (`incorrectBlocksForDrops`) вместо числового уровня добычи (`harvestLevel`).
* Урон и скорость атаки настраиваются через новый компонентный механизм атрибутов предмета (`createAttributes`).
* Модели инструментов в инвентаре и от первого лица требуют специального родительского шаблона **`item/handheld`**.

## 1. Теория: Архитектура инструментов в 1.21+

### 1.1. Параметры материала (`Tier`)
Любой инструмент привязывается к интерфейсу `net.minecraft.world.item.Tier`. Материал определяет базовые физические свойства линейки инструментов:
* **`uses` (Прочность):** количество использований до поломки (у железа — 250, у алмаза — 1561, у незерита — 2031).
* **`speed` (Скорость добычи):** множитель скорости разрушения подходящих блоков (у железа — 6.0f, у алмаза — 8.0f).
* **`attackDamageBonus` (Базовый бонус урона):** добавляется к урону конкретного инструмента.
* **`enchantmentValue` (Зачаровываемость):** шанс выпадения лучших чар на столе зачарования (у золота — 22, у железа — 14, у алмаза — 10).
* **`incorrectBlocksForDrops` (Тег запрещенных блоков):** тег блоков, которые данный инструмент добыть **не может** (например, обсидиан для железной кирки). В 1.21 это заменило старый числовой `level`.
* **`repairIngredient` (Материал починки):** предмет, которым инструмент чинится на наковальне.

---

### 1.2. Механика атрибутов урона и скорости атаки (`createAttributes`)
В 1.21 свойства урона и скорости удара вынесены в `Item.Properties.attributes(...)`:
* **Базовый урон кулака игрока:** `1.0`.
* **Базовая скорость атаки игрока:** `4.0` удара в секунду.
* В метод `createAttributes(tier, bonusDamage, attackSpeed)` передаются:
    * Дополнительный урон (складывается с бонусом тира).
    * Отрицательный модификатор скорости атаки:
        * **Меч:** `-2.4f` $\rightarrow$ результирующая скорость: $4.0 - 2.4 = 1.6$ удара/сек (кулдаун 0.625 сек).
        * **Топор:** `-3.0f` или `-3.1f` $\rightarrow$ результирующая скорость: $4.0 - 3.1 = 0.9$ удара/сек (медленный, но сокрушительный удар).
        * **Лопата:** `-3.0f` $\rightarrow$ скорость 1.0 удара/сек.
        * **Кирка:** `-2.8f` $\rightarrow$ скорость 1.2 удара/сек.
        * **Мотыга:** `-1.0f` или `0.0f` $\rightarrow$ скорость до 4.0 ударов/сек (самое быстрое оружие без задержки).

## 2. Создание материала инструментов (`ModToolTiers`)

Создадим класс для регистрации параметров нашего тира (Ледяной эфир будет немного прочнее и быстрее железа, ближе к алмазу).

1. В пакете `com.besson.tutorial.item` создайте класс `ModToolTiers.java`.
2. Реализуем интерфейс `Tier`:

```java
package com.besson.tutorial.item;

import com.besson.tutorial.tag.ModTags;
import net.minecraft.tags.BlockTags;
import net.minecraft.tags.TagKey;
import net.minecraft.world.item.Tier;
import net.minecraft.world.item.crafting.Ingredient;
import net.minecraft.world.level.block.Block;

import java.util.function.Supplier;

public enum ModToolTiers implements Tier {
    // Наш материал: Ледяной эфир
    ICE_ETHER(
            // Не может добывать блоки из уровня алмаза (требует алмаз)
            BlockTags.INCORRECT_FOR_DIAMOND_TOOL,
            // Прочность: 650 использований
            650,
            // Скорость копания: 7.0f
            7.0f,
            // Базовый бонус к урону: 2.5f
            2.5f,
            // Зачаровываемость: 16
            16,
            // Предмет для починки на наковальне
            () -> Ingredient.of(ModItems.ICE_ETHER.get())
    );

    private final TagKey<Block> incorrectBlocksForDrops;
    private final int uses;
    private final float speed;
    private final float damage;
    private final int enchantmentValue;
    private final Supplier<Ingredient> repairIngredient;

    ModToolTiers(TagKey<Block> incorrectBlocksForDrops, int uses, float speed, 
                 float damage, int enchantmentValue, Supplier<Ingredient> repairIngredient) {
        this.incorrectBlocksForDrops = incorrectBlocksForDrops;
        this.uses = uses;
        this.speed = speed;
        this.damage = damage;
        this.enchantmentValue = enchantmentValue;
        this.repairIngredient = repairIngredient;
    }

    @Override
    public int getUses() {
        return this.uses;
    }

    @Override
    public float getSpeed() {
        return this.speed;
    }

    @Override
    public float getAttackDamageBonus() {
        return this.damage;
    }

    @Override
    public TagKey<Block> getIncorrectBlocksForDrops() {
        return this.incorrectBlocksForDrops;
    }

    @Override
    public int getEnchantmentValue() {
        return this.enchantmentValue;
    }

    @Override
    public Ingredient getRepairIngredient() {
        return this.repairIngredient.get();
    }
}
```

## 3. Регистрация 5 инструментов в `ModItems`

Откройте класс `ModItems.java`. Зарегистрируйте все 5 инструментов, используя методы фабрики атрибутов `SwordItem.createAttributes(...)`, `PickaxeItem.createAttributes(...)` и т.д.:

```java
package com.besson.tutorial.item;

import com.besson.tutorial.TutorialMod;
import net.minecraft.world.item.*;
import net.neoforged.bus.api.IEventBus;
import net.neoforged.neoforge.registries.DeferredItem;
import net.neoforged.neoforge.registries.DeferredRegister;

public class ModItems {
    public static final DeferredRegister.Items ITEMS = 
            DeferredRegister.createItems(TutorialMod.MOD_ID);

    // ================= ИНСТРУМЕНТЫ =================

    // 1. Меч: +3 урона, скорость атаки -2.4f
    public static final DeferredItem<SwordItem> ICE_ETHER_SWORD = ITEMS.register("ice_ether_sword",
            () -> new SwordItem(ModToolTiers.ICE_ETHER, new Item.Properties()
                    .attributes(SwordItem.createAttributes(ModToolTiers.ICE_ETHER, 3, -2.4f))));

    // 2. Кирка: +1 урона, скорость атаки -2.8f
    public static final DeferredItem<PickaxeItem> ICE_ETHER_PICKAXE = ITEMS.register("ice_ether_pickaxe",
            () -> new PickaxeItem(ModToolTiers.ICE_ETHER, new Item.Properties()
                    .attributes(PickaxeItem.createAttributes(ModToolTiers.ICE_ETHER, 1.0f, -2.8f))));

    // 3. Топор: +6 урона (сильный удар!), скорость атаки -3.1f (медленный замах)
    public static final DeferredItem<AxeItem> ICE_ETHER_AXE = ITEMS.register("ice_ether_axe",
            () -> new AxeItem(ModToolTiers.ICE_ETHER, new Item.Properties()
                    .attributes(AxeItem.createAttributes(ModToolTiers.ICE_ETHER, 6.0f, -3.1f))));

    // 4. Лопата: +1.5 урона, скорость атаки -3.0f
    public static final DeferredItem<ShovelItem> ICE_ETHER_SHOVEL = ITEMS.register("ice_ether_shovel",
            () -> new ShovelItem(ModToolTiers.ICE_ETHER, new Item.Properties()
                    .attributes(ShovelItem.createAttributes(ModToolTiers.ICE_ETHER, 1.5f, -3.0f))));

    // 5. Мотыга: 0 урона, скорость атаки -1.0f (быстрый взмах)
    public static final DeferredItem<HoeItem> ICE_ETHER_HOE = ITEMS.register("ice_ether_hoe",
            () -> new HoeItem(ModToolTiers.ICE_ETHER, new Item.Properties()
                    .attributes(HoeItem.createAttributes(ModToolTiers.ICE_ETHER, 0.0f, -1.0f))));

    // Предметы из прошлых уроков...
    public static final DeferredItem<Item> ICE_ETHER = ITEMS.register("ice_ether", () -> new Item(new Item.Properties()));
    public static final DeferredItem<Item> RAW_ICE_ETHER = ITEMS.register("raw_ice_ether", () -> new Item(new Item.Properties()));

    public static void register(IEventBus eventBus) {
        ITEMS.register(eventBus);
    }
}
```

## 5. Настройка DataGen

### 5.1. Модели инструментов (`handheldItem` против `basicItem`)

> ⚠️ **Критически важное отличие:**  
> Обычные предметы (слитки, ягоды) используют шаблон `item/generated` — в руке персонажа они лежат плашмя.  
> Инструменты и оружие **обязаны** использовать метод **`handheldItem(...)`** (родитель `item/handheld`). В противном случае меч или кирка будут направлены рукоятью вверх или выглядеть плоскими значками!

Откройте `ModItemModelProvider.java` в пакете `datagen`:

```java
package com.besson.tutorial.datagen;

import com.besson.tutorial.TutorialMod;
import com.besson.tutorial.item.ModItems;
import net.minecraft.data.PackOutput;
import net.neoforged.neoforge.client.model.generators.ItemModelProvider;
import net.neoforged.neoforge.common.data.ExistingFileHelper;

public class ModItemModelProvider extends ItemModelProvider {

    public ModItemModelProvider(PackOutput output, ExistingFileHelper existingFileHelper) {
        super(output, TutorialMod.MOD_ID, existingFileHelper);
    }

    @Override
    protected void registerModels() {
        // Обычные 2D предметы
        basicItem(ModItems.ICE_ETHER.get());
        basicItem(ModItems.RAW_ICE_ETHER.get());
        basicItem(ModItems.CARDBOARD.get());
        basicItem(ModItems.STRAWBERRY.get());
        basicItem(ModItems.CHEESE.get());
        basicItem(ModItems.ANTHRACITE.get());
        basicItem(ModItems.ANTHRACITE_2.get());
        basicItem(ModItems.PROSPECTOR.get());

        // ================= ИНСТРУМЕНТЫ (item/handheld) =================
        handheldItem(ModItems.ICE_ETHER_SWORD.get());
        handheldItem(ModItems.ICE_ETHER_PICKAXE.get());
        handheldItem(ModItems.ICE_ETHER_AXE.get());
        handheldItem(ModItems.ICE_ETHER_SHOVEL.get());
        handheldItem(ModItems.ICE_ETHER_HOE.get());
    }
}
```

### 5.2. Теги инструментов (`ModItemTagsProvider`)

В Minecraft 1.21+ игра определяет тип инструмента через ванильные теги предметов (`ItemTags.SWORDS`, `PICKAXES`, `AXES`, `SHOVELS`, `HOES`). Добавим наши инструменты в соответствующие теги:

Откройте `ModItemTagsProvider.java`:

```java
@Override
protected void addTags(HolderLookup.Provider provider) {
    tag(ModTags.Items.SUGAR_INGREDIENTS)
            .add(ModItems.CARDBOARD.get(), ModItems.STRAWBERRY.get(), Items.BEETROOT);

    // Добавляем наши инструменты в ванильные теги игры
    tag(ItemTags.SWORDS).add(ModItems.ICE_ETHER_SWORD.get());
    tag(ItemTags.PICKAXES).add(ModItems.ICE_ETHER_PICKAXE.get());
    tag(ItemTags.AXES).add(ModItems.ICE_ETHER_AXE.get());
    tag(ItemTags.SHOVELS).add(ModItems.ICE_ETHER_SHOVEL.get());
    tag(ItemTags.HOES).add(ModItems.ICE_ETHER_HOE.get());
}
```

## 6. Тестирование в игре

1. Запустите конфигурацию **`Run Data`** — в папке `models/item/` сгенерируются файлы моделей с правильным родителем `"parent": "minecraft:item/handheld"`.
2. Запустите клиент игры (**`Run Client`**).
3. Войдите в мир и откройте инвентарь:
    * **Визуальный тест:** возьмите в руку меч или кирку от третьего лица (`F5`) — персонаж держит предмет ровно за рукоять, лезвием вперед.
    * **Меч:** ударьте моба — проверьте плавное заполнение индикатора атаки и увеличенный урон (в подсказке предмета отображается суммарный урон).
    * **Топор:**
        * Нажмите ПКМ по бревну дерева — топор снимет кору, превратив бревно в обтесанное!
        * Нанесите удар мобу — урон топора значительно выше меча, но замах происходит заметно медленнее.
    * **Лопата:** кликните ПКМ по блоку травы — создается блок земляной тропинки.
    * **Мотыга:** кликните ПКМ по земле — создается вспаханная грядка под посевы.
    * **Кирка:** проверьте скорость разрушения каменных блоков и руды — блок разрушается быстрее, чем железной киркой.
    * **Наковальня:** попробуйте повредить инструмент и починить его с помощью кристалла `Ice Ether` — механика ремонта функционирует штатно.
