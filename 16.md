## 1. Теория: Как устроены всплывающие подсказки (Tooltips) в 1.21+

### 1.1. Анатомия метода `appendHoverText`
В базовом классе `net.minecraft.world.item.Item` за отрисовку текста под именем предмета отвечает метод:
```java
public void appendHoverText(ItemStack stack, TooltipContext context, List<Component> tooltipComponents, TooltipFlag tooltipFlag)
```

Параметры метода:
* **`stack`**: экземпляр конкретного предмета в руках игрока (позволяет считывать прочность, зачарования, кастомные данные).
* **`context`**: контекст подсказки в 1.21+ (предоставляет доступ к реестрам мира `HolderLookup.Provider`, уровням сложности и состоянию игры).
* **`tooltipComponents`**: список строк подсказки (`List<Component>`). Каждая добавленная запись `.add(...)` отображается как отдельная новая строка в рамке описания.
* **`tooltipFlag`**: флаг режима подсказок (`isAdvanced()` возвращает `true`, если у игрока включен расширенный режим отладки подсказок через `F3 + H`).

---

### 1.2. Стилизация текста: `ChatFormatting` против символа `§`

Исторически цвета текста задавались через управляющий символ секции `§` (например, `§e` — желтый, `§7` — серый, `§l` — жирный).

> ⚠️ **Современный стандарт:**  
> В современных версиях движка жесткое использование `§` в Java-коде не рекомендуется, так как Mojang постепенно переводит весь рендеринг текста на строго типизированные компоненты `Component` со стилями:
> ```java
> Component.translatable("...").withStyle(ChatFormatting.YELLOW)
> ```
> Однако внутри JSON-файлов локализации (`en_us.json`, `ru_ru.json`) использование кодов форматирования `§e`, `§7` по-прежнему поддерживается и активно используется для выделения отдельных слов в середине предложения.

## 2. Реализация динамической подсказки в `PickaxeAxeItem`

Откройте класс `PickaxeAxeItem.java`, созданный в Уроке 15, и переопределите метод `appendHoverText`.

Для проверки зажатия клавиши `Shift` на клиенте используется метод:
```java
Screen.hasShiftDown()
```

### Код класса `PickaxeAxeItem`:
```java
package com.besson.tutorial.item.custom;

import com.besson.tutorial.tag.ModTags;
import net.minecraft.ChatFormatting;
import net.minecraft.client.gui.screens.Screen;
import net.minecraft.network.chat.Component;
import net.minecraft.world.item.AxeItem;
import net.minecraft.world.item.Item;
import net.minecraft.world.item.ItemStack;
import net.minecraft.world.item.Tier;
import net.minecraft.world.item.TooltipFlag;
import net.minecraft.world.level.block.state.BlockState;
import net.neoforged.neoforge.common.ItemAbilities;
import net.neoforged.neoforge.common.ItemAbility;

import java.util.List;

public class PickaxeAxeItem extends AxeItem {

    public PickaxeAxeItem(Tier tier, Properties properties) {
        super(tier, properties);
    }

    @Override
    public float getDestroySpeed(ItemStack stack, BlockState state) {
        if (state.is(ModTags.Blocks.PICKAXE_AXE_MINEABLE)) {
            return this.tier.getSpeed();
        }
        return super.getDestroySpeed(stack, state);
    }

    @Override
    public boolean isCorrectToolForDrops(ItemStack stack, BlockState state) {
        return state.is(ModTags.Blocks.PICKAXE_AXE_MINEABLE)
                && !state.is(this.getTier().getIncorrectBlocksForDrops());
    }

    @Override
    public boolean canPerformAction(ItemStack stack, ItemAbility itemAbility) {
        return ItemAbilities.DEFAULT_PICKAXE_ACTIONS.contains(itemAbility)
                || ItemAbilities.DEFAULT_AXE_ACTIONS.contains(itemAbility)
                || super.canPerformAction(stack, itemAbility);
    }

    // ================= ПОДСКАЗКИ К ПРЕДМЕТУ =================
    @Override
    public void appendHoverText(ItemStack stack, TooltipContext context, List<Component> tooltipComponents, TooltipFlag tooltipFlag) {
        // Проверяем, зажата ли клавиша Shift на клавиатуре
        if (Screen.hasShiftDown()) {
            // Подробное описание при зажатом Shift
            tooltipComponents.add(Component.translatable("tooltip.tutorial_mod.pickaxe_axe.shift_down")
                    .withStyle(ChatFormatting.AQUA));
        } else {
            // Подсказка-призыв к действию в обычном состоянии
            tooltipComponents.add(Component.translatable("tooltip.tutorial_mod.pickaxe_axe.shift_prompt")
                    .withStyle(ChatFormatting.GRAY));
        }

        super.appendHoverText(stack, context, tooltipComponents, tooltipFlag);
    }
}
```

## 3. Настройка локализации и цветов в DataGen

Зададим текст подсказок в наших языковых провайдерах. Чтобы слово `[Shift]` красиво выделялось желтым цветом на фоне серого текста, применим цветовые коды `§e` (желтый) и `§7` (серый).

### 3.1. Английская локализация (`ModEnUsLangProvider.java`)
Откройте `ModEnUsLangProvider.java` и добавьте ключи:

```java
// Подсказки к инструментам
add("tooltip.tutorial_mod.pickaxe_axe.shift_prompt", "Hold §e[Shift]§7 for more info");
add("tooltip.tutorial_mod.pickaxe_axe.shift_down", "Dual-tool: Functions as both a Pickaxe and an Axe!");
```

### 3.2. Русская локализация (`ModRuRuLangProvider.java`)
Откройте `ModRuRuLangProvider.java`:

```java
// Подсказки к инструментам
add("tooltip.tutorial_mod.pickaxe_axe.shift_prompt", "Зажмите §e[Shift]§7 для подробностей");
add("tooltip.tutorial_mod.pickaxe_axe.shift_down", "Мультиинструмент: работает как Кирка и Топор одновременно!");
```

## 4. Бонус: Добавление подсказок к любым предметам через `ItemTooltipEvent`

Что делать, если вы хотите добавить описание к блоку, еде или **чужому ванильному предмету** (например, к обычному углю или яблоку), не создавая под каждый предмет отдельный Java-класс?

Для этого в NeoForge существует клиентское событие **`ItemTooltipEvent`**.

Создайте в пакете `event` (или в клиентском классе событий) слушатель:

```java
package com.besson.tutorial.event;

import com.besson.tutorial.TutorialMod;
import com.besson.tutorial.item.ModItems;
import net.minecraft.ChatFormatting;
import net.minecraft.network.chat.Component;
import net.neoforged.api.distmarker.Dist;
import net.neoforged.bus.api.SubscribeEvent;
import net.neoforged.fml.common.EventBusSubscriber;
import net.neoforged.neoforge.event.entity.player.ItemTooltipEvent;

@EventBusSubscriber(modid = TutorialMod.MOD_ID, value = Dist.CLIENT)
public class ModClientEvents {

    @SubscribeEvent
    public static void onItemTooltip(ItemTooltipEvent event) {
        // Добавляем подсказку к сырому ледяному эфиру
        if (event.getItemStack().is(ModItems.RAW_ICE_ETHER.get())) {
            event.getToolTip().add(Component.translatable("tooltip.tutorial_mod.raw_ice_ether")
                    .withStyle(ChatFormatting.DARK_PURPLE, ChatFormatting.ITALIC));
        }
    }
}
```

Не забудьте добавить ключ перевода в языковые файлы:
* `en_us.json`: `"tooltip.tutorial_mod.raw_ice_ether": "Unrefined crystal emitting cold mist."`
* `ru_ru.json`: `"tooltip.tutorial_mod.raw_ice_ether": "Необработанный кристалл, излучающий ледяной туман."`

## 5. Тестирование в игре

1. Запустите задачу генерации данных **`Run Data`** для обновления языковых файлов.
2. Запустите клиент игры (**`Run Client`**).
3. Откройте инвентарь и найдите **Киркотопор (`Ice Ether Pickaxe-Axe`)**:
    * **Обычный вид:** Наведите курсор мыши на инструмент. Внизу отобразится серый текст:  
      `Зажмите [Shift] для подробностей`, при этом скобки и слово `[Shift]` подсвечены ярко-желтым.
    * **Зажатый `Shift`:** Не убирая курсор с предмета, зажмите на клавиатуре клавишу **Shift**. Текст мгновенно и плавно сменится на бирюзовое подробное описание:  
      `Мультиинструмент: работает как Кирка и Топор одновременно!`
    * Отпустите Shift — текст вернется к исходному компактному призыву.
4. Проверьте предмет **Сырой ледяной эфир (`Raw Ice Ether`)** — под ним появится курсивная темно-фиолетовая строчка, добавленная через событие.
