# Урок 17: Создание комплекта брони (Armor & ArmorMaterials) в NeoForge 1.21.1

В предыдущих уроках мы вооружили игрока полным набором инструментов и гибридным киркотопором. Теперь пришло время защитить персонажа — мы создадим полный комплект **брони из ледяного эфира (Ice Ether Armor)**:
1. **Шлем (`ice_ether_helmet`)**
2. **Нагрудник (`ice_ether_chestplate`)**
3. **Поножи (`ice_ether_leggings`)**
4. **Ботинки (`ice_ether_boots`)**

Начиная с версий Minecraft **1.20.5+ и 1.21.1**, система брони претерпела фундаментальные изменения:
* Класс `ArmorMaterials` **больше не является перечислением (`enum`)**. Теперь материалы брони регистрируются в специальном динамическом реестре `Registries.ARMOR_MATERIAL`.
* Расчет прочности элементов брони вынесен в метод `ArmorItem.Type.getDurability(multiplier)`.
* Добавлена поддержка слоев (`ArmorMaterial.Layer`) и брони для волков (`ArmorItem.Type.BODY`).
* Введена поддержка отделки брони кузнечными шаблонами через тег `ItemTags.TRIMMABLE_ARMOR`.

## 1. Теория: Архитектура брони в Minecraft 1.21+

### 1.1. Новый реестр `ArmorMaterial` вместо Enum
В старых версиях Forge для создания брони использовался `enum ModArmorMaterials implements ArmorMaterial`. В Minecraft 1.21.1 Mojang перевели материалы брони в полноценный дата-драйвен реестр `BuiltInRegistries.ARMOR_MATERIAL` (`Registries.ARMOR_MATERIAL`).

Теперь каждый материал — это зарегистрированный объект `Holder<ArmorMaterial>`, инкапсулирующий параметры защиты, звуков и слоев текстур.

---

### 1.2. Расчет прочности частей брони
Каждая деталь брони имеет фиксированный базовый коэффициент прочности в перечислении `ArmorItem.Type`:
* **Шлем (`HELMET`):** `11`
* **Нагрудник (`CHESTPLATE`):** `16`
* **Поножи (`LEGGINGS`):** `15`
* **Ботинки (`BOOTS`):** `13`
* *(Волчья броня (`BODY`): `16`)*

Итоговая прочность рассчитывается умножением базы на **общий множитель материала** (`multiplier`):
$$\text{Прочность шлема} = 11 \times \text{multiplier}$$

| Материал | Множитель | Шлем | Нагрудник | Поножи | Ботинки | Суммарно |
| :--- | :---: | :---: | :---: | :---: | :---: | :---: |
| Кожа | `5` | 55 | 80 | 75 | 65 | 275 |
| Железо | `15` | 165 | 240 | 225 | 195 | 825 |
| **Ледяной эфир (наш)** | **`28`** | **308** | **448** | **420** | **364** | **1540** |
| Алмаз | `33` | 363 | 528 | 495 | 429 | 1815 |
| Незерит | `37` | 407 | 592 | 555 | 481 | 2035 |

---

### 1.3. Параметры защиты, стойкости и сопротивления отбрасыванию
* **Защита (`defense`):** количество очков защиты (один значок нагрудника на панели брони = 2 очка). Максимум ванильной шкалы — 20 очков (10 полных значков).
* **Бронестойкость (`toughness`):** снижает пробивание брони при получении сильного единовременного урона (например, от удара босса или взрыва крипера). У железа — `0.0f`, у алмаза — `2.0f`, у незерита — `3.0f`.
* **Сопротивление отбрасыванию (`knockbackResistance`):** снижает расстояние, на которое персонажа отбрасывает при ударе (`0.1f` = 10% сопротивления).

## 2. Создание и регистрация материала брони (`ModArmorMaterials`)

1. В пакете `com.besson.tutorial.item` создайте класс `ModArmorMaterials.java`.
2. Создайте `DeferredRegister` для реестра `Registries.ARMOR_MATERIAL`:

```java
package com.besson.tutorial.item;

import com.besson.tutorial.TutorialMod;
import net.minecraft.Util;
import net.minecraft.core.Holder;
import net.minecraft.core.registries.Registries;
import net.minecraft.resources.ResourceLocation;
import net.minecraft.sounds.SoundEvents;
import net.minecraft.world.item.ArmorItem;
import net.minecraft.world.item.ArmorMaterial;
import net.minecraft.world.item.crafting.Ingredient;
import net.neoforged.bus.api.IEventBus;
import net.neoforged.neoforge.registries.DeferredHolder;
import net.neoforged.neoforge.registries.DeferredRegister;

import java.util.EnumMap;
import java.util.List;

public class ModArmorMaterials {
    // 1. Реестр материалов брони
    public static final DeferredRegister<ArmorMaterial> ARMOR_MATERIALS = 
            DeferredRegister.create(Registries.ARMOR_MATERIAL, TutorialMod.MOD_ID);

    // 2. Регистрация материала "Ледяной эфир"
    public static final DeferredHolder<ArmorMaterial, ArmorMaterial> ICE_ETHER = ARMOR_MATERIALS.register(
            "ice_ether",
            () -> new ArmorMaterial(
                    // Очки защиты для каждой части (Суммарно: 3 + 8 + 6 + 3 = 20, полный комплект дает 100% шкалы)
                    Util.make(new EnumMap<>(ArmorItem.Type.class), map -> {
                        map.put(ArmorItem.Type.BOOTS, 3);
                        map.put(ArmorItem.Type.LEGGINGS, 6);
                        map.put(ArmorItem.Type.CHESTPLATE, 8);
                        map.put(ArmorItem.Type.HELMET, 3);
                        map.put(ArmorItem.Type.BODY, 11);
                    }),
                    // Зачаровываемость (16 — выше, чем у железа и алмаза)
                    16,
                    // Звук надевания брони
                    SoundEvents.ARMOR_EQUIP_DIAMOND,
                    // Предмет для ремонта на наковальне
                    () -> Ingredient.of(ModItems.ICE_ETHER.get()),
                    // Слой текстуры брони на теле игрока
                    List.of(new ArmorMaterial.Layer(ResourceLocation.fromNamespaceAndPath(TutorialMod.MOD_ID, "ice_ether"))),
                    // Бронестойкость (Toughness)
                    2.0f,
                    // Сопротивление отбрасыванию (Knockback Resistance, 0.05f = 5%)
                    0.05f
            )
    );

    public static void register(IEventBus eventBus) {
        ARMOR_MATERIALS.register(eventBus);
    }
}
```

## 3. Регистрация предметов брони в `ModItems`

Откройте класс `ModItems.java`. Зарегистрируйте все 4 предмета брони, передав зарегистрированный `Holder<ArmorMaterial>` и рассчитав прочность с множителем **`28`**:

```java
// ================= БРОНЯ (Multiplier = 28) =================
public static final DeferredItem<ArmorItem> ICE_ETHER_HELMET = ITEMS.register(
        "ice_ether_helmet",
        () -> new ArmorItem(ModArmorMaterials.ICE_ETHER, ArmorItem.Type.HELMET,
                new Item.Properties().durability(ArmorItem.Type.HELMET.getDurability(28)))
);

public static final DeferredItem<ArmorItem> ICE_ETHER_CHESTPLATE = ITEMS.register(
        "ice_ether_chestplate",
        () -> new ArmorItem(ModArmorMaterials.ICE_ETHER, ArmorItem.Type.CHESTPLATE,
                new Item.Properties().durability(ArmorItem.Type.CHESTPLATE.getDurability(28)))
);

public static final DeferredItem<ArmorItem> ICE_ETHER_LEGGINGS = ITEMS.register(
        "ice_ether_leggings",
        () -> new ArmorItem(ModArmorMaterials.ICE_ETHER, ArmorItem.Type.LEGGINGS,
                new Item.Properties().durability(ArmorItem.Type.LEGGINGS.getDurability(28)))
);

public static final DeferredItem<ArmorItem> ICE_ETHER_BOOTS = ITEMS.register(
        "ice_ether_boots",
        () -> new ArmorItem(ModArmorMaterials.ICE_ETHER, ArmorItem.Type.BOOTS,
                new Item.Properties().durability(ArmorItem.Type.BOOTS.getDurability(28)))
);
```

## 5. Текстуры брони: разница между `layer_1` и `layer_2`

Для корректного отображения брони на персонаже требуются **два типа текстур**:

### 1. Текстуры предметов (2D иконки в инвентаре, 16×16 PNG):
`src/main/resources/assets/tutorial_mod/textures/item/`
* `ice_ether_helmet.png`
* `ice_ether_chestplate.png`
* `ice_ether_leggings.png`
* `ice_ether_boots.png`

---

### 2. Текстуры модели на персонаже (Развертка скина, 64×32 PNG):
Модель игрока в Minecraft использует двухслойную развертку:
* **`layer_1`**: надевается на **голову, туловище, плечи и ступни** (Шлем, Нагрудник, Ботинки).
* **`layer_2`**: надевается на **ноги** (Поножи). Ноги анимируются отдельно от ступней и туловища, поэтому вынесены во второй файл.

Поместите развертки текстур по пути:  
`src/main/resources/assets/tutorial_mod/textures/models/armor/`
* **`ice_ether_layer_1.png`**
* **`ice_ether_layer_2.png`**

> 💡 **Как создать текстуру?**  
> Самый простой способ — открыть ванильные файлы `diamond_layer_1.png` и `diamond_layer_2.png` в графическом редакторе (Paint.NET, Photoshop, Aseprite) или программе **Blockbench** в режиме редактирования скина и перекрасить их под цвета вашего мода.

## 6. Настройка DataGen

### 6.1. 2D-модели предметов (`ModItemModelProvider`)
Поскольку в инвентаре части брони выглядят как обычные плоские предметы, для них используется стандартный `basicItem`:

Откройте `ModItemModelProvider.java`:
```java
@Override
protected void registerModels() {
    // Инструменты...
    handheldItem(ModItems.ICE_ETHER_SWORD.get());
    // ...

    // Броня (обычные 2D предметы)
    basicItem(ModItems.ICE_ETHER_HELMET.get());
    basicItem(ModItems.ICE_ETHER_CHESTPLATE.get());
    basicItem(ModItems.ICE_ETHER_LEGGINGS.get());
    basicItem(ModItems.ICE_ETHER_BOOTS.get());
}
```

---

### 6.2. Тег отделки брони (`ItemTags.TRIMMABLE_ARMOR`)
Чтобы нашу броню можно было украшать кузнечными шаблонами отделки (Armor Trims) на кузнечном столе, добавим все 4 предмета в ванильный тег:

Откройте `ModItemTagsProvider.java`:
```java
@Override
protected void addTags(HolderLookup.Provider provider) {
    // Теги инструментов...

    // Разрешаем отделку брони кузнечными шаблонами
    tag(ItemTags.TRIMMABLE_ARMOR)
            .add(ModItems.ICE_ETHER_HELMET.get())
            .add(ModItems.ICE_ETHER_CHESTPLATE.get())
            .add(ModItems.ICE_ETHER_LEGGINGS.get())
            .add(ModItems.ICE_ETHER_BOOTS.get());
}
```

## 7. Подключение реестра в главном классе мода

Не забудьте зарегистрировать `ModArmorMaterials` на шине событий в конструкторе главного класса `TutorialMod.java`:

```java
public TutorialMod(IEventBus modEventBus) {
    ModItems.register(modEventBus);
    ModBlocks.register(modEventBus);
    // ОБЯЗАТЕЛЬНО: Регистрация материалов брони!
    ModArmorMaterials.register(modEventBus);
    ModCreativeModeTabs.register(modEventBus);

    modEventBus.addListener(this::addCreative);
}
```

## 8. Тестирование в игре

1. Запустите генератор данных через **`Run Data`**.
2. Запустите клиент игры (**`Run Client`**).
3. Войдите в одиночный мир и откройте инвентарь творческого режима:
    * Возьмите все 4 элемента брони.
    * **Проверка звуков:** наденьте броню нажатием ПКМ из хотбара — проиграется звонкий звук надевания алмазной брони.
    * **Шкала защиты:** наденьте полный комплект — над индикатором здоровья появится полностью заполненная панель защиты (все 10 щитков-нагрудников).
    * **Вид от третьего лица (`F5`):** убедитесь, что текстуры корректно облегают тело персонажа, ноги правильно двигаются в поножах, а шлем плотно сидит на голове без фиолетово-черных сеток отсутствующих текстур.
    * **Кузнечный стол:** попробуйте применить кузнечный шаблон отделки (например, золотой или аметистовый узор) — узоры гармонично накладываются поверх текстуры эфира!
