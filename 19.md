# Урок 19: Создание сельскохозяйственных культур (Crops) и семян в NeoForge 1.21.1

В Уроке 8 мы зарегистрировали клубнику (`strawberry`) как съедобный предмет, восполняющий голод и дающий ускорение. Однако в режиме выживания игрок должен иметь возможность выращивать еду на собственной ферме.

В этом уроке мы создадим полноценную сельскохозяйственную культуру — **Клубничный куст (`StrawberryCrop`)** и **Семена клубники (`strawberry_seeds`)**:
* Разберем иерархию классов растений в Minecraft: `Block` $\rightarrow$ `BushBlock` $\rightarrow$ `CropBlock`.
* Настроим жизненный цикл растения: **6 стадий роста** (от ростка `age = 0` до спелых ягод `age = 5`).
* Узнаем, почему у растений **нет привычного `BlockItem`**, и как работает специальный класс семян `ItemNameBlockItem`.
* Реализуем поддержку костной муки через интерфейс `BonemealableBlock`.
* Расширим ванильную механику посадки: разрешим сажать клубнику не только на грядки, но и на обычный блок земли/дерна.
* Настроим DataGen: напишем специфическую таблицу лута для культур (незрелый куст дает только 1 семя, а зрелый — ягоды и дополнительные семена с бонусом «Удачи») и сгенерируем модели стадий роста со слоем прозрачности `cutout`.

## 1. Теория: Архитектура растений в Minecraft

### 1.1. Иерархия `BushBlock` и `CropBlock`
Все растения в игре построены на строгой иерархии:
* **`Block`**: базовый блок.
* **`BushBlock`**: кустарники и цветы. Определяет базовую физику: блок не имеет физической коллизии (`noCollission()`), разрушается при падении блоков сверху, а метод `mayPlaceOn` проверяет, может ли растение выжить на блоке под ним.
* **`CropBlock`**: сельскохозяйственные культуры. Добавляет случайные тики роста (`randomTick`), форму хитбокса в зависимости от возраста, определение семян и сбор урожая.
* **`BonemealableBlock`**: интерфейс, позволяющий игроку удобрять растение костной мукой.

---

### 1.2. Стадии роста (`IntegerProperty AGE`)
Возраст культуры хранится в свойстве блокстейта `IntegerProperty`:
* Пшеница, морковь, картофель имеют 8 стадий: `BlockStateProperties.AGE_7` (значения от `0` до `7`).
* Свекла имеет 4 стадии: `BlockStateProperties.AGE_3` (значения от `0` до `3`).
* Для клубники мы создадим собственное свойство на **6 стадий**: `BlockStateProperties.AGE_5` (значения от `0` до `5`).

---

### 1.3. Связка «Блок культуры $\leftrightarrow$ Предмет семян»
Обычные блоки регистрируют для себя `BlockItem`. Однако для культур этот подход **неприменим**:
1. Растение в мире — это сложный куст со стадиями роста (`Block`).
2. В инвентаре у игрока лежит не куст, а **семена** (`Item`).
3. При нажатии ПКМ семенами по грядке игра должна посадить куст с начальным возрастом `age = 0`.
4. Для этого используется ванильный класс **`ItemNameBlockItem`** (наследник `BlockItem`), который связывает предмет семян с блоком культуры, но отображается со своей уникальной иконкой и именем.

## 2. Создание класса растения `StrawberryCrop`

В пакете `com.besson.tutorial.block.custom` создайте класс `StrawberryCrop.java`.

```java
package com.besson.tutorial.block.custom;

import com.besson.tutorial.item.ModItems;
import com.mojang.serialization.MapCodec;
import net.minecraft.core.BlockPos;
import net.minecraft.tags.BlockTags;
import net.minecraft.world.level.BlockGetter;
import net.minecraft.world.level.ItemLike;
import net.minecraft.world.level.block.Block;
import net.minecraft.world.level.block.CropBlock;
import net.minecraft.world.level.block.state.BlockState;
import net.minecraft.world.level.block.state.StateDefinition;
import net.minecraft.world.level.block.state.properties.BlockStateProperties;
import net.minecraft.world.level.block.state.properties.IntegerProperty;

public class StrawberryCrop extends CropBlock {

    // 1. Обязательный кодек блока для Minecraft 1.21+
    public static final MapCodec<StrawberryCrop> CODEC = simpleCodec(StrawberryCrop::new);

    // 2. Максимальная стадия роста (0, 1, 2, 3, 4, 5 — всего 6 стадий)
    public static final int MAX_AGE = 5;
    public static final IntegerProperty AGE = BlockStateProperties.AGE_5;

    public StrawberryCrop(Properties properties) {
        super(properties);
    }

    @Override
    protected MapCodec<? extends CropBlock> codec() {
        return CODEC;
    }

    // Возвращает свойство возраста для блокстейта
    @Override
    public IntegerProperty getAgeProperty() {
        return AGE;
    }

    // Возвращает максимальный возраст спелости
    @Override
    public int getMaxAge() {
        return MAX_AGE;
    }

    // Возвращает предмет семян, привязанных к этой культуре
    @Override
    protected ItemLike getBaseSeedId() {
        return ModItems.STRAWBERRY_SEEDS.get();
    }

    // Регистрация свойства AGE в определении блокстейта
    @Override
    protected void createBlockStateDefinition(StateDefinition.Builder<Block, BlockState> builder) {
        builder.add(AGE);
    }

    /**
     * Проверка блоков, на которые можно посадить клубнику.
     * По умолчанию CropBlock разрешает только Farmland (грядку).
     * Мы разрешим посадку как на пашню, так и на обычный дерн/землю!
     */
    @Override
    protected boolean mayPlaceOn(BlockState state, BlockGetter level, BlockPos pos) {
        return super.mayPlaceOn(state, level, pos) || state.is(BlockTags.DIRT);
    }
}
```

## 3. Регистрация блока культуры и семян

### 3.1. Регистрация `STRAWBERRY_CROP` в `ModBlocks`
Откройте `ModBlocks.java`.

> ⚠️ **Критически важно:**  
> Регистрируйте `STRAWBERRY_CROP` через прямой вызов `BLOCKS.register(...)`, а **НЕ** через наш вспомогательный метод `registerBlock(...)`! Для блока культуры нельзя создавать автоматический `BlockItem`, иначе произойдет конфликт с семенами.

```java
// Блок культуры клубники (свойства копируются с ванильной пшеницы)
public static final DeferredBlock<StrawberryCrop> STRAWBERRY_CROP = BLOCKS.register(
        "strawberry_crop",
        () -> new StrawberryCrop(BlockBehaviour.Properties.ofFullCopy(Blocks.WHEAT)
                .noCollission()
                .noOcclusion())
);
```

---

### 3.2. Регистрация `STRAWBERRY_SEEDS` в `ModItems`
Откройте `ModItems.java`. Зарегистрируйте семена как экземпляр **`ItemNameBlockItem`**, передав ему блок `STRAWBERRY_CROP`:

```java
// ================= СЕМЕНА И РАСТЕНИЯ =================
public static final DeferredItem<Item> STRAWBERRY_SEEDS = ITEMS.register(
        "strawberry_seeds",
        () -> new ItemNameBlockItem(ModBlocks.STRAWBERRY_CROP.get(), new Item.Properties())
);
```

## 5. Настройка DataGen

### 5.1. Таблица лута с проверкой спелости (`ModBlockLootTablesProvider`)

Логика выпадения лута с растений требует строгого условия:
1. Если куст **не дозрел** (`age < 5`) $\rightarrow$ выпадает только **1 семя**.
2. Если куст **полностью созрел** (`age == 5`) $\rightarrow$ выпадает **клубника (ягода)** плюс семена с учетом зачарования «Удача».

Для этого в `BlockLootSubProvider` есть метод `createCropDrops(...)`:

Откройте `ModBlockLootTablesProvider.java`:

```java
package com.besson.tutorial.datagen;

import com.besson.tutorial.block.ModBlocks;
import com.besson.tutorial.block.custom.StrawberryCrop;
import com.besson.tutorial.item.ModItems;
import net.minecraft.advancements.critereon.StatePropertiesPredicate;
import net.minecraft.world.level.storage.loot.predicates.LootItemBlockStatePropertyCondition;
import net.minecraft.world.level.storage.loot.predicates.LootItemCondition;

public class ModBlockLootTablesProvider extends BlockLootSubProvider {

    @Override
    protected void generate() {
        // ... другие блоки ...

        // Условие максимальной спелости (AGE == 5)
        LootItemCondition.Builder isMatureCrop = LootItemBlockStatePropertyCondition
                .hasBlockStateProperties(ModBlocks.STRAWBERRY_CROP.get())
                .setProperties(StatePropertiesPredicate.Builder.properties()
                        .hasProperty(StrawberryCrop.AGE, StrawberryCrop.MAX_AGE));

        // Регистрация лута культуры
        add(ModBlocks.STRAWBERRY_CROP.get(), createCropDrops(
                ModBlocks.STRAWBERRY_CROP.get(),     // Сам блок культуры
                ModItems.STRAWBERRY.get(),           // Предмет урожая (ягода)
                ModItems.STRAWBERRY_SEEDS.get(),     // Предмет семян
                isMatureCrop                         // Условие спелости
        ));
    }
}
```

### 5.2. Генерация blockstates и моделей 6 стадий (`ModBlockStateProvider`)

Каждая стадия роста должна ссылаться на собственную текстуру.

Откройте `ModBlockStateProvider.java` и добавьте вспомогательный метод генерации моделей культур:

```java
package com.besson.tutorial.datagen;

import com.besson.tutorial.block.ModBlocks;
import com.besson.tutorial.block.custom.StrawberryCrop;
import net.minecraft.world.level.block.CropBlock;
import net.minecraft.world.level.block.state.properties.IntegerProperty;
import net.neoforged.neoforge.client.model.generators.ConfiguredModel;
import net.neoforged.neoforge.client.model.generators.ModelFile;

public class ModBlockStateProvider extends BlockStateProvider {

    @Override
    protected void registerStatesAndModels() {
        // ... другие блоки ...

        // Генерация состояний и 6 моделей культуры клубники
        makeCrop((CropBlock) ModBlocks.STRAWBERRY_CROP.get(), "strawberry_crop_stage", "strawberry_crop_stage");
    }

    /**
     * Универсальный метод для генерации моделей всех стадий культуры
     */
    public void makeCrop(CropBlock block, String modelName, String textureName) {
        IntegerProperty ageProperty = block.getAgeProperty();

        getVariantBuilder(block).forAllStates(state -> {
            int age = state.getValue(ageProperty);

            // Создаем модель со слоем рендеринга cutout (прозрачные пиксели)
            ModelFile model = models().crop(modelName + age, modLoc("block/" + textureName + age))
                    .renderType("cutout");

            return ConfiguredModel.builder().modelFile(model).build();
        });
    }
}
```

## 6. Тестирование на грядке

1. Сгенерируйте данные через конфигурацию запуска **`Run Data`**.  
   Убедитесь, что в `blockstates` и `models/block` появились все 6 файлов стадий `stage0`..`stage5`.
2. Запустите клиент игры (**`Run Client`**).
3. Войдите в мир, переключитесь в режим выживания (`/gamemode survival`).
4. Возьмите мотыгу, семена клубники (`Strawberry Seeds`) и костную муку (`Bone Meal`).
5. **Тест посадки:**
    * Вспашите землю мотыгой рядом с водой $\rightarrow$ посадите семена на пашню.
    * Попробуйте посадить семена на обычный дерн рядом с грядкой $\rightarrow$ благодаря переопределенному `mayPlaceOn` клубника успешно сажается и на дерн!
6. **Тест роста и костной муки:**
    * Кликните костной мукой по ростку: куст плавно проходит стадии развития, увеличиваясь в размерах и покрываясь красными ягодами.
7. **Тест выпадения лута:**
    * Разрушьте **молодой росток** (стадия 1–2): выпадает ровно **1 семя**, ягоды не дропаются.
    * Вырастите куст до **финальной стадии 5** и сломайте его: выпадает спелая съедобная **клубника** и от **1 до 3 семян** для повторного засева!
