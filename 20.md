# Урок 20: Двухблочные культуры и сбор урожая по ПКМ (Corn / Мультиблочные растения) в NeoForge 1.21.1

В Уроке 19 мы создали одноблочную культуру клубники (`StrawberryCrop`). Однако в реальном мире и во многих агрокультурных модах (таких как *Farmer's Delight*) многие растения вырастают выше человеческого роста — например, **кукуруза (Corn)**, сахарный тростник или подсолнух.

В этом уроке мы создадим полноценную **двухблочную сельскохозяйственную культуру — Кукурузу (`CornCrop`)**:
* Разберем механику многоблочного роста: нижний стебель растет от стадии `0` до `7`, а при созревании выпускает верхний побег `stage 8` на блок выше (`pos.above()`).
* Реализуем строгие физические проверки выживания растения (`canSurvive`): верхний блок не может существовать без нижнего, а разрушение основания автоматически ломает верхушку.
* Добавим популярную механику современных модов — **сбор урожая нажатием ПКМ (`useWithoutItem`)**: при правом клике по спелому кусту выпадают кукуруза и опыт, а растение автоматически сбрасывается на начальную стадию без необходимости повторно вспахивать землю и сажать семена.
* Настроим логику удобрения костной мукой (`BonemealableBlock`), таблицы лута и автогенерацию 9 стадий моделей через **DataGen**.

## 1. Теория: Как устроены двухблочные культуры в Minecraft

### 1.1. Разделение стадий: нижний блок против верхнего
Стандартный класс `CropBlock` рассчитан на растение высотой в 1 блок. Чтобы культура заняла 2 блока по вертикали:
1. Задается свойство возраста от `0` до `8` (всего 9 стадий):
    * **Стадии 0–7:** растение растет в нижнем блоке (на пашне).
    * **Стадия 8:** когда нижний блок достигает возраста `7`, игра проверяет блок над ним (`pos.above()`). Если сверху воздух, там устанавливается второй блок кукурузы со стадией `8`.
2. Если нижний блок ломается, верхний блок мгновенно теряет опору и разрушается.

---

### 1.2. Механика сбора урожая по ПКМ
В ванильном Minecraft, чтобы собрать пшеницу или морковь, игрок вынужден сломать блок рукой и заново посадить семя.

Метод `useWithoutItem` (срабатывающий при клике пустой рукой по блоку) позволяет реализовать «умный сбор»:
* Проверяется максимальный возраст куста;
* Выпадение плодов кукурузы через `popResource`;
* Выпадение небольшого количества сфер опыта через `popExperience`;
* Верхний блок удаляется, а нижний откатывается на стадию `0` (или `FIRST_STAGE_AGE - 1`), продолжая расти дальше.

## 2. Создание класса двухблочной культуры `CornCrop`

В пакете `com.besson.tutorial.block.custom` создайте класс `CornCrop.java`.

```java
package com.besson.tutorial.block.custom;

import com.besson.tutorial.item.ModItems;
import com.mojang.serialization.MapCodec;
import net.minecraft.core.BlockPos;
import net.minecraft.server.level.ServerLevel;
import net.minecraft.util.RandomSource;
import net.minecraft.world.InteractionResult;
import net.minecraft.world.entity.player.Player;
import net.minecraft.world.item.ItemStack;
import net.minecraft.world.level.BlockGetter;
import net.minecraft.world.level.ItemLike;
import net.minecraft.world.level.Level;
import net.minecraft.world.level.LevelReader;
import net.minecraft.world.level.block.Block;
import net.minecraft.world.level.block.CropBlock;
import net.minecraft.world.level.block.state.BlockState;
import net.minecraft.world.level.block.state.StateDefinition;
import net.minecraft.world.level.block.state.properties.IntegerProperty;
import net.minecraft.world.phys.BlockHitResult;
import net.minecraft.world.phys.shapes.CollisionContext;
import net.minecraft.world.phys.shapes.VoxelShape;

public class CornCrop extends CropBlock {

    public static final MapCodec<CornCrop> CODEC = simpleCodec(CornCrop::new);

    // Нижняя часть имеет 8 стадий (0..7), верхняя часть — стадию 8
    public static final int FIRST_STAGE_AGE = 7;
    public static final int SECOND_STAGE_AGE = 1;
    public static final IntegerProperty AGE = IntegerProperty.create("age", 0, 8);

    // Хитбоксы для каждой из 9 стадий развития
    private static final VoxelShape[] SHAPE_BY_AGE = new VoxelShape[]{
            Block.box(0.0, 0.0, 0.0, 16.0, 2.0, 16.0),
            Block.box(0.0, 0.0, 0.0, 16.0, 4.0, 16.0),
            Block.box(0.0, 0.0, 0.0, 16.0, 6.0, 16.0),
            Block.box(0.0, 0.0, 0.0, 16.0, 8.0, 16.0),
            Block.box(0.0, 0.0, 0.0, 16.0, 10.0, 16.0),
            Block.box(0.0, 0.0, 0.0, 16.0, 12.0, 16.0),
            Block.box(0.0, 0.0, 0.0, 16.0, 14.0, 16.0),
            Block.box(0.0, 0.0, 0.0, 16.0, 16.0, 16.0),
            Block.box(0.0, 0.0, 0.0, 16.0, 8.0, 16.0) // Верхний блок
    };

    public CornCrop(Properties properties) {
        super(properties);
    }

    @Override
    protected MapCodec<? extends CropBlock> codec() {
        return CODEC;
    }

    @Override
    public VoxelShape getShape(BlockState state, BlockGetter level, BlockPos pos, CollisionContext context) {
        return SHAPE_BY_AGE[this.getAge(state)];
    }

    @Override
    public IntegerProperty getAgeProperty() {
        return AGE;
    }

    @Override
    public int getMaxAge() {
        return FIRST_STAGE_AGE + SECOND_STAGE_AGE; // 8
    }

    @Override
    protected ItemLike getBaseSeedId() {
        return ModItems.CORN_SEEDS.get();
    }

    @Override
    protected void createBlockStateDefinition(StateDefinition.Builder<Block, BlockState> builder) {
        builder.add(AGE);
    }
```

### 2.2. Проверка условий существования (`canSurvive`)

Добавим логику привязки верхнего блока к нижнему:

```java
    /**
     * Проверка выживания блока в мире
     */
    @Override
    public boolean canSurvive(BlockState state, LevelReader level, BlockPos pos) {
        // Если это нижний блок (или обычная посадка) — проверяем стандартное выживание на грядке
        // Если это верхний блок — снизу ОБЯЗАН находиться стебель кукурузы с возрастом не ниже FIRST_STAGE_AGE
        return super.canSurvive(state, level, pos) || (level.getBlockState(pos.below()).is(this)
                && level.getBlockState(pos.below()).getValue(AGE) >= FIRST_STAGE_AGE);
    }
```

### 2.3. Алгоритм роста и появление верхнего блока (`randomTick`)

В каждом случайном тике игра ускоряет рост растения:

```java
    @Override
    public void randomTick(BlockState state, ServerLevel level, BlockPos pos, RandomSource random) {
        if (level.getRawBrightness(pos, 0) >= 9) {
            int currentAge = this.getAge(state);

            if (currentAge < this.getMaxAge()) {
                float growthSpeed = getGrowthSpeed(this, level, pos);

                if (random.nextInt((int)(25.0F / growthSpeed) + 1) == 0) {
                    // Если нижняя часть созрела до стадии 7, проверяем пространство сверху
                    if (currentAge == FIRST_STAGE_AGE) {
                        if (level.getBlockState(pos.above()).isAir()) {
                            // Спавним верхний блок со стадией 8
                            level.setBlock(pos.above(), this.getStateForAge(currentAge + 1), 3);
                        }
                    } else {
                        // Обычный рост нижнего стебля
                        level.setBlock(pos, this.getStateForAge(currentAge + 1), 3);
                    }
                }
            }
        }
    }
```

### 2.4. Логика костной муки (`growCrops`)

При использовании костной муки рост также должен корректно переходить на второй ярус:

```java
    @Override
    public void growCrops(Level level, BlockPos pos, BlockState state) {
        int nextAge = this.getAge(state) + this.getBonemealAgeIncrease(level);
        int maxAge = this.getMaxAge();

        if (nextAge > maxAge) {
            nextAge = maxAge;
        }

        // Если растение перерастает первый ярус
        if (this.getAge(state) == FIRST_STAGE_AGE && level.getBlockState(pos.above()).isAir()) {
            level.setBlock(pos.above(), this.getStateForAge(nextAge), 3);
        } else {
            level.setBlock(pos, this.getStateForAge(nextAge - 1), 3);
        }
    }
```

### 2.5. Сбор урожая по ПКМ (`useWithoutItem`)

Переопределим метод взаимодействия пустой рукой:

```java
    @Override
    protected InteractionResult useWithoutItem(BlockState state, Level level, BlockPos pos, Player player, BlockHitResult hitResult) {
        if (!level.isClientSide()) {
            // Если растение созрело до максимальной стадии (AGE == 8)
            if (this.getAge(state) == this.getMaxAge()) {
                // Определяем, по какому именно блоку кликнул игрок:
                // Если кликнули по верхнему блоку:
                BlockPos cropBottomPos = level.getBlockState(pos.below()).is(this) ? pos.below() : pos;
                BlockPos cropTopPos = cropBottomPos.above();

                // 1. Выбиваем спелую кукурузу
                popResource(level, pos, new ItemStack(ModItems.CORN.get(), 1));

                // 2. Дропаем опыт (1-2 единицы)
                popExperience((ServerLevel) level, pos, 1);

                // 3. Удаляем верхний блок
                if (level.getBlockState(cropTopPos).is(this)) {
                    level.removeBlock(cropTopPos, false);
                }

                // 4. Сбрасываем нижний блок на начальную стадию
                level.setBlock(cropBottomPos, this.getStateForAge(0), 3);

                return InteractionResult.SUCCESS;
            }
        }

        return super.useWithoutItem(state, level, pos, player, hitResult);
    }
}
```

## 6. Тестирование на грядке

1. Запустите генерацию данных через **`Run Data`**.  
   Убедитесь, что для `corn_crop` успешно сгенерировались файлы блокстейта и 9 моделей стадий.
2. Запустите клиент игры (**`Run Client`**).
3. Войдите в мир, переключитесь в режим выживания (`/gamemode survival`).
4. Возьмите **Семена кукурузы (`Corn Seeds`)** и **Костную муку**.
5. **Тест вертикального роста:**
    * Посадите кукурузу на пашню.
    * Применяйте костную муку: стебель подрастет до стадии 7, а при следующем клике над ним появится второй ярус (стадия 8 с желтыми початками).
6. **Тест физики опоры:**
    * Сломайте нижний блок: верхний ярус не повиснет в воздухе, а немедленно разрушится.
7. **Тест сбора урожая по ПКМ:**
    * Вырастите кукурузу до стадии 8.
    * Кликните **ПКМ пустой рукой** по стеблю:
        * В инвентарь (или на землю) выпадет спелый початок кукурузы;
        * Вылетят сферы опыта;
        * Верхний блок исчезнет, а нижний куст сбросится на стадию 0, будучи готовым расти снова!
