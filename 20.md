# Урок 20: Добавление пользовательских сделок жителям (Villager Trades) в NeoForge 1.21.1

В Уроке 19 мы вырастили урожай клубники, а в Уроке 17 выковали комплект эфирной брони. Теперь мы интегрируем созданные предметы в экономику деревень Minecraft, настроив **торговые сделки с деревенскими жителями (Villager Trades)** и **странствующим торговцем (Wandering Trader)**.

Начиная с версий Minecraft **1.20.5+ и 1.21.1**, внутренняя структура сделок претерпела изменения:
* Вместо сырых предметов `ItemStack` для покупки теперь используется специализированный класс-обертка **`ItemCost`**.
* Добавлена строгая типизация второй валюты через `Optional<ItemCost>`.
* Подключение кастомных сделок осуществляется через шину игровых событий с помощью событий **`VillagerTradesEvent`** и **`WandererTradesEvent`**.

## 1. Теория: Архитектура торговли жителей в 1.21+

### 1.1. Профессии и 5 уровней мастерства жителя
Профессия жителя определяется его рабочим местом (компостер $\rightarrow$ Фермер, плавильня $\rightarrow$ Бронник, точило $\rightarrow$ Оружейник).

Каждый житель повышает свой уровень мастерства по мере совершения сделок:
* **Уровень 1 (Новичок / Novice):** каменный бейдж.
* **Уровень 2 (Подмастерье / Apprentice):** железный бейдж.
* **Уровень 3 (Ремесленник / Journeyman):** золотой бейдж.
* **Уровень 4 (Эксперт / Expert):** изумрудный бейдж.
* **Уровень 5 (Мастер / Master):** алмазный бейдж.

Список сделок на каждом уровне представляет собой список фабрик `List<VillagerTrades.ItemListing>`, хранящихся в оптимизированной карте `Int2ObjectMap<List<ItemListing>>`.

---

### 1.2. Анатомия сделки: `MerchantOffer` и новый класс `ItemCost`
В Minecraft 1.21+ сделка описывается объектом `MerchantOffer`:

```java
new MerchantOffer(
    ItemCost buyCost,             // Основная цена покупки (что отдаёт игрок)
    Optional<ItemCost> secondCost,// Дополнительная цена (например, изумруды + компас)
    ItemStack result,             // Товар (что получает игрок)
    int maxUses,                  // Сколько раз сделку можно совершить до блокировки
    int villagerXp,               // Опыт, получаемый жителем за одну транзакцию
    float priceMultiplier         // Множитель скидок/наценок (репутация, эффект «Герой деревни»)
)
```

> 💡 **Что такое `ItemCost`:**  
> Ранее в конструктор сделки передавался обычный `ItemStack`. В 1.20.5+ Mojang ввели `ItemCost(ItemLike item, int count)` для разделения логики инвентаря и правил расчета коммерческой стоимости товаров.

---

### 1.3. Параметры: опыт жителя, лимит сделок и множитель скидки
1. **`maxUses` (Лимит сделок):** обычно от `4` (для ценной брони/инструментов) до `16` (для массовых ресурсов вроде ягод или пшеницы). После исчерпания лимита сделка блокируется крестиком, пока житель не поработает за своим станком.
2. **`villagerXp` (Опыт жителя):**
    * Уровень 1: `1`–`2` опыта.
    * Уровень 2: `5` опыта.
    * Уровень 3: `10` опыта.
    * Уровень 4–5: `15`–`30` опыта.
3. **`priceMultiplier` (Множитель цены):**
    * Для дешевых ресурсов (ягоды, дерево): `0.05f` (скидка снижает цену незначительно).
    * Для дорогого снаряжения (броня, инструменты): `0.2f` (скидка за излечение зомби-жителя может сбросить цену в разы).

## 2. Создание класса торговых сделок (`ModCustomTrades`)

1. В пакете вашего мода создайте подпакет `trade` (например, `com.besson.tutorial.trade`).
2. Внутри создайте класс `ModCustomTrades.java`.

Событие `VillagerTradesEvent` срабатывает на общей игровой шине NeoForge в момент инициализации пулов торговли:

```java
package com.besson.tutorial.trade;

import com.besson.tutorial.TutorialMod;
import com.besson.tutorial.item.ModItems;
import it.unimi.dsi.fastutil.ints.Int2ObjectMap;
import net.minecraft.world.entity.npc.VillagerProfession;
import net.minecraft.world.entity.npc.VillagerTrades;
import net.minecraft.world.item.ItemStack;
import net.minecraft.world.item.Items;
import net.minecraft.world.item.trading.ItemCost;
import net.minecraft.world.item.trading.MerchantOffer;
import net.neoforged.bus.api.SubscribeEvent;
import net.neoforged.fml.common.EventBusSubscriber;
import net.neoforged.neoforge.event.village.VillagerTradesEvent;

import java.util.List;
import java.util.Optional;

@EventBusSubscriber(modid = TutorialMod.MOD_ID)
public class ModCustomTrades {

    @SubscribeEvent
    public static void addCustomTrades(VillagerTradesEvent event) {

        // ================= 1. СДЕЛКИ С ФЕРМЕРОМ (FARMER) =================
        if (event.getType() == VillagerProfession.FARMER) {
            Int2ObjectMap<List<VillagerTrades.ItemListing>> trades = event.getTrades();

            // Уровень 1 (Новичок): Игрок покупает 15 ягод клубники за 2 изумруда
            trades.get(1).add((trader, random) -> new MerchantOffer(
                    new ItemCost(Items.EMERALD, 2),
                    new ItemStack(ModItems.STRAWBERRY.get(), 15),
                    16,   // maxUses: можно купить 16 раз
                    2,    // villagerXp: дает 2 опыта жителю
                    0.05f // priceMultiplier
            ));

            // Уровень 2 (Подмастерье): Фермер скупает выращенную клубнику (15 шт) за 5 изумрудов
            trades.get(2).add((trader, random) -> new MerchantOffer(
                    new ItemCost(ModItems.STRAWBERRY.get(), 15),
                    new ItemStack(Items.EMERALD, 5),
                    10,
                    5,
                    0.05f
            ));
        }

        // ================= 2. СДЕЛКИ С БРОННИКОМ (ARMORER) =================
        if (event.getType() == VillagerProfession.ARMORER) {
            Int2ObjectMap<List<VillagerTrades.ItemListing>> trades = event.getTrades();

            // Уровень 2 (Подмастерье): Продажа шлема из ледяного эфира за 10 изумрудов
            trades.get(2).add((trader, random) -> new MerchantOffer(
                    new ItemCost(Items.EMERALD, 10),
                    new ItemStack(ModItems.ICE_ETHER_HELMET.get(), 1),
                    4,    // редкая сделка, всего 4 раза до блокировки
                    12,   // дает много опыта (12)
                    0.2f  // высокая чувствительность к репутации
            ));

            // Пример сделки с двумя входящими предметами: 15 сырого эфира + 5 изумрудов -> Нагрудник
            trades.get(3).add((trader, random) -> new MerchantOffer(
                    new ItemCost(Items.EMERALD, 5),
                    Optional.of(new ItemCost(ModItems.RAW_ICE_ETHER.get(), 15)),
                    new ItemStack(ModItems.ICE_ETHER_CHESTPLATE.get(), 1),
                    3,
                    20,
                    0.2f
            ));
        }
    }
}
```

## 3. Сделки со Странствующим торговцем (`WandererTradesEvent`)

Странствующий торговец (`Wandering Trader`) не имеет уровней прокачки. Его сделки делятся на две категории:
* **Обычные (`generic`):** саженцы, красители, семена.
* **Редкие (`rare`):** ведра с тропическими рыбами, плотный лед, порох.

Добавим продажу семян клубники и геологоразведчика в класс `ModCustomTrades.java`:

```java
import net.neoforged.neoforge.event.village.WandererTradesEvent;

// Добавьте этот метод в класс ModCustomTrades:
@SubscribeEvent
public static void addWanderingTrades(WandererTradesEvent event) {
    // 1. Обычные товары: 1 изумруд -> 3 семени клубники
    event.getGenericTrades().add((trader, random) -> new MerchantOffer(
            new ItemCost(Items.EMERALD, 1),
            new ItemStack(ModItems.STRAWBERRY_SEEDS.get(), 3),
            8,
            1,
            0.05f
    ));

    // 2. Редкие товары: 15 изумрудов -> Геологоразведчик (Prospector)
    event.getRareTrades().add((trader, random) -> new MerchantOffer(
            new ItemCost(Items.EMERALD, 15),
            new ItemStack(ModItems.PROSPECTOR.get(), 1),
            1,    // одноразовая покупка
            5,
            0.2f
    ));
}
```

## 4. Подключение слушателя к шине событий

Обратите внимание на аннотацию над классом:
```java
@EventBusSubscriber(modid = TutorialMod.MOD_ID)
```
По умолчанию (без указания `bus = Bus.MOD`) эта аннотация автоматически подписывает методы класса на **основную игровую шину событий (`NeoForge.EVENT_BUS`)**. Дополнительных вызовов в главном классе `TutorialMod.java` прописывать не требуется!

## 5. Тестирование в игре

1. Запустите клиент игры (**`Run Client`**).
2. Создайте или откройте тестовый мир.
3. Возьмите из творческого инвентаря:
    * **Яйцо призыва жителя (Villager Spawn Egg)**;
    * **Компостер (Composter)**;
    * **Плавильню (Blast Furnace)**;
    * Стак **изумрудов (Emerald)** и стак **клубники (Strawberry)**.

---

### Тест 1: Торговля с Фермером
1. Поставьте **Компостер** и заспавните рядом жителя.
2. Житель наденет соломенную шляпу и станет **Фермером (Новичок)**.
3. Откройте интерфейс торговли (ПКМ по жителю):
    * Среди стандартных предложений (хлеб, пшеница) появится ваша сделка: **2 изумруда $\rightarrow$ 15 клубники**.
4. Купите клубнику несколько раз: шкала опыта жителя заполнится, вокруг него появятся фиолетовые искры повышения уровня, и он станет **Подмастерьем**.
5. Прокрутите список сделок: на 2-м уровне открылась обратная сделка: **15 клубники $\rightarrow$ 5 изумрудов**!

---

### Тест 2: Торговля с Бронником
1. Поставьте рядом **Плавильню** и заспавните второго жителя.
2. Житель наденет защитную маску сварщика и превратится в **Бронника**.
3. Прокачайте его до 2-го уровня с помощью ванильного железа/угля.
4. На уровне «Подмастерье» появится сделка: **10 изумрудов $\rightarrow$ Шлем из ледяного эфира (`Ice Ether Helmet`)**!
5. На 3-м уровне появится комбинированная сделка: **5 изумрудов + 15 сырого эфира $\rightarrow$ Нагрудник**.

---

### Тест 3: Механика динамического изменения цен (Скидки и Наценки)
* **Наценка:** Ударьте жителя мечом — его репутация упадет, а вокруг пойдут грозовые тучки. Откройте торговлю: цены на шлем и клубнику вырастут (например, с 10 до 12–15 изумрудов).
* **Скидка:** Наложите на себя эффект «Герой деревни» (`/effect give @p hero_of_the_village`) или излечите зомби-жителя — цены снизятся благодаря множителю `priceMultiplier`.
