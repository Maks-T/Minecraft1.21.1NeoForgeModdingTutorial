# Урок 22: Создание новой профессии жителя и точки интереса (POI) в NeoForge 1.21.1

В Уроке 21 мы научились внедрять свои товары в сделки ванильных жителей (Фермера и Бронника). В этом уроке мы сделаем следующий шаг и создадим **абсолютно новую, уникальную профессию деревенского жителя — Мастер ледяного эфира (`Ice Ether Master`)**:
* Разберем концепцию **Точки интереса (Point of Interest / POI)** в искусственном интеллекте жителей Minecraft.
* Превратим наш собственный блок (`Ice Ether Block`) в полноценное рабочее место.
* Зарегистрируем новую профессию `VillagerProfession` с привязкой к нашему POI.
* Настроим тег `PoiTypeTags.ACQUIRABLE_JOB_SITE` через DataGen, чтобы жители могли находить новый рабочий станок.
* Нарисуем текстуру специальной рабочей одежды (скин-оверлей профессии).
* Наполним новую профессию многоуровневыми сделками (продажа сырого эфира, покупка кристаллов и приобретение редкого гибридного киркотопора).

## 1. Теория: Как ИИ жителей связывается с блоками через POI

### 1.1. Что такое `PoiType` (Point of Interest)
В движке Minecraft жители не сканируют окружающие блоки напрямую. Вместо этого игровой мир кэширует координаты важных объектов в виде **Точек интереса (Point of Interest / POI)**:
* Кровати (`home` — место для сна);
* Колокола (`meeting` — место сбора жителей в полдень);
* Ульи (`bee_nest` / `beehive` — для пчел);
* **Рабочие места** (компостер, кафедра, бочка, плавильня и т.д.).

Чтобы блок стал рабочим местом, для него создается экземпляр `PoiType`:
```java
new PoiType(
    Set<BlockState> matchingStates, // Все состояния блока (ориентация, варианты)
    int maxTickets,                 // Сколько жителей могут занять один блок (обычно 1)
    int validRange                  // Радиус поиска (обычно 1)
)
```

---

### 1.2. Ванильный тег доступных рабочих мест (`acquirable_job_site`)
Даже если вы зарегистрируете `PoiType`, жители **не будут** подходить к блоку и устраиваться на работу.

Игра требует, чтобы идентификатор вашего POI входил в обязательный ванильный тег:
`#minecraft:acquirable_job_site` (`data/minecraft/tags/point_of_interest_type/acquirable_job_site.json`).

Мы сгенерируем этот тег автоматически через DataGen.

---

### 1.3. Архитектура класса `VillagerProfession`
Профессия жителя `VillagerProfession` описывает:
1. Строковый ID профессии (`"ice_ether_master"`).
2. Предикат доступного рабочего места (`Predicate<Holder<PoiType>> heldJobSite`).
3. Предикат доступного места для трудоустройства (`acquirableJobSite`).
4. Вторичные точки интереса (`secondaryJobSites` — например, для фермера это грядки).
5. Памятные предметы (`memorableItems` — предметы, которые житель стремится собирать в свой инвентарь).
6. Звуковой эффект работы (`SoundEvent` — звук, проигрываемый жителем, когда он работает за станком).

## 2. Создание класса `ModVillagers` (Регистрация POI и Профессии)

1. В пакете вашего мода создайте подпакет `villager` (например, `com.besson.tutorial.villager`).
2. Создайте класс `ModVillagers.java`:

```java
package com.besson.tutorial.villager;

import com.besson.tutorial.TutorialMod;
import com.besson.tutorial.block.ModBlocks;
import com.google.common.collect.ImmutableSet;
import net.minecraft.core.Holder;
import net.minecraft.core.registries.Registries;
import net.minecraft.sounds.SoundEvents;
import net.minecraft.world.entity.ai.village.poi.PoiType;
import net.minecraft.world.entity.npc.VillagerProfession;
import net.neoforged.bus.api.IEventBus;
import net.neoforged.neoforge.registries.DeferredHolder;
import net.neoforged.neoforge.registries.DeferredRegister;

public class ModVillagers {

    // 1. Реестр точек интереса (POI)
    public static final DeferredRegister<PoiType> POI_TYPES =
            DeferredRegister.create(Registries.POINT_OF_INTEREST_TYPE, TutorialMod.MOD_ID);

    // 2. Реестр профессий жителей
    public static final DeferredRegister<VillagerProfession> VILLAGER_PROFESSIONS =
            DeferredRegister.create(Registries.VILLAGER_PROFESSION, TutorialMod.MOD_ID);

    // ================= РЕГИСТРАЦИЯ POI =================
    // В качестве рабочего места используем Блок ледяного эфира (ICE_ETHER_BLOCK)
    public static final DeferredHolder<PoiType, PoiType> ICE_ETHER_POI = POI_TYPES.register(
            "ice_ether_poi",
            () -> new PoiType(
                    // Передаем все возможные состояния нашего блока
                    ImmutableSet.copyOf(ModBlocks.ICE_ETHER_BLOCK.get().getStateDefinition().getPossibleStates()),
                    1, // maxTickets: только 1 житель на один рабочий блок
                    1  // validRange
            )
    );

    // ================= РЕГИСТРАЦИЯ ПРОФЕССИИ =================
    public static final DeferredHolder<VillagerProfession, VillagerProfession> ICE_ETHER_MASTER = VILLAGER_PROFESSIONS.register(
            "ice_ether_master",
            () -> new VillagerProfession(
                    "ice_ether_master",
                    // Проверяем, что рабочее место жителя совпадает с нашим POI
                    holder -> holder.is(ICE_ETHER_POI.getKey()),
                    holder -> holder.is(ICE_ETHER_POI.getKey()),
                    ImmutableSet.of(), // Вторичные блоки отсутствуют
                    ImmutableSet.of(), // Запоминаемые предметы отсутствуют
                    SoundEvents.VILLAGER_WORK_ARMORER // Звук работы (звон металла/брони)
            )
    );

    // Метод подключения к шине событий мода
    public static void register(IEventBus eventBus) {
        POI_TYPES.register(eventBus);
        VILLAGER_PROFESSIONS.register(eventBus);
    }
}
```

### 2.3. Подключение к главной шине мода в `TutorialMod`
Откройте главный класс вашего мода `TutorialMod.java` и добавьте вызов регистрации `ModVillagers` в конструктор:

## 3. Настройка торговых сделок новой профессии (`ModCustomTrades`)

Откройте класс `ModCustomTrades.java`, созданный в Уроке 21. Добавьте блок обработки сделок для нашей профессии `ICE_ETHER_MASTER`:

```java
package com.besson.tutorial.trade;

import com.besson.tutorial.TutorialMod;
import com.besson.tutorial.item.ModItems;
import com.besson.tutorial.villager.ModVillagers;
import it.unimi.dsi.fastutil.ints.Int2ObjectMap;
import net.minecraft.world.entity.npc.VillagerProfession;
import net.minecraft.world.entity.npc.VillagerTrades;
import net.minecraft.world.item.ItemStack;
import net.minecraft.world.item.Items;
import net.minecraft.world.item.trading.ItemCost;
import net.minecraft.world.item.trading.MerchantOffer;
import net.neoforged.bus.api.SubscribeEvent;
import net.neoforged.fml.common.EventBusSubscriber;
import net.neoforged.neoforge.event.village.VillagerTradesEvent;

import java.util.List;

@EventBusSubscriber(modid = TutorialMod.MOD_ID)
public class ModCustomTrades {

    @SubscribeEvent
    public static void addCustomTrades(VillagerTradesEvent event) {

        // ... Сделки фермера и бронника из Урока 21 ...

        // ================= СДЕЛКИ МАСТЕРА ЛЕДЯНОГО ЭФИРА =================
        if (event.getType() == ModVillagers.ICE_ETHER_MASTER.value()) {
            Int2ObjectMap<List<VillagerTrades.ItemListing>> trades = event.getTrades();

            // ================= УРОВЕНЬ 1 (НОВИЧОК) =================
            // Сделка 1: 1 Изумруд -> 15 Сырого ледяного эфира
            trades.get(1).add((trader, random) -> new MerchantOffer(
                    new ItemCost(Items.EMERALD, 1),
                    new ItemStack(ModItems.RAW_ICE_ETHER.get(), 15),
                    10,  // maxUses
                    2,   // villagerXp
                    0.05f
            ));

            // Сделка 2: 20 Изумрудов -> Гибридный киркотопор (Pickaxe-Axe)
            trades.get(1).add((trader, random) -> new MerchantOffer(
                    new ItemCost(Items.EMERALD, 20),
                    new ItemStack(ModItems.ICE_ETHER_PICKAXE_AXE.get(), 1),
                    4,   // редкая покупка
                    5,
                    0.05f
            ));

            // ================= УРОВЕНЬ 2 (ПОДМАСТЕРЬЕ) =================
            // Сделка: 5 Изумрудов -> 10 Кристаллов очищенного ледяного эфира
            trades.get(2).add((trader, random) -> new MerchantOffer(
                    new ItemCost(Items.EMERALD, 5),
                    new ItemStack(ModItems.ICE_ETHER.get(), 10),
                    10,
                    5,
                    0.05f
            ));
        }
    }
}
```

## 4. Настройка DataGen

### 4.1. Генератор тегов POI (`ModPoiTypeTagsProvider`)
Чтобы игра прописала наш `ice_ether_poi` в ванильный тег рабочих мест, создадим специальный тег-провайдер.

В пакете `datagen` создайте класс `ModPoiTypeTagsProvider.java`:

```java
package com.besson.tutorial.datagen;

import com.besson.tutorial.TutorialMod;
import net.minecraft.core.HolderLookup;
import net.minecraft.core.registries.Registries;
import net.minecraft.data.PackOutput;
import net.minecraft.data.tags.TagsProvider;
import net.minecraft.resources.ResourceLocation;
import net.minecraft.tags.PoiTypeTags;
import net.minecraft.world.entity.ai.village.poi.PoiType;
import net.neoforged.neoforge.common.data.ExistingFileHelper;
import org.jetbrains.annotations.Nullable;

import java.util.concurrent.CompletableFuture;

public class ModPoiTypeTagsProvider extends TagsProvider<PoiType> {

    public ModPoiTypeTagsProvider(PackOutput output, 
                                  CompletableFuture<HolderLookup.Provider> lookupProvider, 
                                  @Nullable ExistingFileHelper existingFileHelper) {
        super(output, Registries.POINT_OF_INTEREST_TYPE, lookupProvider, TutorialMod.MOD_ID, existingFileHelper);
    }

    @Override
    protected void addTags(HolderLookup.Provider provider) {
        // Добавляем наш POI в ванильный список доступных рабочих мест жителей
        tag(PoiTypeTags.ACQUIRABLE_JOB_SITE)
                .addOptional(ResourceLocation.fromNamespaceAndPath(TutorialMod.MOD_ID, "ice_ether_poi"));
    }
}
```

---

### 4.2. Подключение провайдера в `ModDataGenerator`
Откройте `ModDataGenerator.java` и добавьте новый серверный провайдер в метод `gatherData`:

```java
// Серверные данные: Теги точек интереса (POI)
generator.addProvider(event.includeServer(), 
        new ModPoiTypeTagsProvider(packOutput, lookupProvider, existingFileHelper));
```

### 4.3. Особенности ключа локализации профессии
В Minecraft название профессии в интерфейсе жителя формируется по строгому шаблону:
`entity.minecraft.villager.<mod_id>.<profession_name>`

Если этот ключ не задан, в заголовке окна торговли будет отображаться техническая строка.

В `ModEnUsLangProvider.java`:
```java
add("entity.minecraft.villager.tutorial_mod.ice_ether_master", "Ice Ether Master");
```

В `ModRuRuLangProvider.java`:
```java
add("entity.minecraft.villager.tutorial_mod.ice_ether_master", "Мастер ледяного эфира");
```

## 5. Текстура рабочей одежды жителя (Скин-оверлей)

Когда житель приобретает профессию, поверх его базового скина накладывается полупрозрачная текстура профессиональной униформы.

Путь к файлу текстуры:  
`src/main/resources/assets/tutorial_mod/textures/entity/villager/profession/`
* **`ice_ether_master.png`** (разрешение 64×64 PNG).

> 💡 **Как создать текстуру одежды?**  
> Возьмите ванильную текстуру фартука бронника (`textures/entity/villager/profession/armorer.png`) или библиотекаря, откройте в графическом редакторе и перекрасьте фартук, повязку или защитные очки в фирменный ледяной/бирюзовый цвет вашего мода.

## 6. Тестирование в игре

1. Запустите конфигурацию **`Run Data`** — в папке `data/minecraft/tags/point_of_interest_type/` сгенерируется файл `acquirable_job_site.json`.
2. Запустите клиент игры (**`Run Client`**).
3. Создайте новый одиночный мир.
4. Возьмите из творческого инвентаря:
    * **Яйцо призыва жителя (Villager Spawn Egg)**;
    * **Блок ледяного эфира (`Ice Ether Block`)**;
    * Стак **изумрудов**.
5. **Проверка трудоустройства:**
    * Заспавните обычного жителя без профессии (в коричневой рубахе).
    * Поставьте рядом **Блок ледяного эфира**.
    * Житель посмотрит на блок, вокруг него вспыхнут **зеленые частицы**, и на нем мгновенно появится уникальная бирюзовая униформа `ice_ether_master.png`!
6. **Проверка интерфейса торговли:**
    * Нажмите ПКМ по жителю:
        * В шапке окна отображается корректное локализованное имя: **«Мастер ледяного эфира — Новичок»**.
        * На 1-м уровне доступны обе созданные сделки: **1 изумруд $\rightarrow$ 15 сырого эфира** и покупка **Киркотопора**.
7. **Проверка повышения уровня:**
    * Купите сырой эфир несколько раз.
    * Житель наберет опыт, проиграется звук работы `SoundEvents.VILLAGER_WORK_ARMORER`, бейдж сменится на железный (Подмастерье), и откроется продажа очищенного эфира!
