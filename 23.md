# Урок 23: Кастомные звуки (Sound Events & DeferredSoundType) в NeoForge 1.21.1

Качественное звуковое оформление — ключевой элемент погружения в Minecraft. До сих пор мы использовали стандартные ванильные звуки (звуки аметиста для блоков, звуки алмаза для брони).

В этом уроке мы создадим собственную аудиосистему:
* Разберем требования движка к звуковым файлам: почему Minecraft поддерживает **только формат `.ogg`** и почему аудиодорожка **обязана быть монофонической (Mono)**.
* Зарегистрируем кастомные звуковые события (`SoundEvent`) с переменным радиусом затухания (`createVariableRangeEvent`).
* Озвучим прибор **Геологоразведчик (`Prospector`)**: добавим звуковой сигнал (бип) при обнаружении руды.
* Создадим собственный набор звуков блока через **`DeferredSoundType`**: полностью озвучим установку, шаги, удары, падение и разрушение блока ледяного эфира.
* Настроим конфигурационный файл **`sounds.json`** и добавим локализованные **субтитры** для слабослышащих игроков.

## 1. Теория: Архитектура аудио в Minecraft

### 1.1. Формат `.ogg` и критическая важность Mono (1 канал)

Minecraft использует звуковой движок *OpenAL* и звуковые библиотеки *Vorbis*:
1. **Только формат `.ogg` (Ogg Vorbis):** файлы `.mp3`, `.wav`, `.flac` движком **игнорируются** и работать не будут.
2. ⚠️ **Критическое правило каналов: Звуки ДОЛЖНЫ быть Моно (Mono, 1 канал)!**  
   Если ваш файл сохранен в стерео (Stereo, 2 канала), движок игры **отключает 3D-позиционирование в пространстве** [12:00–12:35]. Стерео-звук будет оглушительно звучать одинаково громко в обоих наушниках в любой точке мира, независимо от расстояния до источника звука! Стерео используется только для фоновой музыки и пластинок.

> 💡 **Как конвертировать звук:**  
> В бесплатной программе **Audacity** откройте ваш звук, нажмите `Правка -> Настройки -> Треки -> Стерео в моно` и экспортируйте как `Ogg Vorbis`.

---

### 1.2. `createVariableRangeEvent` против `createFixedRangeEvent`
В коде Minecraft звуковые события объявляются через статические фабрики `SoundEvent`:
* **`SoundEvent.createVariableRangeEvent(ResourceLocation)`:** стандартный звук. Громкость плавно затухает по мере удаления игрока от источника.
* **`SoundEvent.createFixedRangeEvent(ResourceLocation, float distance)`:** звук с жестко фиксированным радиусом слышимости (используется для рева Визера, взрыва Дракона Края и сигналов колокола).

---

### 1.3. Пять звуков блока и класс `DeferredSoundType`
В поведении блоков `BlockBehaviour.Properties.of().sound(...)` задается набор звуков `SoundType`. Полноценный материал имеет 5 звуковых событий:
1. **`break`** — разрушение блока;
2. **`step`** — шаги персонажа или мобов по поверхности;
3. **`place`** — установка блока в мир;
4. **`hit`** — глухие удары рукой/инструментом по блоку;
5. **`fall`** — звук приземления персонажа на блок после падения.

NeoForge предоставляет удобный класс **`DeferredSoundType`**, позволяющий передавать ссылки `Supplier<SoundEvent>` напрямую из реестра без риска вызова незарегистрированных объектов.

## 2. Создание класса звуков `ModSounds`

1. В пакете вашего мода создайте подпакет `sound` (например, `com.besson.tutorial.sound`).
2. Внутри создайте класс `ModSounds.java`:

```java
package com.besson.tutorial.sound;

import com.besson.tutorial.TutorialMod;
import net.minecraft.core.registries.Registries;
import net.minecraft.resources.ResourceLocation;
import net.minecraft.sounds.SoundEvent;
import net.neoforged.bus.api.IEventBus;
import net.neoforged.neoforge.common.util.DeferredSoundType;
import net.neoforged.neoforge.registries.DeferredHolder;
import net.neoforged.neoforge.registries.DeferredRegister;

public class ModSounds {

    // 1. Создаем реестр звуковых событий
    public static final DeferredRegister<SoundEvent> SOUND_EVENTS =
            DeferredRegister.create(Registries.SOUND_EVENT, TutorialMod.MOD_ID);

    // ================= ЗВУК ПРЕДМЕТА ГЕОЛОГОРАЗВЕДЧИКА =================
    public static final DeferredHolder<SoundEvent, SoundEvent> PROSPECTOR_FOUND_ORE =
            registerSoundEvent("prospector_found_ore");

    // ================= ЗВУКИ БЛОКА ЛЕДЯНОГО ЭФИРА =================
    public static final DeferredHolder<SoundEvent, SoundEvent> ICE_ETHER_BLOCK_BREAK =
            registerSoundEvent("ice_ether_block_break");
    public static final DeferredHolder<SoundEvent, SoundEvent> ICE_ETHER_BLOCK_STEP =
            registerSoundEvent("ice_ether_block_step");
    public static final DeferredHolder<SoundEvent, SoundEvent> ICE_ETHER_BLOCK_PLACE =
            registerSoundEvent("ice_ether_block_place");
    public static final DeferredHolder<SoundEvent, SoundEvent> ICE_ETHER_BLOCK_HIT =
            registerSoundEvent("ice_ether_block_hit");
    public static final DeferredHolder<SoundEvent, SoundEvent> ICE_ETHER_BLOCK_FALL =
            registerSoundEvent("ice_ether_block_fall");

    // ================= НАБОР ЗВУКОВ ДЛЯ БЛОКОВ =================
    public static final DeferredSoundType ICE_ETHER_SOUND_TYPE = new DeferredSoundType(
            1.0f, // Громкость (volume)
            1.0f, // Высота тона (pitch)
            ICE_ETHER_BLOCK_BREAK,
            ICE_ETHER_BLOCK_STEP,
            ICE_ETHER_BLOCK_PLACE,
            ICE_ETHER_BLOCK_HIT,
            ICE_ETHER_BLOCK_FALL
    );

    /**
     * Вспомогательный метод регистрации SoundEvent с переменным радиусом затухания
     */
    private static DeferredHolder<SoundEvent, SoundEvent> registerSoundEvent(String name) {
        return SOUND_EVENTS.register(name, () -> SoundEvent.createVariableRangeEvent(
                ResourceLocation.fromNamespaceAndPath(TutorialMod.MOD_ID, name)
        ));
    }

    public static void register(IEventBus eventBus) {
        SOUND_EVENTS.register(eventBus);
    }
}
```

## 3. Привязка звуков к предмету и блоку

### 3.1. Воспроизведение звука в `ProspectorItem`
Откройте класс `ProspectorItem.java` (из Урока 10). В методе `outputValuableCoordinates` вызовем проигрывание звука `PROSPECTOR_FOUND_ORE`:

```java
    private void outputValuableCoordinates(BlockPos pos, Player player, Block block) {
        player.sendSystemMessage(Component.translatable(
                "chat.tutorial_mod.prospector.ore_found",
                block.getName().getString(),
                pos.getX(),
                pos.getY(),
                pos.getZ()
        ));

        // Воспроизводим звук прибора на позиции игрока
        player.level().playSound(
                null,                   // null означает, что звук услышат все игроки рядом (включая самого игрока)
                player.blockPosition(), // Координаты источника звука
                ModSounds.PROSPECTOR_FOUND_ORE.get(), // Звуковое событие
                SoundSource.PLAYERS,    // Категория звука в настройках громкости
                1.0f,                   // Громкость
                1.0f                    // Тональность
        );
    }
```

---

### 3.2. Назначение звукового набора в `ModBlocks.ICE_ETHER_BLOCK`
Откройте `ModBlocks.java`. Замените ванильный звук `SoundType.AMETHYST` на наш новый `ModSounds.ICE_ETHER_SOUND_TYPE`:

```java
public static final DeferredBlock<Block> ICE_ETHER_BLOCK = registerBlock(
        "ice_ether_block",
        () -> new Block(BlockBehaviour.Properties.of()
                .strength(3.0f, 3.0f)
                // Подключаем наш кастомный набор звуков!
                .sound(ModSounds.ICE_ETHER_SOUND_TYPE)
                .requiresCorrectToolForDrops())
);
```

## 4. Подключение реестра в `TutorialMod`

Откройте главный класс мода `TutorialMod.java` и добавьте вызов регистрации звуков на шине событий в конструктор:

```java
public TutorialMod(IEventBus modEventBus) {
    ModItems.register(modEventBus);
    ModBlocks.register(modEventBus);
    ModArmorMaterials.register(modEventBus);
    ModVillagers.register(modEventBus);
    // ОБЯЗАТЕЛЬНО: Регистрация звуков!
    ModSounds.register(modEventBus);
    ModCreativeModeTabs.register(modEventBus);

    modEventBus.addListener(this::addCreative);
}
```

### Размещение аудиофайлов:
Поместите 6 монофонических файлов `.ogg` в директорию звуков:  
`src/main/resources/assets/tutorial_mod/sounds/`
* `prospector_found_ore.ogg` (короткий электронный бип / зуммер)
* `ice_ether_block_break.ogg` (хрустальный звон разбивания)
* `ice_ether_block_step.ogg` (звук хрустящего шага по льду/эфиру)
* `ice_ether_block_place.ogg` (звук установки)
* `ice_ether_block_hit.ogg` (глухой удар)
* `ice_ether_block_fall.ogg` (приземление)

## 6. Тестирование в игре

1. Запустите генерацию языковых файлов через конфигурацию **`Run Data`**.
2. Запустите клиент игры (**`Run Client`**).
3. Зайдите в `Настройки -> Музыка и звуки`:
    * Убедитесь, что общая громкость и громкость блоков включены на 100%.
    * В правом нижнем углу включите параметр **«Субтитры: ВКЛ» (Show Subtitles: ON)**.
4. Войдите в тестовый мир:
    * **Тест 1 (Геологоразведчик):**
        * Возьмите прибор `Prospector` и кликните ПКМ над залежами руды.
        * Прозвучит отчетливый бип, а в правом нижнем углу экрана появится субтитр:  
          `Геологоразведчик пищит >` со стрелочкой направления на источник звука!
    * **Тест 2 (Установка и разрушение блока):**
        * Поставьте `Ice Ether Block` на землю — проиграется уникальный звук размещения.
        * Начните ломать блок киркой — проиграются звуки ударов (`hit`), а при разрушении — звонкий хрустальный звук (`break`).
    * **Тест 3 (Шаги и падение):**
        * Выложите дорожку из блоков ледяного эфира и пробегитесь по ней: каждый шаг отзывается новым кастомным звуком шага.
        * Подпрыгните и приземлитесь на блок — проиграется звук падения (`fall`).
