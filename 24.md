# Урок 24: Создание музыкальных пластинок (Music Discs & JukeboxSong) в NeoForge 1.21.1

В Уроке 23 мы освоили систему звуковых событий (`SoundEvent`) и научились озвучивать блоки и интерактивные инструменты. В этом уроке мы создадим собственную **музыкальную пластинку (Music Disc)**.

В версиях Minecraft **1.20.5+ и 1.21.1** система пластинок и проигрывателей (`Jukebox`) претерпела революционные изменения:
* Класс `RecordItem` **устарел**. Теперь пластинка — это обычный предмет `Item`, поведение которого задается через компонент **`JukeboxPlayable`**.
* Параметры воспроизведения (длительность трека, сигнал компаратора, описание) вынесены в дата-драйвен реестр **`Registries.JUKEBOX_SONG`** в формате JSON-файлов.
* Для длинных музыкальных треков критически важно использовать флаг **`"stream": true`** в `sounds.json`, чтобы предотвратить утечку и перерасход оперативной памяти (RAM).
* Мы разберем, как подключить пластинку к ванильному тегу `ItemTags.MUSIC_DISCS`, настроить 3D-позиционирование звука в пространстве и протестировать взаимодействие с компаратором редстоуна.

## 1. Теория: Архитектура пластинок в Minecraft 1.21+

### 1.1. Компонент `JukeboxPlayable` вместо `RecordItem`
До версии 1.20.5 включительно любая пластинка требовала создания экземпляра специализированного класса `RecordItem`:
```java
// УСТАРЕВШИЙ СПОСОБ (до 1.20.5):
new RecordItem(15, ModSounds.MY_SONG, new Item.Properties(), 2400);
```

В Minecraft 1.21.1 Mojang полностью переписали механику предметов на систему компонентов данных (*Data Components*). Теперь пластинкой может быть **абсолютно любой предмет**, у которого в свойствах включен компонент:
```java
new Item.Properties().jukeboxPlayable(ResourceKey<JukeboxSong>)
```
Вы можете сделать проигрываемой даже палку или алмаз!

---

### 1.2. Реестр `JukeboxSong` и формат данных
Параметры музыкальной композиции больше не зашиваются жестко в Java-код. Вместо этого песня регистрируется как объект `JukeboxSong` через JSON-файл в папке `data/<mod_id>/jukebox_song/<song_name>.json`:
* **`comparator_output`** (от `1` до `15`): сила сигнала редстоуна, которую компаратор считывает с проигрывателя при воспроизведении этой пластинки.
* **`length_in_seconds`**: точная длительность трека в секундах. По истечении этого времени проигрыватель автоматически остановит музыку.
* **`sound_event`**: ID звукового события из `sounds.json`.
* **`description`**: ключ перевода для отображения названия песни и автора во всплывающем уведомлении над хотбаром.

---

### 1.3. Стриминг звука (`"stream": true`) против загрузки в RAM
В Уроке 23 мы узнали, что короткие звуки шагов и разрушения блоков загружаются в оперативную память целиком.

> ⚠️ **Критически важное правило для музыки:**  
> Обычный звуковой эффект длится 0.5–1 секунду и весит 20–50 КБ. Полноценная музыкальная композиция длится 3–4 минуты и весит несколько мегабайт.  
> Если в `sounds.json` **не указать** флаг `"stream": true`, игра попытается полностью распаковать весь сжатый аудиопоток в несжатый массив байт в RAM, что вызовет резкий скачок потребления памяти и микрофризы!  
> Параметр `"stream": true` заставляет звуковой движок считывать аудиофайл с диска небольшими порциями прямо в процессе воспроизведения.

---

### 1.4. Моно против Стерео для проигрывателя
* Если аудиофайл сохранен в **Стерео (Stereo)**, он воспроизводится как фоновый саундтрек: одинаково громко в обоих наушниках, без привязки к координатам блока.
* Если аудиофайл сохранен в **Моно (Mono)**, движок OpenAL привязывает его к координатам проигрывателя: при удалении от блока звук затихает, а при повороте головы плавно панорамируется между левым и правым ухом. Для реалистичного эффекта пластинки в мире рекомендуется использовать **Mono**.

## 2. Объявление звука и ключа песни в `ModSounds`

Откройте класс `ModSounds.java` (из Урока 23). Добавим регистрацию звукового события и ключа ресурса `ResourceKey<JukeboxSong>`:

```java
package com.besson.tutorial.sound;

import com.besson.tutorial.TutorialMod;
import net.minecraft.core.registries.Registries;
import net.minecraft.resources.ResourceKey;
import net.minecraft.resources.ResourceLocation;
import net.minecraft.sounds.SoundEvent;
import net.minecraft.world.item.JukeboxSong;
import net.neoforged.bus.api.IEventBus;
import net.neoforged.neoforge.common.util.DeferredSoundType;
import net.neoforged.neoforge.registries.DeferredHolder;
import net.neoforged.neoforge.registries.DeferredRegister;

public class ModSounds {

    public static final DeferredRegister<SoundEvent> SOUND_EVENTS =
            DeferredRegister.create(Registries.SOUND_EVENT, TutorialMod.MOD_ID);

    // ================= ЗВУКИ ИЗ УРОКА 23 =================
    public static final DeferredHolder<SoundEvent, SoundEvent> PROSPECTOR_FOUND_ORE =
            registerSoundEvent("prospector_found_ore");
    // ... звуки блока эфира ...

    // ================= 1. ЗВУКОВОЕ СОБЫТИЕ ПЛАСТИНКИ =================
    // Песня: Odesza - A Moment Apart
    public static final DeferredHolder<SoundEvent, SoundEvent> A_MOMENT_APART =
            registerSoundEvent("a_moment_apart");

    // ================= 2. КЛЮЧ ДАТА-ДРАЙВЕН ПЕСНИ ДЛЯ JUKEBOX =================
    public static final ResourceKey<JukeboxSong> A_MOMENT_APART_SONG =
            createSongKey("a_moment_apart");

    /**
     * Вспомогательный метод создания ResourceKey для JukeboxSong
     */
    private static ResourceKey<JukeboxSong> createSongKey(String name) {
        return ResourceKey.create(Registries.JUKEBOX_SONG, 
                ResourceLocation.fromNamespaceAndPath(TutorialMod.MOD_ID, name));
    }

    private static DeferredHolder<SoundEvent, SoundEvent> registerSoundEvent(String name) {
        return SOUND_EVENTS.register(name, () -> SoundEvent.createVariableRangeEvent(
                ResourceLocation.fromNamespaceAndPath(TutorialMod.MOD_ID, name)
        ));
    }

    public static void register(IEventBus eventBus) {
        SOUND_EVENTS.register(eventBus);
    }
}
```

## 3. Регистрация пластинки в `ModItems`

Откройте класс `ModItems.java`. Зарегистрируем пластинку как обычный `Item` с компонентом `jukeboxPlayable`, ограничением в 1 предмет в стаке и редкостью `Rarity.RARE` (бирюзовое название предмета, как у ванильных дисков):

```java
// ================= МУЗЫКАЛЬНЫЕ ПЛАСТИНКИ =================
public static final DeferredItem<Item> A_MOMENT_APART_MUSIC_DISC = ITEMS.register(
        "a_moment_apart_music_disc",
        () -> new Item(new Item.Properties()
                // Привязываем песню к проигрывателю
                .jukeboxPlayable(ModSounds.A_MOMENT_APART_SONG)
                // Пластинки не стакаются
                .stacksTo(1)
                // Бирюзовый цвет названия
                .rarity(Rarity.RARE))
);
```

## 5. Создание JSON-файла песни (`jukebox_song`)

Поскольку параметры песни в 1.21 хранятся в серверных данных дата-пака, создадим соответствующий JSON-файл.

Создайте директорию и файл по пути:  
`src/main/resources/data/tutorial_mod/jukebox_song/a_moment_apart.json`:

```json
{
  "comparator_output": 15,
  "description": {
    "translate": "item.tutorial_mod.a_moment_apart_music_disc.desc"
  },
  "length_in_seconds": 234.0,
  "sound_event": "tutorial_mod:a_moment_apart"
}
```

### Параметры файла:
* **`comparator_output`**: `15` — при проигрывании диск выдает максимальную силу сигнала редстоуна (как диск *Pigstep*).
* **`description`**: ссылка на ключ локализации с названием трека и автором.
* **`length_in_seconds`**: `234.0` — длительность трека (3 минуты 54 секунды = 234 секунды).
* **`sound_event`**: ID звука, зарегистрированного в `ModSounds` и `sounds.json`.

## 6. Настройка стриминга в `sounds.json`

Откройте файл `src/main/resources/assets/tutorial_mod/sounds.json` и добавьте описание звука пластинки с обязательным объектом и флагом `"stream": true`:

```json

  "prospector_found_ore": {

  "a_moment_apart": {
    "sounds": [
```

## 7. Настройка DataGen

### 7.1. Модель предмета (`ModItemModelProvider`)
В инвентаре пластинка представляет собой обычную 2D-текстуру диска.

Откройте `ModItemModelProvider.java`:
```java
@Override
protected void registerModels() {
    // ... другие предметы ...

    // Модель музыкальной пластинки
    basicItem(ModItems.A_MOMENT_APART_MUSIC_DISC.get());
}
```

Поместите иконку пластинки (16×16 PNG) по пути:  
`src/main/resources/assets/tutorial_mod/textures/item/a_moment_apart_music_disc.png`.

---

### 7.2. Ванильный тег пластинок (`ItemTags.MUSIC_DISCS`)
Чтобы игра распознавала нашу пластинку во всех механиках (например, выпадение из крипера при убийстве скелетом), добавим её в ванильный тег.

Откройте `ModItemTagsProvider.java`:
```java
@Override
protected void addTags(HolderLookup.Provider provider) {
    // ... другие теги ...

    // Добавляем нашу пластинку в ванильный список музыкальных дисков
    tag(ItemTags.MUSIC_DISCS)
            .add(ModItems.A_MOMENT_APART_MUSIC_DISC.get());

    // Также можно разрешить выпадение из криперов
    tag(ItemTags.CREEPER_DROP_MUSIC_DISCS)
            .add(ModItems.A_MOMENT_APART_MUSIC_DISC.get());
}
```

---

### 7.3. Локализация названия и описания трека
Для пластинок в Minecraft используется два языковых ключа:
1. Название самого предмета (обычно просто «Музыкальная пластинка / Music Disc»).
2. Описание трека (автор и композиция), отображаемое серым шрифтом в подсказке и синим уведомлением при вставке в проигрыватель.

В `ModEnUsLangProvider.java`:
```java
add(ModItems.A_MOMENT_APART_MUSIC_DISC.get(), "Music Disc");
add("item.tutorial_mod.a_moment_apart_music_disc.desc", "Odesza - A Moment Apart");
```

В `ModRuRuLangProvider.java`:
```java
add(ModItems.A_MOMENT_APART_MUSIC_DISC.get(), "Музыкальная пластинка");
add("item.tutorial_mod.a_moment_apart_music_disc.desc", "Odesza - A Moment Apart");
```

## 8. Тестирование в игре

1. Запустите генерацию ресурсов через конфигурацию **`Run Data`**.
2. Запустите клиент игры (**`Run Client`**).
3. Войдите в мир и откройте инвентарь:
    * Возьмите созданную пластинку **`Music Disc`** — ее название подсвечено бирюзовым цветом редкости, а под ним серым шрифтом выведено: `Odesza - A Moment Apart`.
    * Возьмите ванильный **Проигрыватель (Jukebox)** и **Компаратор (Redstone Comparator)**.
4. **Тест воспроизведения:**
    * Поставьте проигрыватель на землю и нажмите по нему ПКМ с пластинкой в руке.
    * Из проигрывателя полетят разноцветные **частицы нот**.
    * Над панелью быстрого доступа появится уведомление:  
      `Сейчас играет: Odesza - A Moment Apart`!
5. **Тест 3D-звука и дистанции:**
    * Отойдите на 10–20 блоков назад — музыка начнет плавно стихать.
    * Повернитесь к проигрывателю левым или правым боком — звук четко локализуется в соответствующем наушнике.
6. **Тест редстоуна:**
    * Установите компаратор вплотную к задней стенке проигрывателя.
    * Проведите от компаратора дорожку из красной пыли: компаратор загорится и выдаст мощный сигнал силой **15 блоков**!
    * Нажмите ПКМ по проигрывателю: пластинка выскочит, музыка мгновенно прекратится, а редстоун-сигнал погаснет.
