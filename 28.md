# Урок 28: Создание сидений и диванов (Механика посадки через Entity) в NeoForge 1.21.1

В декоративных модах (таких как *MrCrayfish's Furniture Mod*) одной из самых востребованных механик является возможность взаимодействовать с мебелью — садиться на стулья, кресла и диваны.

В этом уроке мы разберем, как реализовать механику посадки игрока на любой блок:
* Почему в архитектуре Minecraft **нельзя сесть на блок напрямую** и почему для этого требуется сущность (*Entity*).
* Создадим специальную **невидимую сущность-сиденье (`SitEntity`)**, которая спавнится при клике ПКМ.
* Реализуем автоматическое удаление сущности (`discard()`) при вставании игрока или разрушении блока мебели, предотвращая утечки памяти и лаги сервера.
* Настроим безопасную точку спешивания (`dismount`) при нажатии `Left Shift`.
* Ограничим угол поворота головы сидящего игрока (не более 120° в стороны), чтобы тело персонажа выглядело анатомически естественно.
* Зарегистрируем сущность и подключим пустой клиентский рендерер (`SitEntityRenderer`).

## 1. Теория: Архитектура механики сидения в Minecraft

### 1.1. Почему блоки не поддерживают пассажиров
В движке Minecraft система езды жестко привязана к классу `net.minecraft.world.entity.Entity`. Игрок может «оседлать» и стать пассажиром только другой сущности (лодки, вагонетки, лошади, свиньи или лавомерки).

Блоки (`Block`) статичны, не имеют списка пассажиров (`passengers`) и не могут передавать клиенту позицию сидения.

---

### 1.2. Концепция невидимой сущности-призрака (Sit Entity)
Чтобы обойти это ограничение движка, во всех модификациях на мебель применяется классический трюк:
1. Игрок нажимает ПКМ по блоку дивана/стула.
2. Игра незаметно спавнит в центре верхней части блока крошечную сущность без модели и текстуры.
3. Игрок мгновенно привязывается к этой сущности в качестве пассажира (`player.startRiding(seat)`).
4. Визуально создается полная иллюзия того, что персонаж сидит прямо на блоке дивана.

---

### 1.3. Вопрос производительности: жизненный цикл и автоудаление
Если сущности-сиденья после вставания игрока останутся в мире, при активной игре их накопятся сотни, что приведет к падению TPS сервера.

Поэтому `SitEntity`:
* Имеет микроскопический хитбокс ($0.02 \times 0.02$ блока) и не имеет коллизии;
* Не сохраняется на диск дата-паком (`noSave()`);
* В каждом тике проверяет: если игрок встал (`getPassengers().isEmpty()`) или блок под сиденьем сломан — сущность немедленно уничтожается методом `this.discard()`.

## 2. Создание класса сущности-сиденья (`SitEntity`)

1. В пакете вашего мода создайте подпакет `entity.custom` (например, `com.besson.tutorial.entity.custom`).
2. Создайте класс `SitEntity.java`, унаследованный от `Entity`:

```java
package com.besson.tutorial.entity.custom;

import com.besson.tutorial.entity.ModEntities;
import net.minecraft.core.BlockPos;
import net.minecraft.core.Direction;
import net.minecraft.nbt.CompoundTag;
import net.minecraft.network.syncher.SynchedEntityData;
import net.minecraft.util.Mth;
import net.minecraft.world.entity.Entity;
import net.minecraft.world.entity.EntityDimensions;
import net.minecraft.world.entity.EntityType;
import net.minecraft.world.entity.LivingEntity;
import net.minecraft.world.entity.vehicle.DismountHelper;
import net.minecraft.world.level.Level;
import net.minecraft.world.phys.Vec3;

public class SitEntity extends Entity {

    // Базовый конструктор, необходимый фабрике EntityType
    public SitEntity(EntityType<?> entityType, Level level) {
        super(entityType, level);
        this.noPhysics = true; // Отключаем гравитацию и физические столкновения
    }

    // Пользовательский конструктор для создания сиденья на блоке
    public SitEntity(Level level, BlockPos pos, double yOffset, Direction direction) {
        this(ModEntities.SIT_ENTITY.get(), level);
        // Центрируем сущность по осям X и Z (+0.5) и смещаем по высоте
        this.setPos(pos.getX() + 0.5, pos.getY() + yOffset, pos.getZ() + 0.5);
        // Ориентируем сущность в сторону, куда направлен диван
        this.setRot(direction.toYRot(), 0.0f);
    }

    @Override
    protected void defineSynchedData(SynchedEntityData.Builder builder) {
        // Синхронизируемые данные не требуются
    }

    @Override
    protected void readAdditionalSaveData(CompoundTag compoundTag) {
        // Данные не сохраняются в NBT
    }

    @Override
    protected void addAdditionalSaveData(CompoundTag compoundTag) {
        // Данные не сохраняются в NBT
    }

    /**
     * Контроль жизненного цикла в каждом тике
     */
    @Override
    public void tick() {
        super.tick();

        // Проверку выполняем строго на стороне сервера
        if (!this.level().isClientSide()) {
            // Если игрок встал (нет пассажиров) ИЛИ блок мебели под сиденьем сломан/удален:
            if (this.getPassengers().isEmpty() || this.level().isEmptyBlock(this.blockPosition())) {
                // Немедленно уничтожаем сущность-сиденье
                this.discard();
                this.level().updateNeighbourForOutputSignal(this.blockPosition(), 
                        this.level().getBlockState(this.blockPosition()).getBlock());
            }
        }
    }

    /**
     * Смещение точки посадки пассажира относительно центра сущности
     */
    @Override
    protected Vec3 getPassengerAttachmentPoint(Entity entity, EntityDimensions dimensions, float scale) {
        return new Vec3(0.0, 0.0, 0.0);
    }

    /**
     * Разрешаем игроку быть пассажиром
     */
    @Override
    protected boolean canRide(Entity entity) {
        return true;
    }

    /**
     * Безопасная точка выхода игрока при нажатии Left Shift
     */
    @Override
    public Vec3 getDismountLocationForPassenger(LivingEntity passenger) {
        Direction direction = this.getDirection();
        Direction[] directions = {direction, direction.getClockWise(), direction.getCounterClockWise(), direction.getOpposite()};

        for (Direction dir : directions) {
            Vec3 safeVec = DismountHelper.findSafeDismountLocation(
                    passenger.getType(),
                    this.level(),
                    this.blockPosition().relative(dir),
                    false
            );
            if (safeVec != null) {
                // Приподнимаем игрока на 0.25 блока для исключения застревания в соседних блоках
                return safeVec.add(0.0, 0.25, 0.0);
            }
        }

        // Запасной выход — встать поверх самого сиденья
        return super.getDismountLocationForPassenger(passenger);
    }

    /**
     * Ограничение угла поворота головы игрока во время сидения
     */
    @Override
    public void onPassengerTurned(Entity passenger) {
        this.clampPassengerYaw(passenger);
    }

    private void clampPassengerYaw(Entity passenger) {
        // Ограничиваем угол поворота в диапазоне от -120 до +120 градусов от взгляда дивана
        float bodyYaw = this.getYRot();
        float clampedYaw = Mth.clamp(Mth.wrapDegrees(passenger.getYRot() - bodyYaw), -120.0f, 120.0f);

        passenger.yRotO += clampedYaw - (passenger.getYRot() - bodyYaw);
        passenger.setYRot(bodyYaw + clampedYaw);
        passenger.setYHeadRot(passenger.getYRot());
    }
}
```

## 3. Регистрация сущности в `ModEntities`

1. В пакете `com.besson.tutorial.entity` создайте класс `ModEntities.java`.
2. Зарегистрируйте `SitEntity` с категорией `MISC` и минимальными размерами хитбокса ($0.02 \times 0.02$):

```java
package com.besson.tutorial.entity;

import com.besson.tutorial.TutorialMod;
import com.besson.tutorial.entity.custom.SitEntity;
import net.minecraft.core.registries.Registries;
import net.minecraft.world.entity.EntityType;
import net.minecraft.world.entity.MobCategory;
import net.neoforged.bus.api.IEventBus;
import net.neoforged.neoforge.registries.DeferredHolder;
import net.neoforged.neoforge.registries.DeferredRegister;

public class ModEntities {

    public static final DeferredRegister<EntityType<?>> ENTITY_TYPES =
            DeferredRegister.create(Registries.ENTITY_TYPE, TutorialMod.MOD_ID);

    // Регистрация сиденья
    public static final DeferredHolder<EntityType<?>, EntityType<SitEntity>> SIT_ENTITY =
            ENTITY_TYPES.register("sit_entity", () -> EntityType.Builder.<SitEntity>of(SitEntity::new, MobCategory.MISC)
                    .sized(0.02f, 0.02f) // Минимальный размер без столкновений
                    .noSave()            // Запрет записи в файлы сохранения мира
                    .build("sit_entity"));

    public static void register(IEventBus eventBus) {
        ENTITY_TYPES.register(eventBus);
    }
}
```

Не забудьте вызвать `ModEntities.register(modEventBus)` в конструкторе `TutorialMod.java`!

## 4. Создание невидимого рендерера (`SitEntityRenderer`)

Поскольку сиденье — это техническая сущность, ей не нужна модель в игре.

1. В пакете `com.besson.tutorial.client.renderer` создайте класс `SitEntityRenderer.java`:

```java
package com.besson.tutorial.client.renderer;

import com.besson.tutorial.entity.custom.SitEntity;
import net.minecraft.client.renderer.culling.Frustum;
import net.minecraft.client.renderer.entity.EntityRenderer;
import net.minecraft.client.renderer.entity.EntityRendererProvider;
import net.minecraft.resources.ResourceLocation;

public class SitEntityRenderer extends EntityRenderer<SitEntity> {

    public SitEntityRenderer(EntityRendererProvider.Context context) {
        super(context);
    }

    @Override
    public ResourceLocation getTextureLocation(SitEntity entity) {
        return null;
    }

    @Override
    public boolean shouldRender(SitEntity livingEntity, Frustum camera, double camX, double camY, double camZ) {
        return false; // Запрещаем видеокарте отрисовывать эту сущность
    }
}
```

2. Зарегистрируйте рендерер на клиентской шине событий (`EntityRenderersEvent.RegisterRenderers`):

```java
@EventBusSubscriber(modid = TutorialMod.MOD_ID, bus = EventBusSubscriber.Bus.MOD, value = Dist.CLIENT)
public class ModClientEvents {

    @SubscribeEvent
    public static void registerEntityRenderers(EntityRenderersEvent.RegisterRenderers event) {
        event.registerEntityRenderer(ModEntities.SIT_ENTITY.get(), SitEntityRenderer::new);
    }
}
```

## 5. Интеграция посадки в блок мебели (`SofaBlock`)

В блоке дивана переопределим метод `useWithoutItem` (в версиях 1.20.5+ и 1.21.1 он заменил устаревший `use` при клике пустой рукой).

```java
package com.besson.tutorial.block.custom;

import com.besson.tutorial.entity.custom.SitEntity;
import net.minecraft.core.BlockPos;
import net.minecraft.core.Direction;
import net.minecraft.world.InteractionResult;
import net.minecraft.world.entity.player.Player;
import net.minecraft.world.level.Level;
import net.minecraft.world.level.block.Block;
import net.minecraft.world.level.block.HorizontalDirectionalBlock;
import net.minecraft.world.level.block.state.BlockState;
import net.minecraft.world.phys.AABB;
import net.minecraft.world.phys.BlockHitResult;

import java.util.List;

public class SofaBlock extends HorizontalDirectionalBlock {

    public SofaBlock(Properties properties) {
        super(properties);
        this.registerDefaultState(this.stateDefinition.any().setValue(FACING, Direction.NORTH));
    }

    /**
     * Обработка клика ПКМ по дивану
     */
    @Override
    protected InteractionResult useWithoutItem(BlockState state, Level level, BlockPos pos, Player player, BlockHitResult hitResult) {
        if (!level.isClientSide()) {
            // 1. Проверяем, не сидит ли уже кто-то на этом блоке
            List<SitEntity> existingSeats = level.getEntitiesOfClass(
                    SitEntity.class,
                    new AABB(pos.getX(), pos.getY(), pos.getZ(), pos.getX() + 1.0, pos.getY() + 1.0, pos.getZ() + 1.0)
            );

            // Если сиденья нет — создаем новое
            if (existingSeats.isEmpty()) {
                Direction facing = state.getValue(FACING);
                
                // Высота посадки: 0.25 (или 0.45 в зависимости от высоты модели дивана)
                SitEntity seat = new SitEntity(level, pos, 0.25, facing);
                level.addFreshEntity(seat);

                // Сажаем игрока на сиденье
                player.startRiding(seat);
            }
        }

        return InteractionResult.SUCCESS;
    }
}
```

## 6. Тестирование в игре

1. Запустите конфигурацию **`Run Client`**.
2. Войдите в мир и установите диван (`Sofa Block`).
3. **Проверка посадки:**
   * Нажмите ПКМ по дивану с пустой рукой.
   * Персонаж мгновенно займет сидячее положение.
   * Переключитесь на вид от третьего лица (`F5`): персонаж сидит с согнутыми ногами точно на подушке дивана.
4. **Проверка ограничения поворота:**
   * Попробуйте повернуть камеру назад: угол обзора ограничивается диапазоном 120° — персонаж не может противоестественно вывернуть шею назад на 180°.
5. **Проверка спешивания:**
   * Нажмите клавишу **Left Shift** — игрок аккуратно встанет рядом с диваном.
   * Нажмите клавишу `F3 + B` (показ хитбоксов): убедитесь, что невидимая сущность `SitEntity` мгновенно исчезла из мира, не оставляя фантомных объектов.

***

**Итог:** Вы реализовали механику посадки игрока на мебель в NeoForge 1.21.1: создали невидимую сущность `SitEntity`, оптимизировали автоудаление при вставании и поломке блока, настроили безопасное спешивание и ограничение вращения камеры!
