# Урок 29: Создание источников света и переключаемых ламп (Light Emission & LIT Property) в NeoForge 1.21.1

В предыдущих уроках мы научились создавать сложные декоративные блоки, мебель и растения. В этом уроке мы разберем механику **освещения блоков** в Minecraft:
* Как устроена система света в движке игры (шкала яркости от `0` до `15`).
* Как создавать **статические источники света** (подобно факелам, светящемуся камню или блоку лавы).
* Как создавать **интерактивные переключаемые лампы**, реагирующие на нажатие правой кнопки мыши (ПКМ) пустой рукой (`useWithoutItem`).
* Как работает динамическая привязка яркости через свойство блокстейта **`BlockStateProperties.LIT`** и лямбда-функцию `lightLevel(state -> ...)`.
* Разберем побочный физический эффект света в Minecraft: почему яркий блок ($\ge 12$) растапливает снег и лед вокруг себя.
* Настроим DataGen: сгенерируем состояния блока с двумя разными текстурами (включенная и выключенная лампа).

## 1. Теория: Архитектура освещения в Minecraft

### 1.1. Шкала уровней света (0–15)
В Minecraft уровень освещения измеряется целым числом в диапазоне **от 0 до 15**:
* **`0`**: абсолютная темнота (не излучает свет).
* **`5`**: тусклое свечение (аметистовый кластер).
* **`7`**: красный факел.
* **`10`**: плачущий обсидиан.
* **`14`**: обычный факел.
* **`15`**: максимальная яркость (лампа из редстоуна, лава, светокамень, костер, морской фонарь).

---

### 1.2. Метод `lightLevel` и функциональный интерфейс `ToIntFunction<BlockState>`
В классе `BlockBehaviour.Properties` за излучение света отвечает метод:
```java
public Properties lightLevel(ToIntFunction<BlockState> lightEmission)
```

Обратите внимание, что метод принимает **не число**, а функцию `ToIntFunction<BlockState>`:
* Для **постоянного (статического)** источника света передается лямбда, возвращающая фиксированное значение:
  ```java
  .lightLevel(state -> 15)
  ```
* Для **переключаемого (динамического)** источника света возвращаемое число зависит от текущего состояния блока:
  ```java
  .lightLevel(state -> state.getValue(LampBlock.LIT) ? 15 : 0)
  ```

---

### 1.3. Свойство блокстейта `BlockStateProperties.LIT`
Для переключения состояния «горит / не горит» в ванильном коде (`net.minecraft.world.level.block.state.properties.BlockStateProperties`) используется булево свойство:
```java
public static final BooleanProperty LIT = BooleanProperty.create("lit");
```
Оно используется печками, кострами, редстоун-лампами и свечами.

---

### 1.4. Таяние снега и льда: особенности механики
В движке Minecraft заложено правило: если блок излучает свет уровнем **12 и выше** (`Light Level >= 12`), в случайных тиках (`randomTick`) блоки снега и обычного льда, находящиеся вплотную к нему, **начинают таять и превращаться в воду**. Это естественное физическое поведение игры для любых ярких ламп.

## 2. Создание класса интерактивной лампы `LampBlock`

Создадим класс блока, который при клике ПКМ пустой рукой переключает свойство `LIT` между `true` и `false`.

1. В пакете `com.besson.tutorial.block.custom` создайте класс `LampBlock.java`:

```java
package com.besson.tutorial.block.custom;

import net.minecraft.core.BlockPos;
import net.minecraft.world.InteractionResult;
import net.minecraft.world.entity.player.Player;
import net.minecraft.world.level.Level;
import net.minecraft.world.level.block.Block;
import net.minecraft.world.level.block.state.BlockState;
import net.minecraft.world.level.block.state.StateDefinition;
import net.minecraft.world.level.block.state.properties.BlockStateProperties;
import net.minecraft.world.level.block.state.properties.BooleanProperty;
import net.minecraft.world.phys.BlockHitResult;

public class LampBlock extends Block {

    // Булево свойство: true - включено, false - выключено
    public static final BooleanProperty LIT = BlockStateProperties.LIT;

    public LampBlock(Properties properties) {
        super(properties);
        // По умолчанию лампа выключена (или true, если хотите включенную по умолчанию)
        this.registerDefaultState(this.defaultBlockState().setValue(LIT, false));
    }

    /**
     * Обработка клика ПКМ пустой рукой
     */
    @Override
    protected InteractionResult useWithoutItem(BlockState state, Level level, BlockPos pos, Player player, BlockHitResult hitResult) {
        if (!level.isClientSide()) {
            // Переключаем состояние LIT на противоположное
            boolean isLit = state.getValue(LIT);
            level.setBlock(pos, state.setValue(LIT, !isLit), 3);
        }

        return InteractionResult.SUCCESS;
    }

    /**
     * Регистрация свойства LIT в блокстейте
     */
    @Override
    protected void createBlockStateDefinition(StateDefinition.Builder<Block, BlockState> builder) {
        builder.add(LIT);
    }
}
```

## 3. Регистрация статического и динамического источников света в `ModBlocks`

Откройте класс `ModBlocks.java` и добавьте два блока:
1. **`ICE_ETHER_LAMP`**: интерактивная лампа с переключаемым светом (0 или 15).
2. **Демонстрация статического света**: настроим мягкое тусклое свечение (уровень 5) для обычного рудного или кристаллического блока эфира.

```java
package com.besson.tutorial.block;

import com.besson.tutorial.block.custom.LampBlock;
import net.minecraft.world.level.block.Block;
import net.minecraft.world.level.block.SoundType;
import net.minecraft.world.level.block.state.BlockBehaviour;
import net.neoforged.neoforge.registries.DeferredBlock;

public class ModBlocks {
    // ... существующие блоки ...

    // 1. Интерактивная переключаемая лампа (0 или 15 света)
    public static final DeferredBlock<LampBlock> ICE_ETHER_LAMP = registerBlock("ice_ether_lamp",
            () -> new LampBlock(BlockBehaviour.Properties.of()
                    .strength(3.0f)
                    .sound(SoundType.GLASS)
                    // Динамическая привязка света через лямбду!
                    .lightLevel(state -> state.getValue(LampBlock.LIT) ? 15 : 0)
            ));

    // 2. Пример статического источника света (постоянное свечение 5 уровня)
    public static final DeferredBlock<Block> GLOWING_ICE_ETHER_BLOCK = registerBlock("glowing_ice_ether_block",
            () -> new Block(BlockBehaviour.Properties.of()
                    .strength(3.0f)
                    .sound(SoundType.AMETHYST)
                    .lightLevel(state -> 5) // Всегда излучает свет 5 уровня
            ));
}
```

## 5. Настройка DataGen

### 5.1. Генерация BlockStates для двух состояний (`ModBlockStateProvider`)

Для лампы нам понадобятся две разные модели:
* `ice_ether_lamp_off.json` (темная текстура);
* `ice_ether_lamp_on.json` (яркая светящаяся текстура).

Откройте `ModBlockStateProvider.java`:

```java
package com.besson.tutorial.datagen;

import com.besson.tutorial.block.ModBlocks;
import com.besson.tutorial.block.custom.LampBlock;
import net.neoforged.neoforge.client.model.generators.BlockStateProvider;
import net.neoforged.neoforge.client.model.generators.ModelFile;

public class ModBlockStateProvider extends BlockStateProvider {

    @Override
    protected void registerStatesAndModels() {
        // ... другие блоки ...

        // Создаем две модели куба: включенное и выключенное состояние
        ModelFile lampOff = models().cubeAll("ice_ether_lamp", modLoc("block/ice_ether_lamp_off"));
        ModelFile lampOn = models().cubeAll("ice_ether_lamp_on", modLoc("block/ice_ether_lamp_on"));

        // Связываем варианты блокстейта со свойством LIT
        getVariantBuilder(ModBlocks.ICE_ETHER_LAMP.get())
                .partialState().with(LampBlock.LIT, false).modelForState().modelFile(lampOff).addModel()
                .partialState().with(LampBlock.LIT, true).modelForState().modelFile(lampOn).addModel();

        // Модель предмета в инвентаре наследует выключенное состояние
        simpleBlockItem(ModBlocks.ICE_ETHER_LAMP.get(), lampOff);

        // Статический светящийся блок
        simpleBlockWithItem(ModBlocks.GLOWING_ICE_ETHER_BLOCK.get(), cubeAll(ModBlocks.GLOWING_ICE_ETHER_BLOCK.get()));
    }
}
```

## 6. Тестирование в игре

1. Запустите генерацию данных через конфигурацию **`Run Data`**.  
   Убедитесь, что в `blockstates/ice_ether_lamp.json` создались варианты `"lit=false"` и `"lit=true"`.
2. Запустите клиент игры (**`Run Client`**).
3. Дождитесь ночи (`/time set midnight`) или зайдите в темную пещеру.
4. **Проверка интерактивной лампы:**
    * Установите блок лампы на землю: лампа появится в выключенном состоянии, вокруг темно.
    * Нажмите по ней **ПКМ пустой рукой**:
        * Текстура мгновенно сменится на светящуюся `lamp_on`.
        * Вся поляна вокруг озарится ярким светом 15 уровня!
    * Нажмите клавишу **F3** и посмотрите на блок: в блоке информации справа отобразится `lit: true`, а в строке `Client Light` — уровень `15 (15 block, 0 sky)`.
    * Нажмите ПКМ еще раз — лампа погаснет, а свет пропадет.
5. **Проверка таяния снега:**
    * Установите лампу в заснеженном биоме и включите ее.
    * Поставьте вокруг лампы снежный покров или лед.
    * Увеличьте скорость случайных тиков (`/gamerule randomTickSpeed 1000`).
    * Из-за уровня освещенности 15 снег и лед в радиусе 2–3 блоков начнут быстро таять!
