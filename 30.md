# Урок 30: Создание кастомной кровати и BlockEntity (BedBlock & BedBlockEntity) в NeoForge 1.21.1

В предыдущем уроке мы создали переключаемую лампу и разобрались с уровнями света. В этом уроке мы реализуем один из самых комплексных и знаковых составных блоков Minecraft — **Кровать из ледяного эфира (`Ice Ether Bed`)**:
* Разберем устройство кровати: почему физически это **два связанных блока** (`BedPart.HEAD` — изголовье и `BedPart.FOOT` — изножье).
* Узнаем, почему кровати необходим собственный **`BlockEntity`** (сущность блока), и напишем класс `ModBedBlockEntity` с сохранением данных через NBT.
* Наследуем функционал ванильного `BedBlock`: сон в ночное время, установка точки возрождения (`Spawn Point`), проверка занятости кровати жителями, отскок при падении (`bounceUp`) и взрыв в Незере/Энде.
* Настроим DataGen: напишем специфическую таблицу лута (кровать занимает 2 блока, но при разрушении любой части должен выпадать ровно **один** предмет) и настроим состояния блока.

## 1. Теория: Архитектура кроватей в Minecraft

### 1.1. Двухблочная структура: `HEAD` и `FOOT`
В Minecraft кровать занимает пространство $2 \times 1 \times 1$ блока. При установке предмета кровати игра фактически размещает **два отдельных блока**:
1. **`BedPart.FOOT` (Изножье):** блок, на который кликнул игрок.
2. **`BedPart.HEAD` (Изголовье):** блок, появляющийся на 1 клетку вперед по направлению взгляда игрока (`pos.relative(facing)`).

Если сломать любую из половинок, соседняя половинка автоматически разрушается.

---

### 1.2. Свойства блокстейта
Состояние кровати определяется тремя свойствами:
* **`FACING` (`HorizontalDirectionalBlock.FACING`):** горизонтальное направление (куда направлено изголовье: север, юг, восток, запад).
* **`PART` (`BlockStateProperties.BED_PART`):** часть кровати (`HEAD` или `FOOT`).
* **`OCCUPIED` (`BlockStateProperties.OCCUPIED`):** булево значение (`true` / `false`), указывающее, занята ли кровать в данный момент спящим игроком или жителем.

---

### 1.3. Зачем кровати нужен `BlockEntity`
Обычный блок камня одинаков везде и не хранит индивидуальных параметров. Но у кровати есть свойства, требующие сохранения:
* Цвет шерсти (особенно актуально для модов с цветной мебелью);
* Внутренний механизм сна и анимации.

Для этого кровать реализует интерфейс **`EntityBlock`** и создает экземпляр **`BlockEntity`**.

---

### 1.4. Игровая логика: сон, точка спавна, отскок и взрыв
Наследуя ванильный класс `BedBlock`, наш блок автоматически получает всю комплексную логику Minecraft:
1. **Сон:** проверка времени суток (ночь или гроза), отсутствие монстров в радиусе 8 блоков.
2. **Спавнпоинт:** при клике ПКМ в чат выводится сообщение *«Точка возрождения установлена»*.
3. **Отскок (Батут / `bounceUp`):** при падении игрока с высоты на кровать наносимый урон от падения снижается, а персонаж подпрыгивает вверх.
4. **Взрыв:** в измерениях без смены дня и ночи (Nether и The End) попытка лечь на кровать вызывает мощный взрыв силой 5 единиц с огнем.

## 2. Создание сущности блока `ModBedBlockEntity`

В версиях **Minecraft 1.20.5+ и 1.21.1** методы сохранения и загрузки NBT принимают `HolderLookup.Provider registries`.

1. В пакете мода создайте подпакет `block.entity` (например, `com.besson.tutorial.block.entity`).
2. Создайте класс `ModBedBlockEntity.java`:

```java
package com.besson.tutorial.block.entity;

import net.minecraft.core.BlockPos;
import net.minecraft.core.HolderLookup;
import net.minecraft.nbt.CompoundTag;
import net.minecraft.network.protocol.game.ClientboundBlockEntityDataPacket;
import net.minecraft.world.item.DyeColor;
import net.minecraft.world.level.block.entity.BlockEntity;
import net.minecraft.world.level.block.state.BlockState;

public class ModBedBlockEntity extends BlockEntity {

    private DyeColor color;

    public ModBedBlockEntity(BlockPos pos, BlockState blockState) {
        // По умолчанию используем бирюзовый (cyan) цвет ледяного эфира
        this(pos, blockState, DyeColor.CYAN);
    }

    public ModBedBlockEntity(BlockPos pos, BlockState blockState, DyeColor color) {
        super(ModBlockEntities.MOD_BED_BE.get(), pos, blockState);
        this.color = color;
    }

    public DyeColor getColor() {
        return this.color;
    }

    public void setColor(DyeColor color) {
        this.color = color;
        this.setChanged();
    }

    /**
     * Сохранение данных в NBT (в 1.21+ передается провайдер реестров)
     */
    @Override
    protected void saveAdditional(CompoundTag tag, HolderLookup.Provider registries) {
        super.saveAdditional(tag, registries);
        tag.putByte("Color", (byte) this.color.getId());
    }

    /**
     * Загрузка данных из NBT
     */
    @Override
    protected void loadAdditional(CompoundTag tag, HolderLookup.Provider registries) {
        super.loadAdditional(tag, registries);
        if (tag.contains("Color", 99)) {
            this.color = DyeColor.byId(tag.getByte("Color"));
        }
    }

    /**
     * Синхронизация с клиентом при появлении чанка
     */
    @Override
    public ClientboundBlockEntityDataPacket getUpdatePacket() {
        return ClientboundBlockEntityDataPacket.create(this);
    }

    @Override
    public CompoundTag getUpdateTag(HolderLookup.Provider registries) {
        CompoundTag tag = new CompoundTag();
        saveAdditional(tag, registries);
        return tag;
    }
}
```

## 3. Создание класса блока `ModBedBlock`

В пакете `com.besson.tutorial.block.custom` создайте класс `ModBedBlock.java`. Он наследуется от ванильного `BedBlock`:

```java
package com.besson.tutorial.block.custom;

import com.besson.tutorial.block.entity.ModBedBlockEntity;
import net.minecraft.core.BlockPos;
import net.minecraft.world.item.DyeColor;
import net.minecraft.world.level.BlockGetter;
import net.minecraft.world.level.block.BedBlock;
import net.minecraft.world.level.block.Block;
import net.minecraft.world.level.block.RenderShape;
import net.minecraft.world.level.block.entity.BlockEntity;
import net.minecraft.world.level.block.state.BlockState;
import net.minecraft.world.phys.shapes.CollisionContext;
import net.minecraft.world.phys.shapes.VoxelShape;

public class ModBedBlock extends BedBlock {

    // Хитбокс кровати: высота 9 пикселей (немного выше полублока)
    protected static final VoxelShape BASE_SHAPE = Block.box(0.0, 0.0, 0.0, 16.0, 9.0, 16.0);

    private final DyeColor color;

    public ModBedBlock(DyeColor color, Properties properties) {
        super(color, properties);
        this.color = color;
    }

    /**
     * Форма коллизии и хитбокса
     */
    @Override
    public VoxelShape getShape(BlockState state, BlockGetter level, BlockPos pos, CollisionContext context) {
        return BASE_SHAPE;
    }

    /**
     * Создание соответствующего BlockEntity
     */
    @Override
    public BlockEntity newBlockEntity(BlockPos pos, BlockState state) {
        return new ModBedBlockEntity(pos, state, this.color);
    }

    /**
     * Указываем обычный рендеринг через модель (MODEL вместо ванильного ENTITYBLOCK_ANIMATED)
     */
    @Override
    public RenderShape getRenderShape(BlockState state) {
        return RenderShape.MODEL;
    }
}
```

> 💡 **Замечание о `RenderShape`:**  
> Ванильные кровати Minecraft используют старый механизм динамического рендеринга `ENTITYBLOCK_ANIMATED` (через встроенные анимации слоев). Для модов гораздо удобнее и надежнее использовать `RenderShape.MODEL`, позволяя загружать современные 3D-модели блоков из Blockbench через стандартные JSON-файлы моделей.

## 4. Регистрация блока и BlockEntity

### 4.1. Регистрация `ModBlockEntities`
В пакете `block.entity` создайте класс `ModBlockEntities.java`:

```java
package com.besson.tutorial.block.entity;

import com.besson.tutorial.TutorialMod;
import com.besson.tutorial.block.ModBlocks;
import net.minecraft.core.registries.Registries;
import net.minecraft.world.level.block.entity.BlockEntityType;
import net.neoforged.bus.api.IEventBus;
import net.neoforged.neoforge.registries.DeferredHolder;
import net.neoforged.neoforge.registries.DeferredRegister;

public class ModBlockEntities {

    public static final DeferredRegister<BlockEntityType<?>> BLOCK_ENTITY_TYPES =
            DeferredRegister.create(Registries.BLOCK_ENTITY_TYPE, TutorialMod.MOD_ID);

    // Регистрация типа сущности блока кровати
    public static final DeferredHolder<BlockEntityType<?>, BlockEntityType<ModBedBlockEntity>> MOD_BED_BE =
            BLOCK_ENTITY_TYPES.register("mod_bed",
                    () -> BlockEntityType.Builder.of(ModBedBlockEntity::new, ModBlocks.ICE_ETHER_BED.get())
                            .build(null));

    public static void register(IEventBus eventBus) {
        BLOCK_ENTITY_TYPES.register(eventBus);
    }
}
```

### 4.2. Регистрация в `ModBlocks`
Откройте класс `ModBlocks.java` и добавьте регистрацию кровати:

```java
package com.besson.tutorial.block;

import com.besson.tutorial.block.custom.ModBedBlock;
import net.minecraft.world.item.DyeColor;
import net.minecraft.world.level.block.SoundType;
import net.minecraft.world.level.block.state.BlockBehaviour;
import net.neoforged.neoforge.registries.DeferredBlock;

public class ModBlocks {
    // ... существующие блоки ...

    // Кровать из ледяного эфира (бирюзовый цвет)
    public static final DeferredBlock<ModBedBlock> ICE_ETHER_BED = registerBlock("ice_ether_bed",
            () -> new ModBedBlock(DyeColor.CYAN, BlockBehaviour.Properties.of()
                    .strength(0.2f)
                    .sound(SoundType.WOOD)
                    .noOcclusion() // Обязательно для неполных блоков
            ));
}
```

### 4.3. Подключение к главной шине мода в `TutorialMod`
Откройте главный класс мода `TutorialMod.java` и добавьте регистрацию BlockEntity:

```java
public TutorialMod(IEventBus modEventBus) {
    ModItems.register(modEventBus);
    ModBlocks.register(modEventBus);
    // ОБЯЗАТЕЛЬНО: Регистрация BlockEntity!

    ModArmorMaterials.register(modEventBus);
    ModVillagers.register(modEventBus);
    ModSounds.register(modEventBus);
    ModCreativeModeTabs.register(modEventBus);

    modEventBus.addListener(this::addCreative);
}
```

## 6. Настройка DataGen

### 6.1. Таблица лута составного блока (`createSinglePropConditionTable`)

Кровать занимает 2 блока (изголовье и изножье). Если применить стандартный `dropSelf()`, при поломке кровати выпадет **два** предмета (по одному с каждого блока).

Чтобы предмет выпадал **только один раз**, в `BlockLootSubProvider` используется специальный метод `createSinglePropConditionTable`, привязывающий выпадение исключительно к блоку изголовья (`BedPart.HEAD`):

Откройте `ModBlockLootTablesProvider.java`:

```java
package com.besson.tutorial.datagen;

import com.besson.tutorial.block.ModBlocks;
import net.minecraft.world.level.block.BedBlock;
import net.minecraft.world.level.block.state.properties.BedPart;

public class ModBlockLootTablesProvider extends BlockLootSubProvider {

    @Override
    protected void generate() {
        // ... другие блоки ...

        // Дроп выпадает только если разрушенная часть кровати — изголовье (HEAD)
        add(ModBlocks.ICE_ETHER_BED.get(), block -> 
                createSinglePropConditionTable(block, BedBlock.PART, BedPart.HEAD));
    }
}
```

## 7. Тестирование в игре

1. Запустите генерацию данных через **`Run Data`**.
2. Запустите клиент игры (**`Run Client`**).
3. Войдите в мир и возьмите кровать из вкладки мода.
4. **Тест установки и соединения:**
    * Нажмите ПКМ по земле: кровать установится сразу на **два блока** (изножье в месте клика и изголовье впереди).
    * Нажмите `F3`: посмотрите на обе половины. У одной будет `part: foot`, у другой — `part: head`.
5. **Тест сна и точки возрождения:**
    * Нажмите ПКМ днем: в левом нижнем углу появится сообщение:  
      *«Вы можете спать только ночью или во время грозы»*, но точка возрождения будет обновлена (*«Точка возрождения установлена»*).
    * Переключите время на полночь (`/time set midnight`).
    * Нажмите ПКМ: персонаж ляжет на кровать, экран плавно затемнится, и наступит ясное утро!
6. **Тест физики отскока (батут):**
    * Постройте столб из 10–15 блоков вверх над кроватью и спрыгните прямо на нее.
    * Персонаж самортизирует удар, не получив критического урона, и подпрыгнет вверх на несколько блоков!
7. **Тест лута:**
    * Сломайте кровать в режиме выживания: независимо от того, по какой половинке вы ударили, выпадет ровно **одна** кровать.
