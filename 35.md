# Урок 35: Создание кастомных деревьев (Саженцы, TreeGrower и Configured Features) в NeoForge 1.21.1

В предыдущих уроках мы научились регистрировать блоки, предметы и настраивать их модели. В этом уроке мы перейдем к процедурной генерации растительности и создадим **полноценное дерево из ледяного эфира (`Ice Ether Tree`)**:
* Разберем архитектуру деревьев в Minecraft 1.21+: почему дерево — это не просто статичная 3D-модель, а динамическая структура из блоков, генерируемая алгоритмами (`Feature`).
* Узнаем, за что отвечают генератор ствола **`TrunkPlacer`**, генератор листвы **`FoliagePlacer`** и детектор свободного места **`FeatureSize`**.
* Создадим логику роста саженца через **`TreeGrower`** с поддержкой костной муки.
* Зарегистрируем блок саженца **`SaplingBlock`** и настроим его прозрачный рендеринг (`cutout`).
* Освоим дата-драйвен генерацию структур (**DataGen WorldGen**): напишем класс **`ModConfiguredFeatures`** и подключим провайдер **`DatapackBuiltinEntriesProvider`** (`RegistrySetBuilder`), генерирующий конфигурацию дерева в JSON автоматически.

## 1. Теория: Архитектура деревьев в Minecraft 1.21+

### 1.1. Из чего состоит дерево: ствол, крона и проверка пространства
Дерево в Minecraft строится процедурно с помощью объекта `TreeConfiguration`. Для сборки конфигурации необходимы следующие компоненты:
1. **`BlockStateProvider` для ствола и листвы:** поставщик блоков, определяющий, из чего строится ствол (`ICE_ETHER_LOG`) и крона (`ICE_ETHER_LEAVES`).
2. **`TrunkPlacer` (Разместитель ствола):** алгоритм построения ствола.
    * `StraightTrunkPlacer(baseHeight, heightRandA, heightRandB)` — классический прямой вертикальный ствол (как у дуба или березы). Высота дерева вычисляется по формуле:
      $$\text{Высота} = \text{baseHeight} + \operatorname{random}(0..\text{heightRandA}) + \operatorname{random}(0..\text{heightRandB})$$
      В нашем уроке мы зададим `(4, 2, 1)`, то есть высота ствола будет варьироваться от 4 до 7 блоков.
    * *(Существуют и другие: `ForkingTrunkPlacer` для ветвящихся деревьев, `FancyTrunkPlacer` для высоких дубов, `CherryTrunkPlacer` для сакуры).*
3. **`FoliagePlacer` (Разместитель листвы):** алгоритм распределения листвы вокруг верхушки ствола.
    * `BlobFoliagePlacer(radius, offset, height)` — стандартная шарообразная/округлая крона.
4. **`FeatureSize` (Детектор коллизий пространства):**
    * `TwoLayersFeatureSize(limit, lowerSize, upperSize)` — проверяет, достаточно ли вокруг свободного воздуха для генерации кроны и не упрется ли дерево в скалу или соседнее здание.
5. **`.ignoreVines()`**: игнорирует лианы при проверке препятствий.

---

### 1.2. Механика `TreeGrower`: от саженца к дереву
Саженец не содержит внутри себя сложный алгоритм генерации. Саженец обращается к объекту **`TreeGrower`**.

В классе `TreeGrower` прописываются ссылки на ключи `ResourceKey<ConfiguredFeature<?, ?>>`:
* Обычное дерево (1×1 саженец);
* Гигантское дерево 2×2 (как у темного дуба или джунглей, если предусмотрено);
* Варианты с пчелиными гнездами или цветами.

Когда игрок удобряет саженец костной мукой или наступает случайный тик (`randomTick`), `TreeGrower` считывает привязанный ключ и вызывает процедурную генерацию структуры в мире.

---

### 1.3. Концепция `ConfiguredFeature` и дата-паков
Начиная с современных версий движка, все параметры генерации структур, руд и деревьев вынесены в **JSON дата-паки** (`data/<mod_id>/worldgen/configured_feature/`).

Вручную писать такие JSON-файлы долго и чревато ошибками. Поэтому в NeoForge используется специальный провайдер **`DatapackBuiltinEntriesProvider`**, который берет строго типизированный код из метода `bootstrap` и сам компилирует валидные JSON-файлы генерации мира.

## 2. Создание конфигурации дерева (`ModConfiguredFeatures`)

1. В пакете вашего мода создайте подпакет `worldgen` (например, `com.besson.tutorial.worldgen`).
2. Создайте класс `ModConfiguredFeatures.java`:

```java
package com.besson.tutorial.worldgen;

import com.besson.tutorial.TutorialMod;
import com.besson.tutorial.block.ModBlocks;
import net.minecraft.core.registries.Registries;
import net.minecraft.data.worldgen.BootstrapContext;
import net.minecraft.resources.ResourceKey;
import net.minecraft.resources.ResourceLocation;
import net.minecraft.util.valueproviders.ConstantInt;
import net.minecraft.world.level.levelgen.feature.ConfiguredFeature;
import net.minecraft.world.level.levelgen.feature.Feature;
import net.minecraft.world.level.levelgen.feature.configurations.FeatureConfiguration;
import net.minecraft.world.level.levelgen.feature.configurations.TreeConfiguration;
import net.minecraft.world.level.levelgen.feature.featuresize.TwoLayersFeatureSize;
import net.minecraft.world.level.levelgen.feature.foliageplacers.BlobFoliagePlacer;
import net.minecraft.world.level.levelgen.feature.stateproviders.BlockStateProvider;
import net.minecraft.world.level.levelgen.feature.trunkplacers.StraightTrunkPlacer;

public class ModConfiguredFeatures {

    // 1. Создаем ключ реестра для нашего дерева
    public static final ResourceKey<ConfiguredFeature<?, ?>> ICE_ETHER_TREE_KEY =
            registerKey("ice_ether_tree");

    /**
     * Метод наполнения реестра через BootstrapContext
     */
    public static void bootstrap(BootstrapContext<ConfiguredFeature<?, ?>> context) {
        // Конфигурация дерева из ледяного эфира:
        register(context, ICE_ETHER_TREE_KEY, Feature.TREE, new TreeConfiguration.TreeConfigurationBuilder(
                // Блок ствола
                BlockStateProvider.simple(ModBlocks.ICE_ETHER_LOG.get()),
                // Прямой ствол: базовая высота 4 + random(2) + random(1) (от 4 до 7 блоков)
                new StraightTrunkPlacer(4, 2, 1),
                // Блок листвы
                BlockStateProvider.simple(ModBlocks.ICE_ETHER_LEAVES.get()),
                // Шарообразная крона: радиус 2, смещение 0, высота листвы 3
                new BlobFoliagePlacer(ConstantInt.of(2), ConstantInt.of(0), 3),
                // Проверка пространства: 1 блок снизу, 0 промежуточных, 1 сверху
                new TwoLayersFeatureSize(1, 0, 1)
        ).ignoreVines().build());
    }

    public static ResourceKey<ConfiguredFeature<?, ?>> registerKey(String name) {
        return ResourceKey.create(Registries.CONFIGURED_FEATURE, ResourceLocation.fromNamespaceAndPath(TutorialMod.MOD_ID, name));
    }

    private static <FC extends FeatureConfiguration, F extends Feature<FC>> void register(
            BootstrapContext<ConfiguredFeature<?, ?>> context,
            ResourceKey<ConfiguredFeature<?, ?>> key,
            F feature,
            FC configuration) {
        context.register(key, new ConfiguredFeature<>(feature, configuration));
    }
}
```

## 3. Создание класса управления ростом (`ModTreeGrowers`)

Теперь создадим объект `TreeGrower`, который свяжет саженец с зарегистрированным выше ключом `ICE_ETHER_TREE_KEY`.

1. В пакете `worldgen` (или `block.custom`) создайте класс `ModTreeGrowers.java`:

```java
package com.besson.tutorial.worldgen;

import com.besson.tutorial.TutorialMod;
import net.minecraft.world.level.block.grower.TreeGrower;

import java.util.Optional;

public class ModTreeGrowers {

    // TreeGrower для дерева ледяного эфира
    public static final TreeGrower ICE_ETHER_TREE_GROWER = new TreeGrower(
            TutorialMod.MOD_ID + ":ice_ether_tree", // Уникальный строковый идентификатор
            Optional.empty(),                      // Вариант гигантского дерева 2х2 (отсутствует)
            Optional.of(ModConfiguredFeatures.ICE_ETHER_TREE_KEY), // Основное одиночное дерево 1х1
            Optional.empty()                       // Вариант дерева с пчелиным ульем (отсутствует)
    );
}
```

## 4. Регистрация блока саженца в `ModBlocks`

Откройте класс `ModBlocks.java`. Зарегистрируйте саженец, передав ему наш `ICE_ETHER_TREE_GROWER`:

```java
package com.besson.tutorial.block;

import com.besson.tutorial.worldgen.ModTreeGrowers;
import net.minecraft.world.level.block.Blocks;
import net.minecraft.world.level.block.SaplingBlock;
import net.minecraft.world.level.block.state.BlockBehaviour;
import net.neoforged.neoforge.registries.DeferredBlock;

public class ModBlocks {
    // ... блоки бревен и листвы ...
    // public static final DeferredBlock<Block> ICE_ETHER_LOG = ...;
    // public static final DeferredBlock<Block> ICE_ETHER_LEAVES = ...;

    // Регистрация саженца ледяного эфира
    public static final DeferredBlock<SaplingBlock> ICE_ETHER_SAPLING = registerBlock("ice_ether_sapling",
            () -> new SaplingBlock(
                    ModTreeGrowers.ICE_ETHER_TREE_GROWER,
                    // Свойства копируются с ванильного дубового саженца
                    BlockBehaviour.Properties.ofFullCopy(Blocks.OAK_SAPLING)
            ));
}
```

## 6. Настройка генерации данных (DataGen)

### 6.1. Регистратор дата-паков (`ModDatapackEntries`)
Для компиляции `ConfiguredFeature` в JSON создадим провайдер `DatapackBuiltinEntriesProvider`.

В пакете `datagen` создайте класс `ModDatapackEntries.java`:

```java
package com.besson.tutorial.datagen;

import com.besson.tutorial.TutorialMod;
import com.besson.tutorial.worldgen.ModConfiguredFeatures;
import net.minecraft.core.HolderLookup;
import net.minecraft.core.RegistrySetBuilder;
import net.minecraft.core.registries.Registries;
import net.minecraft.data.PackOutput;
import net.neoforged.neoforge.common.data.DatapackBuiltinEntriesProvider;

import java.util.Set;
import java.util.concurrent.CompletableFuture;

public class ModDatapackEntries extends DatapackBuiltinEntriesProvider {

    // Собираем строитель реестров генерации мира
    public static final RegistrySetBuilder BUILDER = new RegistrySetBuilder()
            .add(Registries.CONFIGURED_FEATURE, ModConfiguredFeatures::bootstrap);

    public ModDatapackEntries(PackOutput output, CompletableFuture<HolderLookup.Provider> registries) {
        super(output, registries, BUILDER, Set.of(TutorialMod.MOD_ID));
    }
}
```

### 6.3. Модели блока и предмета

Саженец в мире — это плоская крестообразная 2D-модель растения (`cross`), которая требует прозрачного слоя рендеринга (`cutout`).

#### 1. Модель блока и BlockState (`ModBlockStateProvider.java`):
Откройте `ModBlockStateProvider.java` и добавьте метод генерации саженца:

```java
@Override
protected void registerStatesAndModels() {
    // ... другие блоки ...

    // Генерация blockstate и крестообразной модели саженца
    makeSapling(ModBlocks.ICE_ETHER_SAPLING.get(), "ice_ether_sapling");
}

private void makeSapling(Block block, String name) {
    simpleBlock(block, models().cross(name, modLoc("block/" + name)).renderType("cutout"));
}
```

#### 2. Модель предмета в инвентаре (`ModItemModelProvider.java`):
В инвентаре саженец отображается как стандартная плоская иконка:

```java
@Override
protected void registerModels() {
    // ... другие предметы ...

    // Модель предмета саженца
    basicItem(ModBlocks.ICE_ETHER_SAPLING.asItem());
}
```

#### 3. Текстура:
Поместите PNG-изображение саженца (16×16) по пути:  
`src/main/resources/assets/tutorial_mod/textures/block/ice_ether_sapling.png`.

## 7. Тестирование в игре

1. Запустите генерацию данных через конфигурацию запуска **`Run Data`**.  
   Убедитесь, что в директории `src/generated/resources/data/tutorial_mod/worldgen/configured_feature/` успешно создался файл `ice_ether_tree.json`.
2. Запустите клиент игры (**`Run Client`**).
3. Войдите в мир и переключитесь в режим выживания или творчества.
4. Возьмите из инвентаря:
    * **Саженец ледяного эфира (`Ice Ether Sapling`)**;
    * **Костную муку (`Bone Meal`)**.
5. **Тест размещения:**
    * Посадите саженец на землю, дерн или подзол — вокруг прозрачных пикселей нет черных рамок благодаря слою `cutout`.
6. **Тест выращивания:**
    * Кликните костной мукой по саженцу 1–3 раза: саженец выпустит зеленые частицы удобрения и мгновенно вырастет в красивое дерево с прямым стволом из бревен эфира и пышной шарообразной кроной из бирюзовых листьев!
7. **Тест проверки препятствий:**
    * Попробуйте вырастить саженец в тесной пещере высотой в 3 блока — благодаря `TwoLayersFeatureSize` костная мука будет тратиться, но дерево не прорастет сквозь потолок, соблюдая физику игры.

## 8. Частые ошибки

* **При применении костной муки игра вылетает с ошибкой `NoSuchElementException`:** саженец ссылается на ключ `ConfiguredFeature`, которого нет в реестре (забыли запустить задачу `runData` или забыли добавить `ModConfiguredFeatures::bootstrap` в `ModDatapackEntries`).
* **Вокруг саженца черный непрозрачный фон:** в `ModBlockStateProvider` забыли указать `.renderType("cutout")`.
* **Саженец выпадает в виде черно-фиолетового куба:** забыли зарегистрировать модель предмета в `ModItemModelProvider` через `basicItem(...)`.
* **Дерево не растет даже на открытом пространстве:** параметры `baseHeight` и `BlobFoliagePlacer` превышают свободное пространство до ближайших блоков или листва пытается замениться блоками, не являющимися воздухом.
